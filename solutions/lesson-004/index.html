レッスン4：初めてのHTMLファイル - 解答

✅ 解答コード

<script>
console.log("山田太郎");
console.log(7);
console.log(7 * 2);
console.log("完了");
</script>
📊 コンソール出力結果：
山田太郎
7
14
完了

📖 コード解説

1行目：console.log("山田太郎");

説明： 名前を文字列として出力しています。

  • 「山田太郎」は文字列（テキストデータ）なので、ダブルクォーテーション " で囲みます
  • 文字列は " で囲まないとエラーになります
  • 好きな名前に変更してOKです

2行目：console.log(7);

説明： 好きな数字をそのまま出力しています。

  • 数字は " で囲みません
  • " で囲むと文字列になってしまいます
  • 好きな数字に変更してOKです（例：42、100など）

3行目：console.log(7 * 2);

説明： 好きな数字を2倍した値を計算して出力しています。

  • 7 * 2 は掛け算です。JavaScriptが自動的に計算して 14 を出力します
  • * は掛け算の演算子（レッスン3で学びました）
  • 計算式をそのまま書くことができます

4行目：console.log("完了");

説明： 「完了」という文字列を出力しています。

  • 文字列なので " で囲みます
  • プログラムの終わりを示すメッセージです
  • 「終了」「おわり」など、他の言葉に変更してもOKです

🔑 重要なポイント

ポイント1：文字列と数字の違い
  • 文字列："山田太郎" → " で囲む
  • 数字：7 → " で囲まない
  • 計算式：7 * 2 → " で囲まない
ポイント2：順次実行

JavaScriptは上から順番に実行されます。

1行目 → 2行目 → 3行目 → 4行目 の順に実行されます
ポイント3：セミコロン

各命令の最後には ;（セミコロン）をつけます。

  • セミコロンは「この命令はここで終わり」という意味です
  • 忘れるとエラーになる場合があります

🎨 バリエーション例

同じ課題でも、いろいろな書き方ができます：

例1：別の名前と数字

<script>
console.log("田中花子");
console.log(42);
console.log(42 * 2);
console.log("完了");
</script>
出力結果：
田中花子
42
84
完了

例2：計算式を変える

<script>
console.log("佐藤次郎");
console.log(10);
console.log(10 + 10);  // 足し算でも2倍になる
console.log("終了");
</script>
出力結果：
佐藤次郎
10
20
終了

例3：複数の計算

<script>
console.log("山田太郎");
console.log(5);
console.log(5 * 2);
console.log(5 * 3);  // 3倍も追加
console.log(5 * 4);  // 4倍も追加
console.log("完了");
</script>
出力結果：
山田太郎
5
10
15
20
完了

❓ よくある間違いとその修正

間違い1：数字を文字列で囲んでしまう

// ❌ 間違い
console.log("7");      // 文字列の "7" になる
console.log("7 * 2");  // 文字列の "7 * 2" になる（計算されない）
// ✅ 正しい
console.log(7);        // 数字の 7
console.log(7 * 2);    // 計算されて 14 になる

間違い2：文字列を囲み忘れる

// ❌ 間違い
console.log(山田太郎);  // エラー！変数として扱われる
console.log(完了);      // エラー！
// ✅ 正しい
console.log("山田太郎");  // 文字列として正しく表示される
console.log("完了");      // 文字列として正しく表示される

間違い3：セミコロンを忘れる

// ❌ 間違い（動く場合もあるが推奨されない）
console.log("山田太郎")
console.log(7)
// ✅ 正しい
console.log("山田太郎");
console.log(7);
