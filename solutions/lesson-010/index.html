const Solutions - 定数の使い方をマスターしよう

1課題1：円周率と円の面積

📖 課題の内容

円周率を定数として定義し、半径5の円の面積を計算します。

// 課題1：円周率と円の面積
const pi = 3.14;
let radius = 5;
let area = radius * radius * pi;

console.log("半径：" + radius);
console.log("面積：" + area);
🖥️ 実行結果（コンソール）：
半径：5
面積：78.5

🔄 実行の流れ

  1. const pi = 3.14 - 円周率を定数として定義
  2. let radius = 5 - 半径を変数として定義
  3. radius * radius * pi - 5 × 5 × 3.14 = 78.5 を計算
  4. 計算結果をarea変数に保存
  5. 半径と面積をコンソールに表示
🔑 重要ポイント：
  • 円周率（pi）はconstで宣言 - 数学的に決まっている値なので変更しない
  • 半径（radius）はletで宣言 - 後で異なる半径で計算する可能性がある
  • 面積（area）もletで宣言 - 計算結果を保存する変数

2課題2：消費税計算

📖 課題の内容

消費税率を定数として定義し、複数の商品の税込価格を計算します。

// 課題2：消費税計算
const taxRate = 1.1;

let notebookPrice = 120;
let penPrice = 80;
let eraserPrice = 60;

let notebookWithTax = notebookPrice * taxRate;
let penWithTax = penPrice * taxRate;
let eraserWithTax = eraserPrice * taxRate;

let total = notebookPrice + penPrice + eraserPrice;
let totalWithTax = total * taxRate;

console.log("ノート（税込）：" + notebookWithTax + "円");
console.log("ペン（税込）：" + penWithTax + "円");
console.log("消しゴム（税込）：" + eraserWithTax + "円");
console.log("合計（税込）：" + totalWithTax + "円");
🖥️ 実行結果：
ノート（税込）：132円
ペン（税込）：88円
消しゴム（税込）：66円
合計（税込）：286円

🔄 実行の流れ

  1. const taxRate = 1.1 - 消費税率10%（1.1倍）を定数として定義
  2. 3つの商品の税抜価格を変数に保存
  3. 各商品の税込価格を計算：
    • 120 × 1.1 = 132円（ノート）
    • 80 × 1.1 = 88円（ペン）
    • 60 × 1.1 = 66円（消しゴム）
  4. 合計の税抜価格を計算：120 + 80 + 60 = 260円
  5. 合計の税込価格を計算：260 × 1.1 = 286円
  6. 各商品と合計をコンソールに表示
🔑 重要ポイント：
  • taxRate = 1.1は「110%」を意味します（100% + 10%消費税）
  • すべての計算で同じtaxRateを使うので、税率が変わってもこの1箇所を変更するだけで済む
  • 定数を使うことで、計算ミス（例：1.1を1.01と間違える）を防げる

3課題3：割引計算

📖 課題の内容

割引率20%を定数として定義し、1000円の商品の割引後価格を計算します。

// 課題3：割引計算
const discountRate = 0.2;
let originalPrice = 1000;
let discountedPrice = originalPrice * (1 - discountRate);

console.log("元の価格：" + originalPrice + "円");
console.log("割引率：" + (discountRate * 100) + "%");
console.log("割引後価格：" + discountedPrice + "円");
🖥️ 実行結果：
元の価格：1000円
割引率：20%
割引後価格：800円

🔄 実行の流れ

  1. const discountRate = 0.2 - 割引率20%（0.2）を定数として定義
  2. let originalPrice = 1000 - 元の価格を変数に保存
  3. 1 - discountRate - 1 - 0.2 = 0.8（80%の価格になる）
  4. originalPrice * (1 - discountRate) - 1000 × 0.8 = 800
  5. 割引後価格をdiscountedPriceに保存
  6. 元の価格、割引率、割引後価格をコンソールに表示
🔑 重要ポイント：
  • discountRate = 0.2は20%を意味します（0.2 × 100 = 20）
  • 20%引き = 80%の価格 = 元の価格 × (1 - 0.2) = 元の価格 × 0.8
  • 割引率を定数にすることで、様々な商品に同じ割引率を適用しやすくなる

4課題4：エラーを体験する

📖 課題の内容

constに再代入しようとして、エラーメッセージを確認します。

// 課題4：エラーを体験する
const message = "Hello";
message = "World"; // ← ここでエラーが発生
console.log(message);
❌ 実行結果（エラー）：
Uncaught TypeError: Assignment to constant variable.
at index.html:2

🔄 何が起こったか

  1. const message = "Hello" - messageを定数として宣言し、"Hello"を代入
  2. message = "World" - messageに"World"を再代入しようとする
  3. ❌ エラー発生！ - constで宣言した変数は再代入できない
  4. JavaScriptの実行が停止し、エラーメッセージがコンソールに表示される

📖 エラーメッセージの詳細な読み方

Uncaught TypeError: Assignment to constant variable.

  • Uncaught（アンコート）：捕捉されなかった（処理されなかった）エラー
  • TypeError（タイプエラー）：型に関するエラー。変数の型や操作が正しくない
  • Assignment to constant variable：定数への代入を試みた
  • at index.html:2：エラーが発生したファイルと行番号

このエラーが教えてくれること：

「messageはconstで宣言された定数なので、値を変更することはできません！」

🔑 重要ポイント：
  • これは意図的に発生させたエラーです - constの動作を理解するため
  • エラーメッセージは問題を解決するための重要な情報源
  • エラーが出たら怖がらず、メッセージを読んで原因を理解しましょう
  • もしmessageの値を変更したければ、constの代わりにletを使う必要がある

🎨 バリエーション例（8個）

constを使った様々な実装例を見てみましょう。

バリエーション1：複数の税率（標準税率と軽減税率）

const standardTaxRate = 1.1; // 標準税率10%
const reducedTaxRate = 1.08; // 軽減税率8%

let penPrice = 150; // ペン（標準税率）
let breadPrice = 200; // パン（軽減税率）

let penWithTax = penPrice * standardTaxRate;
let breadWithTax = breadPrice * reducedTaxRate;

console.log("ペン（税込）：" + penWithTax + "円"); // 165円
console.log("パン（税込）：" + breadWithTax + "円"); // 216円

説明： 複数の税率を定数として定義し、商品の種類によって使い分けることができます。

バリエーション2：円の周の長さと面積を同時に計算

const pi = 3.14159;
let radius = 10;

let circumference = 2 * pi * radius; // 円周の長さ
let area = pi * radius * radius; // 円の面積

console.log("半径：" + radius + "cm");
console.log("円周：" + circumference + "cm");
console.log("面積：" + area + "cm²");

説明： 1つの定数（pi）を使って、複数の異なる計算を行うことができます。

バリエーション3：時給計算

const hourlyWage = 1200; // 時給1200円

let hoursWorked = 8; // 働いた時間
let dailyPay = hourlyWage * hoursWorked;

let daysWorked = 5; // 働いた日数
let weeklyPay = dailyPay * daysWorked;

console.log("時給：" + hourlyWage + "円");
console.log("1日の給与：" + dailyPay + "円");
console.log("週給：" + weeklyPay + "円");

説明： 時給を定数にすることで、様々な期間の給与計算に使い回せます。

バリエーション4：ポイント還元率

const pointRate = 0.05; // 5%ポイント還元

let purchaseAmount = 5000;
let pointsEarned = purchaseAmount * pointRate;

console.log("購入金額：" + purchaseAmount + "円");
console.log("還元率：" + (pointRate * 100) + "%");
console.log("獲得ポイント：" + pointsEarned + "ポイント");

説明： ポイント還元率を定数にすることで、計算ミスを防ぎ、変更も簡単になります。

バリエーション5：温度変換（摂氏→華氏）

const conversionFactor = 1.8;
const conversionOffset = 32;

let celsius = 25; // 摂氏25度
let fahrenheit = celsius * conversionFactor + conversionOffset;

console.log(celsius + "℃ = " + fahrenheit + "℉");

説明： 変換係数を定数にすることで、数式が読みやすくなり、間違いも減ります。

❌ よくある間違いと修正方法（5個）

間違い1：constに再代入しようとする

❌ const price = 100;
price = 200; // エラー！

問題点： constで宣言した変数は再代入できません。

✅ let price = 100;
price = 200; // OK!

修正方法： 値を変更したい場合は、constではなくletを使います。

間違い2：constの初期化忘れ

❌ const taxRate; // エラー！
taxRate = 1.1;

問題点： constは宣言と同時に値を設定する必要があります。後から代入することはできません。

✅ const taxRate = 1.1; // 宣言と同時に初期化

修正方法： constの宣言と初期化を同じ行で行います。

間違い3：変更が必要な値にconstを使う

❌ const counter = 0;
counter = counter + 1; // エラー！
counter = counter + 1; // エラー！

問題点： カウンターのように値が変わる変数にconstを使うと、値を更新できません。

✅ let counter = 0;
counter = counter + 1; // OK!
counter = counter + 1; // OK!

修正方法： 値が変わる可能性がある場合は、letを使います。

間違い4：変わらない値にletを使う

❌ let pi = 3.14; // 動くけど推奨されない
let result = 2 * pi * 5;

問題点： 動作はしますが、piは変更しないのにletを使っているため、意図が不明確です。

✅ const pi = 3.14; // 変更しないことが明確
let result = 2 * pi * 5;

修正方法： 変更しない値はconstで宣言することで、意図を明確にします。

間違い5：同じ名前の定数を2回宣言

❌ const pi = 3.14;
const pi = 3.14159; // エラー！

問題点： 同じ名前の変数を2回宣言することはできません（letでも同じ）。

✅ const pi = 3.14159; // 最初から正確な値で宣言

修正方法： 最初の宣言だけを残すか、変数名を変えます。

📊 letとconstの詳細比較

項目 let const
再代入 ✅ できる ❌ できない（エラーになる）
初期化 後で代入可能 宣言時に必須
用途 値が変わる変数 値が変わらない定数
エラー 何度変更してもエラーなし 再代入時にTypeError
例 counter, userInput, result pi, taxRate, maxValue
推奨 値を更新する必要がある場合 値を更新しない場合（基本はconst）

📚 まとめ

今回学んだ重要なポイント

  • 定数（const）：一度値を設定したら変更できない変数
  • constを使う理由：意図を明確にし、意図しない変更を防ぐ
  • letとの違い：letは再代入可能、constは再代入不可
  • エラーメッセージ：constに再代入すると"Assignment to constant variable"エラー
  • 初期化のルール：constは宣言と同時に値を設定する必要がある
  • 使い分けの基本：迷ったらconstを使い、必要に応じてletに変更
