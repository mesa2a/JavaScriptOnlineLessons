✅ 総合確認問題 - 問題1：税込価格の計算

解答例

const taxRate = 1.1;

let applePrice = 150;
let breadPrice = 200;
let milkPrice = 180;

let appleWithTax = applePrice * taxRate;
let breadWithTax = breadPrice * taxRate;
let milkWithTax = milkPrice * taxRate;

let total = applePrice + breadPrice + milkPrice;
let totalWithTax = total * taxRate;

console.log("りんご（税込）：" + appleWithTax + "円");
console.log("パン（税込）：" + breadWithTax + "円");
console.log("牛乳（税込）：" + milkWithTax + "円");
console.log("合計（税込）：" + totalWithTax + "円");
りんご（税込）：165円
パン（税込）：220円
牛乳（税込）：198円
合計（税込）：583円

📖 詳しい解説

ステップ1：消費税率を定数で定義
const taxRate = 1.1;

消費税率は変わらない値なので const を使います。1.1は「100% + 10%」を意味します。

ステップ2：各商品の価格を変数に保存
let applePrice = 150;
let breadPrice = 200;
let milkPrice = 180;

商品の価格を変数に保存します。この例では let を使っていますが、変更しない場合は const でもOKです。

ステップ3：各商品の税込価格を計算
let appleWithTax = applePrice * taxRate; // 150 * 1.1 = 165
let breadWithTax = breadPrice * taxRate; // 200 * 1.1 = 220
let milkWithTax = milkPrice * taxRate; // 180 * 1.1 = 198

各価格に消費税率を掛けて、税込価格を計算します。

ステップ4：合計を計算
let total = applePrice + breadPrice + milkPrice; // 530
let totalWithTax = total * taxRate; // 583

まず税抜の合計を計算し、それに消費税率を掛けて税込合計を算出します。

🎯 この問題で復習したこと：
  • const の使い方（消費税率）
  • let の使い方（変数への値の保存）
  • 四則演算（掛け算と足し算）
  • 文字列連結（+ で文字列と数値を連結）
  • console.log での出力

✅ 総合確認問題 - 問題2：自己紹介文の作成

解答例

let name = "山田太郎";
let age = 25;
let hometown = "東京";
let hobby = "プログラミング";

let intro = name + "は" + age + "歳で、" + hometown + "出身です。趣味は" + hobby + "です。";
console.log(intro);
山田太郎は25歳で、東京出身です。趣味はプログラミングです。

📖 詳しい解説

文字列連結のポイント：

  • + 演算子で文字列と変数をつなげます
  • 変数名の前後に + を付けます
  • 「は」「歳で」などの助詞も忘れずに入れます
文字列連結の流れ：
// 変数の値
name = "山田太郎"
age = 25
hometown = "東京"
hobby = "プログラミング"

// 連結の過程
"山田太郎" + "は" + 25 + "歳で、" + "東京" + "出身です。趣味は" + "プログラミング" + "です。"
↓
"山田太郎は25歳で、東京出身です。趣味はプログラミングです。"

📖 詳しい解説

🎯 実践課題 - 課題2：買い物レシート

解答例

const taxRate = 1.1;

let notebookPrice = 150;
let notebookCount = 2;
let notebookTotal = notebookPrice * notebookCount;

let penPrice = 100;
let penCount = 3;
let penTotal = penPrice * penCount;

let eraserPrice = 80;
let eraserCount = 1;
let eraserTotal = eraserPrice * eraserCount;

let subtotal = notebookTotal + penTotal + eraserTotal;
let totalWithTax = subtotal * taxRate;

console.log("--- 買い物レシート ---");
console.log("ノート：" + notebookTotal + "円");
console.log("ペン：" + penTotal + "円");
console.log("消しゴム：" + eraserTotal + "円");
console.log("小計：" + subtotal + "円");
console.log("税込合計：" + totalWithTax + "円");
--- 買い物レシート ---
ノート：300円
ペン：300円
消しゴム：80円
小計：680円
税込合計：748円

📖 詳しい解説

計算の流れ：
  1. 各商品の小計：単価 × 個数
    • ノート：150 × 2 = 300円
    • ペン：100 × 3 = 300円
    • 消しゴム：80 × 1 = 80円
  2. 合計（税抜）：300 + 300 + 80 = 680円
  3. 税込合計：680 × 1.1 = 748円
🎯 実用的なポイント：

このようなレシート計算は、実際のプログラミングでよく使われるパターンです。ECサイトやPOSレジシステムなど、多くの場所で同じような計算が行われています。

🎯 実践課題 - 課題3：学習記録まとめ

解答例

// 学習情報
let startMonth = 1;
let startDay = 1;
let currentMonth = 1;
let currentDay = 20;

// 学習日数を計算（簡易版）
let studyDays = currentDay - startDay;

// 完了レッスン数
let completedLessons = 12;

// 1日あたりのレッスン数を計算
let lessonsPerDay = completedLessons / studyDays;

// 出力
console.log("=== 第1章 学習記録 ===");
console.log("学習開始日：2025年" + startMonth + "月" + startDay + "日");
console.log("学習日数：" + studyDays + "日");
console.log("完了レッスン数：" + completedLessons + "レッスン");
console.log("1日あたり：" + lessonsPerDay + "レッスン");
console.log("おめでとうございます！第1章完了です！");
=== 第1章 学習記録 ===
学習開始日：2025年1月1日
学習日数：19日
完了レッスン数：12レッスン
1日あたり：0.631578947368421レッスン
おめでとうございます！第1章完了です！

📖 詳しい解説

計算のポイント：
  • studyDays = currentDay - startDay - 学習日数の計算（減算）
  • lessonsPerDay = completedLessons / studyDays - 1日あたりのレッスン数（除算）
  • 割り算の結果は小数になります（JavaScriptは自動的に小数を計算します）
