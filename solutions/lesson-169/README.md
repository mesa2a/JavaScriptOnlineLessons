# 予算管理アプリ

JavaScript学習の総合プロジェクトとして作成した予算管理アプリケーションです。

## 概要

このアプリケーションは、日々の収入と支出を記録し、統計やレポートを表示することで家計管理をサポートするWebアプリです。localStorageを使用してデータを永続化し、CSV/JSON形式でのエクスポート・インポート機能も備えています。

## 機能

### 基本機能
- ✅ 収入・支出の記録
- ✅ カテゴリ別の分類（収入：給料、副業、ボーナス、その他 / 支出：食費、交通費、住居費、娯楽費、医療費、通信費、教育費、その他）

## 使い方

### 1. アプリの起動
`index.html`をブラウザで開くだけで使用できます。サーバーは不要です。

### 2. 収入を記録する
1. 「収入」ラジオボタンを選択
2. カテゴリを選択（給料、副業など）
3. 金額を入力（0以上の数値）
4. 日付を選択
5. メモを入力（任意）
6. 「追加」ボタンをクリック

### 3. 支出を記録する
1. 「支出」ラジオボタンを選択
2. カテゴリを選択（食費、交通費など）
3. 金額を入力（0以上の数値）
4. 日付を選択
5. メモを入力（任意）
6. 「追加」ボタンをクリック

### 4. データの確認
- **取引一覧タブ**: すべての取引を時系列で表示
- **統計タブ**: 収入・支出・収支バランスをカード形式で表示
- **レポートタブ**: カテゴリ別と月別のレポートを表示

### 5. データのエクスポート
1. 「エクスポート」タブを開く
2. 「CSVエクスポート」または「JSONエクスポート」ボタンをクリック
3. ファイルが自動的にダウンロードされます
   - CSV: `budget_data_YYYYMMDD.csv`
   - JSON: `budget_data_YYYYMMDD.json`

### 6. データのインポート
1. 「インポート」タブを開く
2. 「ファイルを選択」ボタンでCSVまたはJSONファイルを選択
3. データが自動的に読み込まれ、既存データに追加されます

## トラブルシューティング

### データが保存されない
- ブラウザのlocalStorageが有効になっているか確認
- プライベートモードやシークレットモードでないか確認
- ストレージ容量が十分か確認（約5-10MBまで）

### インポートが失敗する
- ファイル形式が正しいか確認（CSV/JSON）
- 本アプリでエクスポートしたファイルか確認
- ファイルが破損していないか確認
- 文字エンコーディングがUTF-8か確認

### 画面が正しく表示されない
- ブラウザのキャッシュをクリア
- ページを強制再読み込み（Ctrl+F5 / Cmd+Shift+R）
- 別のブラウザで試す
- コンソールでエラーを確認
