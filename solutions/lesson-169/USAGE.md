## 基本的な使い方

### 1. 収入を記録する

収入を記録する手順：

1. **種類を選択**
   - 画面上部の「収入」ラジオボタンをクリックします
   - カテゴリ選択が収入用に自動更新されます

2. **カテゴリを選択**
   - プルダウンメニューから適切なカテゴリを選択します
   - 収入カテゴリ：給料、副業、ボーナス、その他

3. **金額を入力**
   - 金額欄に数値を入力します
   - 例: `100000`（カンマは不要）
   - 0以上の数値のみ入力可能です

4. **日付を選択**
   - カレンダーアイコンをクリックして日付を選択
   - または直接入力（YYYY-MM-DD形式）
   - 例: `2025-11-24`

5. **メモを入力（任意）**
   - 必要に応じてメモを入力します
   - 例: 「11月分の給与」「副業の報酬」
   - 最大200文字まで入力可能

6. **追加ボタンをクリック**
   - 「追加」ボタンをクリックすると取引が登録されます
   - 成功すると「取引を追加しました」というトースト通知が表示されます
   - 入力フォームが自動的にクリアされます

### 2. 支出を記録する

支出を記録する手順：

1. **種類を選択**
   - 画面上部の「支出」ラジオボタンをクリックします
   - カテゴリ選択が支出用に自動更新されます

2. **カテゴリを選択**
   - プルダウンメニューから適切なカテゴリを選択します
   - 支出カテゴリ：食費、交通費、住居費、娯楽費、医療費、通信費、教育費、その他

3. **金額を入力**
   - 金額欄に数値を入力します
   - 例: `5000`
   - 負の数は入力できません

4. **日付を選択**
   - 収入と同様に日付を選択します

5. **メモを入力（任意）**
   - 支出の内容を記録します
   - 例: 「スーパーで食材購入」「電車代」

6. **追加ボタンをクリック**
   - 「追加」ボタンで取引が登録されます

### 3. 取引を編集・削除する

#### 取引の削除

1. **取引一覧タブを開く**
   - 画面上部の「取引一覧」タブをクリック

2. **削除したい取引を探す**
   - フィルター機能を使って絞り込むこともできます
   - 種類フィルター：すべて、収入のみ、支出のみ
   - カテゴリフィルター：すべて、特定カテゴリ

3. **削除ボタンをクリック**
   - 取引の右側にある「削除」ボタンをクリック
   - 確認ダイアログが表示されます
   - 「OK」をクリックすると削除されます

4. **削除の確認**
   - 「取引を削除しました」というトースト通知が表示されます
   - 統計とレポートが自動的に更新されます

#### フィルター機能

- **種類でフィルター**
  - 「すべて」：すべての取引を表示
  - 「収入」：収入のみ表示
  - 「支出」：支出のみ表示

- **カテゴリでフィルター**
  - プルダウンから特定のカテゴリを選択
  - 選択したカテゴリの取引のみ表示

## レポート機能

### カテゴリ別レポート

カテゴリごとの支出額と割合を確認できます。

#### 使い方

1. **レポートタブを開く**
   - 画面上部の「レポート」タブをクリック

2. **カテゴリ別レポートを確認**
   - カテゴリ別セクションに各カテゴリの情報が表示されます
   - 表示内容：
     - カテゴリ名
     - 合計金額（カンマ区切り）
     - 全体に占める割合（%）

3. **レポートの見方**
   - 割合が高いカテゴリが支出の大部分を占めています
   - どのカテゴリに多く使っているか一目で分かります

#### 活用例

- 食費の割合が高い → 外食を減らす
- 娯楽費が多い → 予算を見直す
- 交通費が高い → 通勤方法を検討

### 月別レポート

月ごとの収入・支出・収支バランスを確認できます。

#### 使い方

1. **レポートタブを開く**
   - 画面上部の「レポート」タブをクリック

2. **月別レポートを確認**
   - 月別レポートセクションに各月の情報が表示されます
   - 表示内容：
     - 年月（YYYY年MM月）
     - 収入合計
     - 支出合計
     - 収支（収入 - 支出）

3. **収支の色分け**
   - プラス（黒字）：緑色で表示
   - マイナス（赤字）：赤色で表示

#### 活用例

- 月ごとの収支推移を確認
- 赤字の月を特定して原因を分析
- 収入の変動パターンを把握

## データ管理

### エクスポート機能

データを外部ファイルとして保存できます。

#### CSV形式でエクスポート

CSVファイルはExcelで開くことができます。

**手順：**

1. **エクスポートタブを開く**
   - 画面上部の「エクスポート」タブをクリック

2. **CSVエクスポートボタンをクリック**
   - 「CSVエクスポート」ボタンをクリック
   - ファイルが自動的にダウンロードされます

3. **ファイル名**
   - `budget_data_YYYYMMDD.csv`
   - 例: `budget_data_20251124.csv`

4. **ファイルの内容**
   ```csv
   日付,種類,カテゴリ,金額,メモ
   2025-11-01,収入,給料,100000,11月分の給与
   2025-11-02,支出,食費,5000,スーパーで買い物
   ```

**特徴：**
- BOM付きUTF-8エンコーディング（Excel日本語対応）
- カンマ、改行、ダブルクォートを含むデータも正しく処理
- Excelで直接開ける

#### JSON形式でエクスポート

JSON形式は他のプログラムで処理しやすい形式です。

**手順：**

1. **エクスポートタブを開く**
   - 画面上部の「エクスポート」タブをクリック

2. **JSONエクスポートボタンをクリック**
   - 「JSONエクスポート」ボタンをクリック
   - ファイルが自動的にダウンロードされます

3. **ファイル名**
   - `budget_data_YYYYMMDD.json`
   - 例: `budget_data_20251124.json`

4. **ファイルの内容**
   ```json
   [
     {
       "id": 1732435200000,
       "type": "income",
       "category": "給料",
       "amount": 100000,
       "date": "2025-11-01",
       "memo": "11月分の給与"
     }
   ]
   ```

**特徴：**
- 整形された読みやすい形式
- すべてのデータ構造を保持
- プログラムで処理しやすい

### インポート機能

外部ファイルからデータを読み込めます。

#### 対応ファイル形式

- CSV（本アプリでエクスポートしたもの）
- JSON（本アプリでエクスポートしたもの）

#### 手順

1. **インポートタブを開く**
   - 画面上部の「インポート」タブをクリック

2. **ファイルを選択**
   - 「ファイルを選択」ボタンをクリック
   - CSVまたはJSONファイルを選択

3. **自動読み込み**
   - ファイルが自動的に処理されます
   - データが既存データに追加されます
   - 「ファイルを読み込みました: XX件」と表示されます

4. **確認**
   - 取引一覧タブでインポートされたデータを確認
   - 統計とレポートが更新されます

#### 注意事項

- **追加方式**: インポートしたデータは既存データに追加されます（上書きではない）
- **重複**: 同じデータを複数回インポートすると重複します
- **検証**: 不正なデータは自動的にスキップされます
- **形式**: 本アプリでエクスポートしたファイルのみ対応

### データのクリア

すべてのデータを削除できます。

**手順：**

1. **データ管理タブを開く**
   - 画面上部の「データ管理」タブをクリック

2. **全データクリアボタンをクリック**
   - 「全データクリア」ボタンをクリック
   - 確認ダイアログが表示されます

3. **確認**
   - 「すべてのデータを削除しますか？この操作は取り消せません。」
   - 「OK」をクリックすると全データが削除されます

4. **削除完了**
   - 「すべてのデータを削除しました」と表示されます
   - すべての画面がクリアされます

⚠️ **警告**: この操作は取り消せません。重要なデータは必ずエクスポートしてバックアップしてください。

### ストレージ情報

現在のデータ使用状況を確認できます。

**表示内容：**
- 取引件数
- 使用ストレージサイズ（KB）
- 最終更新日時

## トラブルシューティング

### データが保存されない

**原因と解決方法：**

1. **localStorageが無効**
   - ブラウザの設定でlocalStorageを有効にしてください
   - Chrome: 設定 > プライバシーとセキュリティ > Cookie

2. **プライベートモード**
   - プライベート/シークレットモードではlocalStorageが機能しない場合があります
   - 通常モードで使用してください

3. **ストレージ容量不足**
   - ブラウザのストレージ容量を超えています（通常5-10MB）
   - 古いデータをエクスポートしてから削除してください

4. **ブラウザの問題**
   - ブラウザのキャッシュをクリアしてください
   - ブラウザを最新版に更新してください

### インポートが失敗する

**原因と解決方法：**

1. **ファイル形式が不正**
   - 本アプリでエクスポートしたCSV/JSONファイルか確認
   - ファイルを手動編集した場合、形式が壊れている可能性があります

2. **ファイルが破損**
   - ファイルを再ダウンロードしてください
   - 別のファイルで試してください

3. **文字エンコーディング**
   - UTF-8形式で保存されているか確認
   - テキストエディタで開いて確認してください

4. **データ形式エラー**
   - 日付形式が YYYY-MM-DD になっているか確認
   - 金額が数値になっているか確認

### 画面が正しく表示されない

**原因と解決方法：**

1. **キャッシュの問題**
   - ブラウザのキャッシュをクリア
   - 強制再読み込み（Ctrl+F5 または Cmd+Shift+R）

2. **CSSが読み込まれていない**
   - style.cssが同じフォルダにあるか確認
   - ブラウザの開発者ツールでエラーを確認

3. **JavaScriptエラー**
   - ブラウザのコンソールでエラーを確認（F12キー）
   - script.jsが同じフォルダにあるか確認

4. **ブラウザの互換性**
   - 別のブラウザで試してください（Chrome推奨）
   - Internet Explorerは非対応です

### 統計が更新されない

**原因と解決方法：**

1. **ページを再読み込み**
   - F5キーでページを再読み込みしてください

2. **データの再計算**
   - 取引を1つ追加または削除すると再計算されます

3. **localStorageの確認**
   - ブラウザの開発者ツールでlocalStorageを確認
   - データが正しく保存されているか確認

## よくある質問

### Q1: データはどこに保存されますか？

A: ブラウザのlocalStorageに保存されます。サーバーには送信されません。同じブラウザでアクセスすれば、いつでもデータを確認できます。

### Q2: 複数のデバイスでデータを共有できますか？

A: localStorageはブラウザごとに独立しています。データを共有するには、エクスポート/インポート機能を使用してください。

### Q3: データのバックアップは必要ですか？

A: はい、重要なデータは定期的にエクスポートしてバックアップすることをお勧めします。ブラウザのデータをクリアするとlocalStorageも削除されます。

### Q4: オフラインで使用できますか？

A: はい、インターネット接続は不要です。ただし、初回アクセス時にファイルをダウンロードする必要があります。

### Q5: スマートフォンで使用できますか？

A: はい、レスポンシブデザインに対応しています。モバイルブラウザでも使用可能です。

### Q6: 予算の上限を設定できますか？

A: 現在のバージョンでは予算設定機能はありません。今後の改善予定です。

### Q7: グラフ表示機能はありますか？

A: 現在のバージョンでは未実装です。今後の改善予定です。

### Q8: データを編集できますか？

A: 現在のバージョンでは削除と再追加で対応してください。編集機能は今後の改善予定です。

### Q9: 複数の通貨に対応していますか？

A: いいえ、現在は単一通貨のみ対応しています。

### Q10: ユーザー登録は必要ですか？

A: いいえ、ユーザー登録は不要です。ブラウザで開くだけで使用できます。

## その他のヒント

### 効率的な使い方

1. **定期的な記録**
   - 毎日または毎週、定期的に記録する習慣をつけましょう

2. **詳細なメモ**
   - メモ欄を活用して、後で見返したときに分かるように記録しましょう

3. **カテゴリの統一**
   - 同じ種類の支出は同じカテゴリに分類しましょう
   - 統計が正確になります

4. **定期的なレビュー**
   - 月末にレポートを確認して、支出を振り返りましょう

5. **バックアップ**
   - 月に1回、エクスポートしてバックアップを取りましょう

### ショートカットキー

- **F5**: ページ再読み込み
- **Ctrl+F5 / Cmd+Shift+R**: 強制再読み込み
- **F12**: 開発者ツールを開く
