レッスン8：変数を使った計算 - 解答

📝 課題1：基本の計算 - 解答

基本の解答

let price = 200; let count = 4; let total = price * count; console.log("単価：" + price + "円"); console.log("個数：" + count + "個"); console.log("合計：" + total + "円");

📖 コードの説明

1行目： let price = 200;

  • 単価（price）を200円として保存

2行目： let count = 4;

  • 個数（count）を4個として保存

3行目： let total = price * count;

  • price * countを計算（200 × 4 = 800）
  • 計算結果の800をtotalに保存
  • この時点でtotalは800という値を持つ

5〜7行目： 結果を表示

  • "単価：" + price + "円" → 文字列と変数を連結
  • priceの値（200）が自動的に文字列に変換される
  • 結果：「単価：200円」

🖥️ コンソール出力

単価：200円
個数：4個
合計：800円

バリエーション例

例1：別の商品

let price = 350; let count = 2; let total = price * count; console.log("単価：" + price + "円"); console.log("個数：" + count + "個"); console.log("合計：" + total + "円");

出力： 単価：350円 / 個数：2個 / 合計：700円

例2：まとめて表示

let price = 200; let count = 4; let total = price * count; console.log(price + "円 × " + count + "個 = " + total + "円");

出力： 200円 × 4個 = 800円

例3：商品名を追加

let item = "りんご"; let price = 200; let count = 4; let total = price * count; console.log("商品：" + item); console.log("単価：" + price + "円"); console.log("個数：" + count + "個"); console.log("合計：" + total + "円");

📝 課題2：割引計算 - 解答

基本の解答

let price = 1000; let discountRate = 20; let discount = price * discountRate / 100; let finalPrice = price - discount; console.log("元の価格：" + price + "円"); console.log("割引率：" + discountRate + "%"); console.log("割引額：" + discount + "円"); console.log("支払い額：" + finalPrice + "円");

📖 コードの説明

1〜2行目： 基本情報を保存

  • price = 1000（元の価格）
  • discountRate = 20（割引率20%）

3行目： let discount = price * discountRate / 100;

  • 割引額を計算：1000 × 20 ÷ 100 = 200
  • 20%は「20 / 100」または「0.2」
  • 1000 × 0.2 = 200 でも同じ結果

4行目： let finalPrice = price - discount;

  • 支払い額を計算：1000 - 200 = 800
  • 元の価格から割引額を引く

🖥️ コンソール出力

元の価格：1000円
割引率：20%
割引額：200円
支払い額：800円

💡 計算の流れ

  1. 元の価格：1000円
  2. 割引率：20%
  3. 割引額：1000 × 20 / 100 = 200円
  4. 支払い額：1000 - 200 = 800円

バリエーション例

例1：別の割引率（30%オフ）

let price = 1500; let discountRate = 30; let discount = price * discountRate / 100; let finalPrice = price - discount; console.log("元の価格：" + price + "円"); console.log("割引率：" + discountRate + "%"); console.log("割引額：" + discount + "円"); console.log("支払い額：" + finalPrice + "円");

計算： 1500 × 30 / 100 = 450円引き → 1050円

例2：小数を使った計算

let price = 1000; let discount = price * 0.2; // 20% let finalPrice = price - discount; console.log("元の価格：" + price + "円"); console.log("割引額：" + discount + "円"); console.log("支払い額：" + finalPrice + "円");

説明： 0.2は20%と同じ意味

例3：1行で計算

let price = 1000; let discountRate = 20; let finalPrice = price - (price * discountRate / 100); console.log("元の価格：" + price + "円"); console.log("割引率：" + discountRate + "%"); console.log("支払い額：" + finalPrice + "円");

📝 課題3：買い物リスト - 解答

基本の解答

let notebookPrice = 150; let notebookCount = 2; let notebookTotal = notebookPrice * notebookCount; let penPrice = 100; let penCount = 3; let penTotal = penPrice * penCount; let eraserPrice = 80; let eraserCount = 1; let eraserTotal = eraserPrice * eraserCount; let grandTotal = notebookTotal + penTotal + eraserTotal; console.log("ノート：" + notebookTotal + "円"); console.log("ペン：" + penTotal + "円"); console.log("消しゴム：" + eraserTotal + "円"); console.log("合計：" + grandTotal + "円");

📖 コードの説明

ノートの計算（1〜3行目）：

  • 単価：150円、個数：2冊
  • 小計：150 × 2 = 300円

ペンの計算（5〜7行目）：

  • 単価：100円、個数：3本
  • 小計：100 × 3 = 300円

消しゴムの計算（9〜11行目）：

  • 単価：80円、個数：1個
  • 小計：80 × 1 = 80円

総合計（13行目）：

  • すべての小計を足す
  • 300 + 300 + 80 = 680円

🖥️ コンソール出力

ノート：300円
ペン：300円
消しゴム：80円
合計：680円

バリエーション例

例1：別の買い物リスト

let applePrice = 120; let appleCount = 4; let appleTotal = applePrice * appleCount; let milkPrice = 180; let milkCount = 2; let milkTotal = milkPrice * milkCount; let breadPrice = 200; let breadCount = 1; let breadTotal = breadPrice * breadCount; let grandTotal = appleTotal + milkTotal + breadTotal; console.log("りんご：" + appleTotal + "円"); console.log("牛乳：" + milkTotal + "円"); console.log("パン：" + breadTotal + "円"); console.log("合計：" + grandTotal + "円");

合計： 480 + 360 + 200 = 1040円

例2：詳細な表示

let notebookPrice = 150; let notebookCount = 2; let notebookTotal = notebookPrice * notebookCount; let penPrice = 100; let penCount = 3; let penTotal = penPrice * penCount; let grandTotal = notebookTotal + penTotal; console.log("--- 買い物リスト ---"); console.log("ノート：" + notebookPrice + "円 × " + notebookCount + "冊 = " + notebookTotal + "円"); console.log("ペン：" + penPrice + "円 × " + penCount + "本 = " + penTotal + "円"); console.log("-------------------"); console.log("合計：" + grandTotal + "円");

📝 課題4：お釣り計算 - 解答

基本の解答

let payment = 1000; let cost = 680; let change = payment - cost; console.log("支払い：" + payment + "円"); console.log("金額：" + cost + "円"); console.log("お釣り：" + change + "円");

📖 コードの説明

1〜2行目： 金額を保存

  • payment = 1000（支払った金額）
  • cost = 680（商品の金額）

3行目： let change = payment - cost;

  • お釣りを計算：1000 - 680 = 320
  • 引き算（-）を使用

🖥️ コンソール出力

支払い：1000円
金額：680円
お釣り：320円

バリエーション例

例1：別の金額

let payment = 2000; let cost = 1350; let change = payment - cost; console.log("支払い：" + payment + "円"); console.log("金額：" + cost + "円"); console.log("お釣り：" + change + "円");

計算： 2000 - 1350 = 650円

例2：ぴったりの場合

let payment = 500; let cost = 500; let change = payment - cost; console.log("支払い：" + payment + "円"); console.log("金額：" + cost + "円"); console.log("お釣り：" + change + "円"); if (change === 0) { console.log("ぴったりです！"); }

注： if文は後のレッスンで学びます

例3：複数の商品を買った場合

let item1 = 250; let item2 = 180; let item3 = 350; let totalCost = item1 + item2 + item3; let payment = 1000; let change = payment - totalCost; console.log("商品1：" + item1 + "円"); console.log("商品2：" + item2 + "円"); console.log("商品3：" + item3 + "円"); console.log("合計：" + totalCost + "円"); console.log("支払い：" + payment + "円"); console.log("お釣り：" + change + "円");

❌ よくある間違いと修正方法

間違い1：計算順序の間違い

❌ 間違ったコード

let a = 10; let b = 20; console.log("合計：" + a + b); // 出力：合計：1020

問題： 文字列連結が先に行われ、計算されない

✅ 正しいコード

let a = 10; let b = 20; console.log("合計：" + (a + b)); // 出力：合計：30

括弧を使って計算を先に実行！

間違い2：変数名のスペルミス

❌ 間違ったコード

let price = 200; let count = 4; let total = prise * count; // priceではなくprise // エラー：priseは定義されていない

✅ 正しいコード

let price = 200; let count = 4; let total = price * count; // 正しいスペル

変数名のスペルに注意！

間違い3：計算結果を保存し忘れる

❌ 間違ったコード

let price = 200; let count = 4; price * count; // 計算だけして保存していない console.log(total); // totalは定義されていない // エラー：totalは定義されていない

✅ 正しいコード

let price = 200; let count = 4; let total = price * count; // 計算結果を保存 console.log(total); // 800

計算結果は変数に保存する！

🎓 まとめ

変数を使った計算の基本

  • 変数に保存された数値を使って四則演算ができる
  • 計算結果を変数に保存できる
  • 変数を使うとコードが読みやすく、変更しやすくなる

文字列と変数の連結

  • +記号で文字列と変数を連結できる
  • 数値は自動的に文字列に変換される
  • 計算を先にしたい場合は括弧を使う：(a + b)

実用的なプログラム

  • 買い物計算機のような実用的なプログラムが作れる
  • 複数の変数を組み合わせて複雑な計算ができる
  • わかりやすい変数名をつけることが重要

覚えておくべきポイント

  1. 変数を使うと意味が明確になる
  2. 変数を使うと変更が簡単になる
  3. 計算結果は変数に保存する
  4. 文字列連結では括弧に注意する
  5. コメントを使ってコードを説明する
