✅ Lesson 009: 文字の連結 - 解答例

String Concatenation Solutions - 詳細な解説とバリエーション

1課題1：基本の名前合成

📖 課題の内容

自分の名字と名前を変数に保存し、フルネームを作成して表示します。

// 課題1：基本の名前合成
let firstName = "山田";
let lastName = "太郎";
let fullName = firstName + lastName;

console.log("名字：" + firstName);
console.log("名前：" + lastName);
console.log("フルネーム：" + fullName);
🖥️ 実行結果（コンソール）：
名字：山田
名前：太郎
フルネーム：山田太郎

🔄 実行の流れ

  1. firstNameに"山田"を保存
  2. lastNameに"太郎"を保存
  3. firstName + lastNameで"山田"と"太郎"を連結
  4. 結果の"山田太郎"をfullNameに保存
  5. それぞれの値をconsole.logで順番に表示
🔑 重要ポイント：
  • 文字列は必ず"（ダブルクォーテーション）で囲む
  • +演算子で2つの文字列を1つにつなげることができる
  • 連結した結果は新しい変数に保存できる

2課題2：挨拶文の作成

📖 課題の内容

名前と時間帯を変数に保存し、挨拶文を作成します。

// 課題2：挨拶文の作成
let name = "山田";
let timeOfDay = "朝";
let greeting = name + "さん、おはようございます。";

console.log(greeting);
🖥️ 実行結果：
山田さん、おはようございます。

🔄 実行の流れ

  1. nameに"山田"を保存
  2. timeOfDayに"朝"を保存（今回は使用しない例）
  3. name + "さん、おはようございます。"で文字列を連結
  4. 結果をgreetingに保存
  5. 挨拶文を表示
🔑 重要ポイント： 変数と固定の文字列を組み合わせることで、カスタマイズされた文章を作ることができます！

3課題3：プロフィール文の作成

📖 課題の内容

複数の情報を変数に保存し、1つのプロフィール文章にまとめます。

// 課題3：プロフィール文の作成
let name = "山田太郎";
let age = 25;
let hometown = "東京";
let hobby = "読書";

let profile = name + "は" + age + "歳で、" + hometown + "出身です。趣味は" + hobby + "です。";
console.log(profile);
🖥️ 実行結果：
山田太郎は25歳で、東京出身です。趣味は読書です。

🔄 実行の流れ

  1. 4つの変数（name, age, hometown, hobby）に値を保存
  2. これらの変数と接続詞の文字列を+演算子で連結
  3. 数値のage（25）は自動的に文字列"25"に変換される
  4. 完成したプロフィール文をprofileに保存
  5. console.logで表示
🔑 重要ポイント： 数値（age）を+演算子で文字列と連結すると、JavaScriptが自動的に数値を文字列に変換してくれます！

4課題4：家族の名前合成

📖 課題の内容

3人の家族の名字と名前を変数に保存し、それぞれのフルネームと全員の名前を表示します。

// 課題4：家族の名前合成
let person1First = "山田";
let person1Last = "太郎";
let person1Full = person1First + person1Last;

let person2First = "山田";
let person2Last = "花子";
let person2Full = person2First + person2Last;

let person3First = "山田";
let person3Last = "次郎";
let person3Full = person3First + person3Last;

console.log("家族1：" + person1Full);
console.log("家族2：" + person2Full);
console.log("家族3：" + person3Full);

let allNames = person1Full + "、" + person2Full + "、" + person3Full;
console.log("全員：" + allNames);
🖥️ 実行結果：
家族1：山田太郎
家族2：山田花子
家族3：山田次郎
全員：山田太郎、山田花子、山田次郎

🔄 実行の流れ

  1. 3人分の名字と名前を6つの変数に保存
  2. それぞれの名字と名前を連結してフルネームを作成
  3. 各フルネームを個別に表示
  4. 3つのフルネームをカンマ（、）で区切って連結
  5. 全員の名前を1行で表示
🔑 重要ポイント： カンマ（、）や句読点も文字列として連結できます。複数の名前をリストとして表示する際に便利です！

5課題5：計算と連結の組み合わせ

📖 課題の内容

生まれ年と現在の年を変数に保存し、年齢を計算して文章を作成します。

// 課題5：計算と連結の組み合わせ
let birthYear = 1998;
let currentYear = 2025;
let age = currentYear - birthYear; // 2025 - 1998 = 27

let message = "私は" + birthYear + "年生まれで、今年" + age + "歳になります。";
console.log(message);
🖥️ 実行結果：
私は1998年生まれで、今年27歳になります。

🔄 実行の流れ

  1. birthYearに1998を保存（数値）
  2. currentYearに2025を保存（数値）
  3. currentYear - birthYearで年齢を計算（2025 - 1998 = 27）
  4. 計算結果をageに保存
  5. 文字列と数値を+演算子で連結して文章を作成
  6. 完成した文章を表示
🔑 重要ポイント：
  • 計算（-演算子）：数値同士の計算は算術演算になる
  • 連結（+演算子）：文字列が含まれると連結になる
  • この課題では、計算してから連結する2段階の処理を行っています

❌ よくある間違いと修正方法

間違い1：クォーテーションの忘れ

❌ let name = 山田太郎;

問題点： 文字列をクォーテーションで囲んでいないため、JavaScriptは「山田太郎」を変数名だと解釈しようとしてエラーになります。

✅ let name = "山田太郎";

修正方法： 文字列は必ず"（ダブルクォーテーション）または'（シングルクォーテーション）で囲みます。

間違い2：スペースの入れ忘れ

❌ let greeting = "Hello" + "World";
console.log(greeting); // "HelloWorld"（スペースなし）

問題点： 文字列を連結しただけでは、自動的にスペースは入りません。

✅ let greeting = "Hello" + " " + "World";
console.log(greeting); // "Hello World"（スペースあり）

修正方法： スペースが必要な場合は、" "（スペース1文字を含む文字列）を明示的に連結します。

間違い3：数値を文字列として保存してしまう

❌ let birthYear = "1998"; // 文字列
let currentYear = "2025"; // 文字列
let age = currentYear - birthYear; // 計算はできるが混乱の元

問題点： 数値を文字列として保存すると、+演算子を使ったときに連結になってしまいます。

let a = "10";
let b = "20";
console.log(a + b); // "1020" （連結）← 期待していた30ではない！
✅ let birthYear = 1998; // 数値
let currentYear = 2025; // 数値
let age = currentYear - birthYear; // 正しく計算される

修正方法： 計算に使う値は、クォーテーションなしで数値として保存します。

間違い4：変数名のスペルミス

❌ let firstName = "山田";
let lastName = "太郎";
let fullName = firstNme + lastName; // firstNmeはタイポ

問題点： firstNameをfirstNmeと間違えてタイプしています。存在しない変数を参照しようとしてエラーになります。

✅ let firstName = "山田";
let lastName = "太郎";
let fullName = firstName + lastName; // 正しいスペル

修正方法： 変数名は正確にタイプします。コピー＆ペーストを活用するのも良い方法です。

間違い5：+演算子の前後にスペースがない（読みにくい）

❌ let fullName = firstName+lastName; // 動くけど読みにくい

問題点： 動作には問題ありませんが、+演算子の前後にスペースがないとコードが読みにくくなります。

✅ let fullName = firstName + lastName; // 読みやすい

修正方法： +演算子の前後には半角スペースを入れると、コードの可読性が向上します。

📊 +演算子の動作比較

オペランドの型 演算子 結果 例
数値 + 数値 + 足し算（計算） 10 + 20 = 30
文字列 + 文字列 + 連結 "Hello" + "World" = "HelloWorld"
文字列 + 数値 + 連結（数値→文字列変換） "合計:" + 100 = "合計:100"
数値 + 文字列 + 連結（数値→文字列変換） 100 + "円" = "100円"

📚 まとめ

今回学んだ重要なポイント

  • 文字列の連結：+演算子を使って複数の文字列を1つにつなげることができる
  • +演算子の2つの役割：数値の場合は足し算、文字列が含まれる場合は連結
  • 自動型変換：文字列と数値を+で連結すると、数値が自動的に文字列に変換される
  • 変数の活用：変数に保存された値も+で連結できる
  • スペースの挿入：" "（スペースを含む文字列）を使って単語の間にスペースを入れられる
  • 複雑な文章の構築：複数の変数と文字列を組み合わせて、意味のある文章を作れる
