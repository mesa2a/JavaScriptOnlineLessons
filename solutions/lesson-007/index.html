レッスン7：値を保存する - 解答

📝 課題1：基本の変数作成 - 解答

基本の解答

let name = "山田太郎"; let age = 25; let color = "青"; console.log(name); console.log(age); console.log(color);

📖 コードの説明

1行目： let name = "山田太郎";

  • let - 変数を作るためのキーワード
  • name - 変数の名前（自由に決められる）
  • = - 代入演算子（右の値を左の変数に入れる）
  • "山田太郎" - 文字列の値（必ずクォーテーションで囲む）
  • ; - 命令の終わりを示す

2行目： let age = 25;

  • 数値を保存する場合は、クォーテーションをつけない
  • 25は数値なので、そのまま書く

3行目： let color = "青";

  • 色の名前も文字列なので、クォーテーションで囲む

5〜7行目： console.log()で出力

  • 変数名を書くと、その変数に保存されている値が取り出される
  • console.log(name) → 「山田太郎」と表示される
  • クォーテーションはつけない（console.log("name")とすると、「name」という文字列が表示される）

🖥️ コンソール出力

山田太郎
25
青

バリエーション例

例1：別の自己紹介

let name = "佐藤花子"; let age = 30; let color = "赤"; console.log(name); console.log(age); console.log(color);

例2：英語の名前

let name = "John Smith"; let age = 22; let color = "green"; console.log(name); console.log(age); console.log(color);

例3：小数点を含む年齢

let name = "田中次郎"; let age = 25.5; // 小数点も使える let color = "黄色"; console.log(name); console.log(age); console.log(color);

📝 課題2：5つの変数を作成 - 解答

基本の解答

let name = "山田太郎"; let age = 25; let birthplace = "東京"; let occupation = "エンジニア"; let dream = "世界一周"; console.log(name); console.log(age); console.log(birthplace); console.log(occupation); console.log(dream);

📖 コードの説明

変数の宣言部分（1〜5行目）：

  • name - 文字列なのでクォーテーションで囲む
  • age - 数値なのでクォーテーションなし
  • birthplace - 文字列（キャメルケースを使用）
  • occupation - 文字列（職業）
  • dream - 文字列（夢）

出力部分（7〜11行目）：

  • 5つの変数を順番に出力
  • 変数名だけを書く（クォーテーションはつけない）

🖥️ コンソール出力

山田太郎
25
東京
エンジニア
世界一周

💡 ポイント

  • 文字列：name, birthplace, occupation, dream → クォーテーション必要
  • 数値：age → クォーテーション不要
  • 変数名：キャメルケース（birthplace, occupation）を使用

バリエーション例

例1：学生の場合

let name = "鈴木一郎"; let age = 18; let birthplace = "大阪"; let occupation = "高校3年生"; let dream = "医者になる"; console.log(name); console.log(age); console.log(birthplace); console.log(occupation); console.log(dream);

例2：社会人の場合

let name = "田中美咲"; let age = 32; let birthplace = "福岡"; let occupation = "デザイナー"; let dream = "独立して会社を作る"; console.log(name); console.log(age); console.log(birthplace); console.log(occupation); console.log(dream);

例3：英語版

let name = "Emily Johnson"; let age = 28; let birthplace = "New York"; let occupation = "Teacher"; let dream = "Write a book"; console.log(name); console.log(age); console.log(birthplace); console.log(occupation); console.log(dream);

📝 課題3：数値の変数を作成 - 解答

基本の解答

let temperature = 20; let height = 170; let favoriteNumber = 7; let sleepHours = 7; console.log(temperature); console.log(height); console.log(favoriteNumber); console.log(sleepHours);

📖 コードの説明

すべて数値の変数：

  • temperature - 気温（20度）
  • height - 身長（170cm）
  • favoriteNumber - 好きな数字（7）
  • sleepHours - 睡眠時間（7時間）

重要ポイント：

  • すべて数値なので、クォーテーションをつけない
  • 変数名はキャメルケースを使用（favoriteNumber, sleepHours）

🖥️ コンソール出力

20
170
7
7

🚨 よくある間違い

❌ 間違い
let temperature = "20"; // 文字列になる let height = "170"; // 文字列になる

クォーテーションをつけると文字列になり、計算ができなくなります。

✅ 正しい
let temperature = 20; // 数値 let height = 170; // 数値

数値はそのまま書く。後で計算に使えます。

バリエーション例

例1：小数点を含む数値

let temperature = 23.5; let height = 165.3; let favoriteNumber = 3.14; let sleepHours = 7.5; console.log(temperature); console.log(height); console.log(favoriteNumber); console.log(sleepHours);

例2：大きな数値

let temperature = 35; let height = 180; let favoriteNumber = 777; let sleepHours = 8; console.log(temperature); console.log(height); console.log(favoriteNumber); console.log(sleepHours);

例3：負の数

let temperature = -5; // マイナス5度 let height = 155; let favoriteNumber = -10; // 負の数も使える let sleepHours = 6; console.log(temperature); console.log(height); console.log(favoriteNumber); console.log(sleepHours);

📝 課題4：alertで自己紹介 - 解答

基本の解答

let name = "山田太郎"; let age = 25; let birthplace = "東京"; let occupation = "エンジニア"; let dream = "世界一周"; alert(name); alert(age); alert(birthplace); alert(occupation); alert(dream);

📖 コードの説明

変数の宣言（1〜5行目）：

  • 課題2と同じ5つの変数を作成

alertで表示（7〜11行目）：

  • console.log()の代わりにalert()を使用
  • 変数名だけを書く（クォーテーションなし）
  • 5つのポップアップが順番に表示される
  • OKを押すたびに次の変数の値が表示される

🖥️ 実行結果

  1. 1つ目のポップアップ： 「山田太郎」 → OKを押す
  2. 2つ目のポップアップ： 「25」 → OKを押す
  3. 3つ目のポップアップ： 「東京」 → OKを押す
  4. 4つ目のポップアップ： 「エンジニア」 → OKを押す
  5. 5つ目のポップアップ： 「世界一周」 → OKを押す

バリエーション例

例1：説明付きで表示

let name = "山田太郎"; let age = 25; let birthplace = "東京"; let occupation = "エンジニア"; let dream = "世界一周"; alert("名前: " + name); alert("年齢: " + age); alert("出身地: " + birthplace); alert("職業: " + occupation); alert("夢: " + dream);

説明： 文字列と変数を+でつなげることで、説明付きで表示できます。

例2：まとめて表示

let name = "山田太郎"; let age = 25; let birthplace = "東京"; let occupation = "エンジニア"; let dream = "世界一周"; alert("私は" + name + "です。" + age + "歳です。");

説明： 複数の変数と文字列を組み合わせて、1つのalertで表示できます。

例3：console.logとalertの両方を使う

let name = "山田太郎"; let age = 25; let birthplace = "東京"; let occupation = "エンジニア"; let dream = "世界一周"; // コンソールにも出力 console.log("名前:", name); console.log("年齢:", age); // alertでも表示 alert("私は" + name + "です。"); alert(age + "歳です。");

説明： デバッグ用にconsole.log()、ユーザー向けにalert()を使い分けることができます。

❌ よくある間違いと修正方法

間違い1：文字列のクォーテーションを忘れる

❌ 間違ったコード

let name = 山田太郎; // クォーテーションがない

エラー： 「山田太郎」が変数として扱われ、エラーになる

✅ 正しいコード

let name = "山田太郎"; // クォーテーションで囲む

文字列は必ずクォーテーションで囲む！

間違い2：数値をクォーテーションで囲む

❌ 間違ったコード

let age = "25"; // 文字列になる

問題： 数値ではなく文字列になり、計算ができなくなる

✅ 正しいコード

let age = 25; // 数値

数値はクォーテーションをつけない！

間違い3：letを忘れる

❌ 間違ったコード

name = "山田太郎"; // letがない

問題： 動くこともあるが、推奨されない。意図しない動作を引き起こす可能性がある

✅ 正しいコード

let name = "山田太郎"; // letをつける

変数を作るときは必ずletをつける！

間違い4：変数名に数字で始める

❌ 間違ったコード

let 1name = "山田太郎"; // 数字で始まっている

エラー： 変数名は数字で始めることができない

✅ 正しいコード

let name1 = "山田太郎"; // 数字は後ろにつける let userName = "山田太郎"; // または英字のみ

変数名は英字またはアンダースコアで始める！

間違い5：変数名にスペースを入れる

❌ 間違ったコード

let user name = "山田太郎"; // スペースが入っている

エラー： 変数名にスペースは使えない

✅ 正しいコード

let userName = "山田太郎"; // キャメルケース let user_name = "山田太郎"; // アンダースコア

複数の単語はキャメルケースまたはアンダースコアでつなぐ！

間違い6：console.logで変数名をクォーテーションで囲む

❌ 間違ったコード

let name = "山田太郎"; console.log("name"); // クォーテーションで囲んでいる

出力： 「name」という文字列が表示される（変数の値ではない）

✅ 正しいコード

let name = "山田太郎"; console.log(name); // クォーテーションなし

出力： 「山田太郎」という変数の値が表示される

変数の値を表示するときは、クォーテーションをつけない！

🎓 まとめ

変数とは

変数は、データを保存しておく箱のようなもの。一度保存した値は、何度でも取り出して使うことができます。

変数の作り方

let 変数名 = 値;
  • let - 変数を作るキーワード
  • 変数名 - 自由に決められる（ルールあり）
  • = - 代入演算子
  • 値 - 保存したいデータ

文字列と数値の違い

種類 書き方 例
文字列 クォーテーションで囲む "山田太郎", "東京"
数値 そのまま書く 25, 170, 23.5

命名規則

  • ✅ 英字、数字、アンダースコア、ドル記号が使える
  • ❌ 数字で始めることはできない
  • ❌ スペースは使えない
  • ❌ 予約語は使えない
  • ✅ キャメルケースが推奨（firstName, userName）

覚えておくべきポイント

  1. 変数を作るときはletをつける
  2. 文字列は必ずクォーテーションで囲む
  3. 数値はクォーテーションをつけない
  4. 変数の値を表示するときはクォーテーションをつけない
  5. 変数名はわかりやすい名前をつける
  6. 複数の単語はキャメルケースを使う
