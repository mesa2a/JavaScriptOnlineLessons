# 予算管理アプリ設計書

## 1. プロジェクト概要

### 目的
日々の収入と支出を記録し、家計の状況を可視化するWebアプリケーション。
シンプルで使いやすいインターフェースで、誰でも簡単に家計管理ができるようにする。

### 主な機能
- 収入・支出の登録、編集、削除
- カテゴリ別の自動分類
- グラフでの可視化（円グラフ、棒グラフ）
- 統計情報の表示（合計、平均、収支）
- データの永続化（localStorage）
- データのエクスポート・インポート（CSV、JSON）

### 想定ユーザー
- 家計簿をつけたい個人
- お小遣いを管理したい学生
- 副業の収支を管理したいフリーランス

|  │ 日付: [2025-11-23] 📅               │

|  │ メモ: [________]                     │

|                                          |

### タブごとの内容

**収入タブ**
- 収入入力フォーム
- 収入一覧（新しい順）
- 収入の合計金額

**支出タブ**
- 支出入力フォーム
- 支出一覧（新しい順）
- 支出の合計金額

**統計タブ**
- 収支のサマリー
- カテゴリ別円グラフ
- 月別棒グラフ
- カテゴリ別内訳テーブル

**設定タブ**
- データのエクスポート（CSV、JSON）
- データのインポート
- カテゴリの管理
- データの全削除

### 色とデザインの方針

**色の使い方**
- 収入: #4CAF50（緑色）
- 支出: #F44336（赤色）
- 収支プラス: #4CAF50（緑色）
- 収支マイナス: #F44336（赤色）
- 背景: #FFFFFF（白）
- テキスト: #333333（濃いグレー）

**デザインの方針**
- シンプルで見やすい
- 重要な情報（収支）は大きく表示
- ボタンは押しやすいサイズ
- カテゴリは色分けして識別しやすく
- 余白を十分に取る

## 4. データ構造

### トランザクション（取引）データ

1件の取引データの形式：

```javascript
{
  id: 1,                           // 一意なID（数値、自動生成）
  type: 'income',                  // 種類: 'income'（収入）または 'expense'（支出）
  amount: 250000,                  // 金額（数値、円単位）
  date: '2025-11-20',             // 日付（文字列、YYYY-MM-DD形式）
  category: '給料',                // カテゴリ名（文字列）
  memo: '11月分の給料'             // メモ（文字列、任意）
}
```

### カテゴリデータ

**収入のカテゴリ**

### localStorageでの保存

```javascript
// 保存
localStorage.setItem('transactions', JSON.stringify(transactions));

// 読み込み
const savedData = localStorage.getItem('transactions');
const transactions = savedData ? JSON.parse(savedData) : [];
```

## 5. 技術スタック

### 使用技術
- **HTML5**: 構造とセマンティクス
- **CSS3**: スタイリングとレイアウト（Flexbox、Grid）
- **JavaScript（ES6+）**: ロジックとDOM操作
- **localStorage**: データの永続化
- **Canvas API**: グラフ描画（円グラフ、棒グラフ）
- **File API**: CSVファイルのエクスポート・インポート

### 使用しないもの（シンプルに保つため）
- ライブラリ・フレームワーク（React、Vue等）
- バックエンドサーバー
- データベース
- 外部APIとの連携

## 6. 主要な関数の設計

### データ管理
- `addTransaction(type, amount, date, category, memo)` - 取引を追加
- `deleteTransaction(id)` - 取引を削除
- `editTransaction(id, newData)` - 取引を編集
- `getTransactions()` - すべての取引を取得
- `getTransactionsByType(type)` - 種類でフィルター
- `getTransactionsByMonth(year, month)` - 月でフィルター
- `saveTransactions()` - localStorageに保存
- `loadTransactions()` - localStorageから読み込み

### 統計計算
- `calculateTotalIncome()` - 収入合計を計算
- `calculateTotalExpense()` - 支出合計を計算
- `calculateBalance()` - 収支を計算
- `calculateByCategory(type)` - カテゴリ別集計
- `calculateByMonth()` - 月別集計

### 表示
- `renderTransactions(transactions)` - 取引一覧を表示
- `renderStats()` - 統計情報を表示
- `renderPieChart(data)` - 円グラフを描画
- `renderBarChart(data)` - 棒グラフを描画

### ユーティリティ
- `generateId()` - 新しいIDを生成
- `formatCurrency(amount)` - 金額をフォーマット（¥1,000）
- `formatDate(date)` - 日付をフォーマット
- `getCategoryColor(category)` - カテゴリの色を取得
