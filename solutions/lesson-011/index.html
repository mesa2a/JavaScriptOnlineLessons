✅ 課題1：基本のカウンター

解答例

let counter = 0;

counter = counter + 1;
console.log("カウント：" + counter);

counter = counter + 1;
console.log("カウント：" + counter);

counter = counter + 1;
console.log("カウント：" + counter);

counter = counter + 1;
console.log("カウント：" + counter);

counter = counter + 1;
console.log("カウント：" + counter);
カウント：1
カウント：2
カウント：3
カウント：4
カウント：5

📖 詳しい解説

カウンターの値の変化

let counter = 0 0
counter = counter + 1 // 0 + 1 1
counter = counter + 1 // 1 + 1 2
counter = counter + 1 // 2 + 1 3
counter = counter + 1 // 3 + 1 4
counter = counter + 1 // 4 + 1 5

ポイント1：カウンターは let で宣言します。値が変わるからです。

ポイント2：counter = counter + 1 は、「現在の値に1を足して、その結果をcounterに保存する」という意味です。

ポイント3：各ステップでcounterの値が1ずつ増えていきます。

🎯 重要：counter = counter + 1 は、プログラミングで最もよく使うパターンの一つです。しっかり理解しましょう！

✅ 課題2：上限付きカウンター

解答例

const maxCount = 10;
let counter = 0;

counter = counter + 1;
console.log(counter + " / " + maxCount);

counter = counter + 1;
console.log(counter + " / " + maxCount);

counter = counter + 1;
console.log(counter + " / " + maxCount);
1 / 10
2 / 10
3 / 10

📖 詳しい解説

ステップ1：上限を定義
const maxCount = 10;

上限値は変わらないので、const を使います。

ステップ2：カウンターを初期化
let counter = 0;

カウンターは値が変わるので、let を使います。

ステップ3：カウントアップと表示
counter = counter + 1;
console.log(counter + " / " + maxCount);

「現在のカウント / 上限」の形式で表示します。

🎯 使い分けのコツ：
  • const maxCount = 10 → 上限は変わらない → const
  • let counter = 0 → カウンターは変わる → let

✅ 課題3：合計計算

解答例

let total = 0;

total = total + 500;
console.log("追加後の合計：" + total + "円");

total = total + 300;
console.log("追加後の合計：" + total + "円");

total = total + 700;
console.log("追加後の合計：" + total + "円");

console.log("最終合計：" + total + "円");
追加後の合計：500円
追加後の合計：800円
追加後の合計：1500円

📖 詳しい解説

totalの値の変化

let total = 0 0円
total = total + 500 // 0 + 500 500円
total = total + 300 // 500 + 300 800円
total = total + 700 // 800 + 700 1500円

ポイント1：total = total + 金額 のパターンで合計を累積していきます。

ポイント2：totalは値が変わっていくので、let を使います。

ポイント3：このパターンは、買い物カゴの合計計算などでよく使います。

✅ 課題4：カウントダウン

解答例

const initialCount = 10;
let counter = initialCount;

console.log("開始：" + counter);

counter = counter - 1;
console.log(counter);

counter = counter - 1;
console.log(counter);

counter = counter - 1;
console.log(counter);

console.log("残り：" + counter);
開始：10
9
8
7
残り：7

📖 詳しい解説

カウントダウンの流れ

const initialCount = 10 初期値
let counter = initialCount 10
counter = counter - 1 // 10 - 1 9
counter = counter - 1 // 9 - 1 8
counter = counter - 1 // 8 - 1 7

ポイント1：初期値 initialCount は変わらないので、const を使います。

ポイント2：counter = counter - 1 で値を1ずつ減らします。

ポイント3：増やすときは + 1、減らすときは - 1 を使います。

✅ 課題5：適切な使い分け

解答例

const taxRate = 1.1;
const price1 = 200;
const price2 = 350;

let total = 0;

total = total + price1;
console.log("商品1追加：" + total + "円");

total = total + price2;
console.log("商品2追加：" + total + "円");

const totalWithTax = total * taxRate;
console.log("税込合計：" + totalWithTax + "円");
商品1追加：200円
商品2追加：550円
税込合計：605円

📖 詳しい解説：なぜこの使い分けなのか

変数名 使ったキーワード 理由
taxRate const 消費税率は固定値。プログラムの中で変更しない。
price1 const 商品価格は決まっている。変更しない。
price2 const 商品価格は決まっている。変更しない。
total let 合計は商品を追加するたびに変わる。
totalWithTax const 一度計算したら、その後変更しない。
🎯 判断基準：

「この値は後で変わる？」と自分に聞いてみましょう。

  • 変わる → let
  • 変わらない → const

🎨 応用例と発展的な使い方

応用例1：ポイント計算システム

// 設定値（変わらない）
const pointRate = 0.05; // 5%還元
const bonusThreshold = 1000; // ボーナス発生の金額
const bonusPoints = 50;

// 変わる値
let purchaseAmount = 0;
let totalPoints = 0;

// 商品購入
purchaseAmount = purchaseAmount + 800;
let earnedPoints1 = purchaseAmount * pointRate;
totalPoints = totalPoints + earnedPoints1;
console.log("購入額：" + purchaseAmount + "円、獲得ポイント：" + earnedPoints1);

// さらに購入
purchaseAmount = purchaseAmount + 500;
let earnedPoints2 = 500 * pointRate;
totalPoints = totalPoints + earnedPoints2;
console.log("購入額：" + purchaseAmount + "円、獲得ポイント：" + earnedPoints2);

// ボーナスチェック
if (purchaseAmount >= bonusThreshold) {
    totalPoints = totalPoints + bonusPoints;
    console.log("ボーナス" + bonusPoints + "ポイント獲得！");
}

console.log("合計購入額：" + purchaseAmount + "円");
console.log("合計ポイント：" + totalPoints);

解説：還元率やボーナス設定は固定値なので const、購入額とポイントは変わるので let を使います。

応用例2：試験の採点システム

// 設定値
const totalQuestions = 10;
const passingScore = 6;

// 変わる値
let correctAnswers = 0;

// 問題に答えていく
correctAnswers = correctAnswers + 1; // 問題1：正解
correctAnswers = correctAnswers + 1; // 問題2：正解
// 問題3は不正解（カウントしない）
correctAnswers = correctAnswers + 1; // 問題4：正解
correctAnswers = correctAnswers + 1; // 問題5：正解

console.log("正解数：" + correctAnswers + " / " + totalQuestions);

// 計算結果（一度計算したら変わらない）
const scorePercentage = (correctAnswers / totalQuestions) * 100;

console.log("得点率：" + scorePercentage + "%");

if (correctAnswers >= passingScore) {
    console.log("合格！");
} else {
    console.log("不合格...");
}

解説：問題数と合格ラインは固定値、正解数は変わる値です。得点率は一度計算したら変わらないので const です。

応用例3：在庫管理システム

// 設定値
const maxStock = 100; // 最大在庫数
const reorderPoint = 20; // 発注ポイント

// 変わる値
let currentStock = 50;

console.log("初期在庫：" + currentStock + " / " + maxStock);

// 販売
currentStock = currentStock - 15;
console.log("販売後：" + currentStock + " / " + maxStock);

currentStock = currentStock - 20;
console.log("販売後：" + currentStock + " / " + maxStock);

// 在庫チェック
if (currentStock <= reorderPoint) {
    console.log("⚠️ 在庫が少なくなりました。発注してください。");
}

// 入荷
const incomingStock = 30;
currentStock = currentStock + incomingStock;
console.log("入荷後：" + currentStock + " / " + maxStock);

解説：最大在庫数と発注ポイントは固定、現在の在庫は変わります。入荷数も一度決めたら変わらないので const です。

応用例4：ゲームのスコアシステム

// 設定値
const comboBonus = 5;
const perfectBonus = 10;
const targetScore = 100;

// 変わる値
let score = 0;
let comboCount = 0;

console.log("ゲーム開始！ 目標スコア：" + targetScore);

// プレイ1
score = score + 10;
comboCount = comboCount + 1;
console.log("スコア：" + score + "、コンボ：" + comboCount);

// プレイ2（コンボ継続）
score = score + 10;
comboCount = comboCount + 1;
score = score + comboBonus; // コンボボーナス
console.log("スコア：" + score + "（コンボボーナス+" + comboBonus + "）、コンボ：" + comboCount);

// プレイ3（パーフェクト）
score = score + 10;
comboCount = comboCount + 1;
score = score + perfectBonus; // パーフェクトボーナス
console.log("スコア：" + score + "（パーフェクトボーナス+" + perfectBonus + "）、コンボ：" + comboCount);

// 結果
const finalScore = score;
const achievement = (finalScore / targetScore) * 100;
console.log("最終スコア：" + finalScore + " / " + targetScore);
console.log("達成率：" + achievement + "%");

解説：ボーナスポイントや目標は固定、スコアとコンボ数は変わります。最終スコアと達成率は計算後変わらないので const です。

応用例5：タイマーとカウントダウン

// 設定値
const startTime = 60; // 60秒
const warningTime = 10; // 警告を出す残り時間

// 変わる値
let remainingTime = startTime;

console.log("タイマー開始：" + remainingTime + "秒");

// 時間経過
remainingTime = remainingTime - 15;
console.log("残り時間：" + remainingTime + "秒");

remainingTime = remainingTime - 20;
console.log("残り時間：" + remainingTime + "秒");

remainingTime = remainingTime - 20;
console.log("残り時間：" + remainingTime + "秒");

// 警告チェック
if (remainingTime <= warningTime) {
    console.log("⏰ あと" + remainingTime + "秒です！");
}

remainingTime = remainingTime - 5;
console.log("残り時間：" + remainingTime + "秒");

if (remainingTime === 0) {
    console.log("⏰ 時間切れ！");
}

解説：開始時間と警告時間は固定、残り時間は変わります。

⚠️ よくある間違いと正しい書き方

間違い1：カウンターにconstを使う

// ❌ 間違い
const counter = 0;
counter = counter + 1; // エラー！Assignment to constant variable
// ✅ 正しい
let counter = 0;
counter = counter + 1; // OK！

理由：カウンターは値が変わるので、let を使う必要があります。

間違い2：上限値にletを使う

// ❌ 良くない（動くけど推奨されない）
let maxCount = 10;
let counter = 0;
// ✅ 良い
const maxCount = 10;
let counter = 0;

理由：変わらない値は const で宣言することで、意図が明確になります。

間違い3：代入を忘れる

// ❌ 間違い
let counter = 0;
counter + 1; // 計算するだけで、代入していない
console.log(counter); // まだ0のまま！
// ✅ 正しい
let counter = 0;
counter = counter + 1; // 代入する
console.log(counter); // 1になっている

理由：counter + 1 だけでは計算結果が保存されません。counter = counter + 1 と代入が必要です。

間違い4：すべての値にletを使う

// ❌ 良くない
let pi = 3.14;
let taxRate = 1.1;
let maxCount = 10;
// ✅ 良い
const pi = 3.14;
const taxRate = 1.1;
const maxCount = 10;

理由：変わらない値は const で宣言することで、うっかり変更してしまうミスを防げます。

間違い5：計算結果をletで宣言する

// ❌ 良くない
const price = 100;
const tax = 1.1;
let total = price * tax; // 計算後は変わらないのに
// ✅ 良い
const price = 100;
const tax = 1.1;
const total = price * tax; // 計算後は変わらない

理由：一度計算したら変わらない値は const で宣言します。

📚 ベストプラクティス

ベストプラクティス1：迷ったらconstを使う

基本的には const で宣言し、再代入が必要になったら let に変えるという順番で考えましょう。

// まずconstで宣言
const value = 10;

// 後で再代入が必要だとわかったら
// constをletに変える

ベストプラクティス2：変数名でconstかletかわかるようにする

変数名を工夫することで、値が変わるかどうかを明確にできます。

// 設定値や上限値はわかりやすい名前に
const MAX_RETRY_COUNT = 3;
const TAX_RATE = 1.1;
const DEFAULT_PRICE = 100;

// カウンターや合計は「変わる」とわかる名前に
let currentCount = 0;
let totalAmount = 0;
let remainingTime = 60;

ベストプラクティス3：関連する変数をまとめて宣言

設定値と変数を分けて宣言すると、コードが読みやすくなります。

// 設定値（const）をまとめる
const maxScore = 100;
const bonusPoint = 10;
const penaltyPoint = 5;

// 変わる値（let）をまとめる
let currentScore = 0;
let attempts = 0;

ベストプラクティス4：マジックナンバーを避ける

直接数値を書くのではなく、定数に名前を付けましょう。

// ❌ マジックナンバー（何の数値かわからない）
let total = price * 1.1;

// ✅ 定数に名前を付ける
const TAX_RATE = 1.1;
let total = price * TAX_RATE;

🎯 まとめ：letとconstの選び方

判断フローチャート

質問1：この値は後で変わる？

→ はい：let を使う（例：counter, total, score）

→ いいえ：const を使う（例：maxCount, taxRate, pi）

質問2：一度計算したら変わらない値？

→ はい：const を使う（例：totalWithTax, finalScore）

迷ったとき：

→ まず const で宣言し、エラーが出たら let に変える

🎉 お疲れさまでした！

letとconstの使い分けは、プログラミングの基本中の基本です。

覚えておくこと：

  • counter = counter + 1 は値を1増やす基本パターン
  • カウンターや合計など、変わる値には let
  • 設定値や上限値など、変わらない値には const
  • 迷ったら const から始める
