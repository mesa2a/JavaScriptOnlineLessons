レッスン6：alertで画面に表示 - 解答

📝 課題1：自己紹介を3コマで表示する - 解答

基本の解答

alert("私の名前は山田太郎です。"); alert("趣味は読書です。"); alert("よろしくお願いします。");

📖 コードの説明

1行目： alert("私の名前は山田太郎です。");

  • alert()は画面にポップアップを表示する命令
  • 括弧の中に表示したい文字列を書く
  • 文字列は必ずクォーテーション（" "）で囲む
  • セミコロン（;）で命令の終わりを示す

2行目と3行目： 同じようにalert()を使う

  • 1つ目のalertでOKを押すと、2つ目のalertが表示される
  • 2つ目のalertでOKを押すと、3つ目のalertが表示される
  • これで「3コマ物語」の完成！

🖥️ 実行結果

  1. 最初のポップアップ： 「私の名前は山田太郎です。」 → OKを押す
  2. 次のポップアップ： 「趣味は読書です。」 → OKを押す
  3. 最後のポップアップ： 「よろしくお願いします。」 → OKを押す
  4. すべてのポップアップが閉じる

バリエーション例

例1：別の自己紹介

alert("私の名前は田中花子です。"); alert("好きな食べ物はカレーです。"); alert("どうぞよろしく！");

例2：趣味の紹介

alert("私は音楽が好きです。"); alert("特にピアノを弾きます。"); alert("一緒に演奏しましょう！");

例3：学校の紹介

alert("私は中学2年生です。"); alert("数学が得意です。"); alert("一緒に勉強しましょう。");

📝 課題2：朝の1日を5コマで表示する - 解答

基本の解答

alert("目が覚めました。"); alert("顔を洗いました。"); alert("朝ごはんを食べました。"); alert("歯を磨きました。"); alert("家を出ました。");

📖 コードの説明

5つのalert()を順番に書くことで、朝のストーリーを表現しています。

  • 各行が1つの行動を表す
  • 上から順番に実行される
  • OKを押すたびに次の行動が表示される
  • まるで短い物語のよう！

💡 ポイント

alert()の順番が大切です。「家を出ました」が最初に来ると、物語がおかしくなります。プログラムは上から順番に実行されることを覚えておきましょう。

バリエーション例

例1：学校の1日

alert("学校に着きました。"); alert("1時間目は国語です。"); alert("お昼ご飯を食べました。"); alert("5時間目は体育です。"); alert("家に帰りました。");

例2：休日の過ごし方

alert("ゆっくり起きました。"); alert("漫画を読みました。"); alert("友達と遊びました。"); alert("夕飯を食べました。"); alert("早く寝ました。");

例3：もっと詳しい朝

alert("6時に目覚ましが鳴りました。"); alert("もう5分だけ寝ました。"); alert("やっと起きました。"); alert("シャワーを浴びました。"); alert("制服を着ました。"); alert("朝ごはんを食べました。"); alert("7時半に家を出ました。");

※ 5コマ以上でもOKです！何コマでも作れます。

📝 課題3：計算物語を作る - 解答

基本の解答

alert("100円持っています。"); alert("50円のお菓子を買いました。"); alert("残りは..."); alert(100 - 50); alert("50円です。");

📖 コードの説明

1行目〜3行目： 文字列（" "で囲む）

  • ストーリーの説明をする部分
  • クォーテーションで囲むので、そのまま表示される

4行目： alert(100 - 50); ← クォーテーションなし！

  • 計算式をそのまま書く
  • クォーテーションで囲まないので、計算される
  • 結果は「50」と表示される

5行目： 締めのメッセージ

  • 「50円です」と答えを確認する

🚨 超重要ポイント

❌ 間違い

alert("100 - 50");

出力：「100 - 50」（文字列）

✅ 正しい

alert(100 - 50);

出力：「50」（計算結果）

クォーテーションの有無で結果が変わります！

バリエーション例

例1：足し算の物語

alert("30円持っています。"); alert("お小遣いで70円もらいました。"); alert("合計は..."); alert(30 + 70); alert("100円になりました！");

例2：掛け算の物語

alert("りんごが1個100円です。"); alert("3個買います。"); alert("合計金額は..."); alert(100 * 3); alert("300円です。");

例3：もっと複雑な計算

alert("500円持っています。"); alert("200円のジュースを買いました。"); alert(500 - 200); alert("残り300円です。"); alert("150円のお菓子をもう1つ買いました。"); alert(300 - 150); alert("最後は150円残りました。");

📝 課題4：confirmを使った確認 - 解答

基本の解答

confirm("この先に進みますか？"); alert("ありがとうございます。");

📖 コードの説明

1行目： confirm("この先に進みますか？");

  • confirm()は確認ダイアログを表示する
  • 「OK」と「キャンセル」の2つのボタンが表示される
  • ユーザーはどちらかを選べる

2行目： alert("ありがとうございます。");

  • confirmの後に実行される
  • 今のところ、「OK」でも「キャンセル」でも実行される
  • 後のレッスンで、選択によって動作を変える方法を学びます

🖥️ 実行結果

  1. confirmが表示される： 「この先に進みますか？」（OKとキャンセルボタン）
  2. ユーザーがボタンを押す： OKでもキャンセルでもどちらでもOK
  3. alertが表示される： 「ありがとうございます。」

バリエーション例

例1：クイズの確認

confirm("1 + 1 = 2 ですか？"); alert("正解です！");

例2：年齢の確認

confirm("あなたは13歳以上ですか？"); alert("ご利用ありがとうございます。");

例3：複数の確認

confirm("準備はいいですか？"); alert("では始めます。"); confirm("続けますか？"); alert("ありがとうございました。");

💡 今後の学習ポイント

後のレッスンで、confirm()の結果（OKかキャンセルか）を使って、異なる動作をする方法を学びます。例えば：

  • OKを押したら → 「次へ進みます」
  • キャンセルを押したら → 「中止します」

これは「条件分岐」という概念で、プログラミングの重要な基礎です。楽しみにしていてください！

❌ よくある間違いと修正方法

間違い1：クォーテーションを忘れる

❌ 間違ったコード

alert(こんにちは);

エラー： 「こんにちは」が変数として扱われ、エラーになる

✅ 正しいコード

alert("こんにちは");

文字列は必ずクォーテーションで囲む！

間違い2：計算式を文字列にしてしまう

❌ 間違ったコード

alert("100 - 50");

出力： 「100 - 50」（文字列として表示される）

✅ 正しいコード

alert(100 - 50);

出力： 「50」（計算結果が表示される）

計算させたい場合はクォーテーションをつけない！

間違い3：セミコロンを忘れる

❌ 間違ったコード

alert("こんにちは") alert("元気ですか")

問題： 動くこともあるが、推奨されない書き方

✅ 正しいコード

alert("こんにちは"); alert("元気ですか");

各行の最後にセミコロン（;）をつける習慣をつけよう！

間違い4：全角文字を使う

❌ 間違ったコード

alert("こんにちは");

エラー： 全角の括弧やセミコロンを使うとエラーになる

✅ 正しいコード

alert("こんにちは");

括弧（）やセミコロン（;）は必ず半角で書く！

間違い5：alertのスペルミス

❌ 間違ったコード

alart("こんにちは"); // 「alart」は間違い Alert("こんにちは"); // 大文字の「Alert」も間違い

エラー： 関数が見つからずエラーになる

✅ 正しいコード

alert("こんにちは");

必ず小文字で「alert」と書く！

🎓 まとめ

alert()とconfirm()の違い

alert()

  • 目的： メッセージを表示
  • ボタン： OKのみ
  • 用途： お知らせ、警告
  • 例： 「保存しました」

confirm()

  • 目的： 確認をとる
  • ボタン： OKとキャンセル
  • 用途： ユーザーの選択
  • 例： 「削除しますか？」

console.log()との使い分け

  • console.log() → プログラマー向け（開発中のデバッグ）
  • alert() → ユーザー向け（実際のアプリで使う）
  • confirm() → ユーザーに確認（削除、送信など重要な操作の前）

覚えておくべきポイント

  1. 文字列は必ずクォーテーション（" "）で囲む
  2. 計算させたい場合はクォーテーションをつけない
  3. 各行の最後にセミコロン（;）をつける
  4. 括弧やセミコロンは必ず半角
  5. alert()はOKを押すまで次に進まない
  6. 複数のalert()でストーリーが作れる
