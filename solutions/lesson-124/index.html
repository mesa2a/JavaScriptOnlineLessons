即時実行関数（IIFE）

Immediately Invoked Function Expression

(function() { })(); - 定義と同時に実行

1. 基本形

(function() { console.log('即時実行されました'); })();
コンソールを確認してください

2. アプリの初期化

(function() { const appName = 'マイアプリ'; const version = '1.0.0'; // 初期化処理... })();

3. 引数を渡す

(function(name, age) { console.log(name + 'さんは' + age + '歳'); })('太郎', 25);
コンソールを確認してください

4. 戻り値を使う

const result = (function(a, b) { return a + b; })(10, 20); console.log(result); // 30

5. プライベート変数を持つカウンター

const counter = (function() { let count = 0; // プライベート変数 return { increment: function() { count++; return count; }, decrement: function() { count--; return count; }, getValue: function() { return count; } }; })();
カウント: 0
