# 教材生成スキル テストケース

## テスト1: 基本的な教材生成

**入力:**
- レッスン番号: 1
- カリキュラムファイル: curriculum.md

**期待される出力ファイル:** `lessons/lesson-001.md`

**期待される内容:**
- [ ] YAMLフロントマターが存在する
  - [ ] title: "Lesson 001: ブラウザと友達になる"
  - [ ] author: "JavaScript学習教材"
  - [ ] date: 生成日（YYYY-MM-DD形式）
- [ ] 「今回の学習」セクションが存在する
  - [ ] 前回の復習（レッスン1なので「はじめてのレッスン」等）
  - [ ] 今回のゴール（3つ以上）
  - [ ] なぜこれを学ぶか
- [ ] 概念説明セクションが存在する
  - [ ] 【知識】に基づいた概念説明
  - [ ] 具体例
  - [ ] コード例（curriculum.mdの□項目に基づく）
  - [ ] 重要ポイント（3つ以上）
- [ ] 確認問題セクションが存在する
  - [ ] 基礎課題（✅成果物に基づく）
  - [ ] 手順（□項目に基づく）
  - [ ] コードを書くスペース
  - [ ] ヒント
  - [ ] 解答例と解説
- [ ] まとめセクションが存在する
  - [ ] キーポイント（3つ以上）

---

## テスト2: 中盤レッスンの教材生成

**入力:**
- レッスン番号: 13
- カリキュラムファイル: curriculum.md

**期待される出力ファイル:** `lessons/lesson-013.md`

**期待される内容:**
- [ ] 前回の復習が「レッスン12：今週の復習」の内容を参照
- [ ] 【知識】DOM（Document Object Model）とは、要素の取得 に基づいた概念説明
- [ ] ✅ 成果物：要素の取得成功 に基づいた確認問題

## テスト3: エラーケース

**入力:**
- レッスン番号: 999（存在しない）

**期待される動作:**
- [ ] エラーメッセージを表示
- [ ] 「レッスン999は見つかりませんでした」

---

## テスト4: 出力ディレクトリ

**期待される動作:**
- [ ] lessonsディレクトリが存在しない場合は自動作成
- [ ] ファイル名は3桁ゼロ埋め（lesson-001.md, lesson-013.md等）

---

## 検証方法

1. スキルを呼び出して教材を生成
2. 生成されたファイルを開いて上記チェックリストを確認
3. テンプレート形式に準拠しているか確認
4. コード例が正しいJavaScript構文か確認
