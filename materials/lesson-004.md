# Lesson 004: 初めてのHTMLファイル

---

## 今回の学習

### 前回の復習

前回は、JavaScriptでの四則演算を学びました。`+`、`-`、`*`、`/`の演算子を使って計算ができること、演算子の優先順位があること、そして括弧を使って計算順序を制御できることを確認しました。

### 今回の目標

1. HTMLファイルを作成できるようになる

3. scriptタグの役割を理解する

## HTMLとは

HTMLは「**H**yper**T**ext **M**arkup **L**anguage」の略で、Webページの構造を作るための言語です。私たちが普段見ているWebサイト（Google、YouTube、Twitterなど）は、すべてHTMLで書かれています。

**簡単に言うと：**
- HTML = Webページを作るための「設計図」
- ブラウザがHTMLを読んで、画面に表示する
- JavaScriptはHTMLの中に書くことができる

### なぜHTMLが必要なのか

これまでは、ブラウザの開発者ツール（コンソール）で直接JavaScriptを実行してきました。これは手軽で便利ですが、いくつかの制限があります。

**コンソールの制限：**
- ❌ ブラウザを閉じると、書いたコードが**消えてしまいます**
- ❌ 長いプログラムを書くのが大変です
- ❌ 他の人と共有することができません
- ❌ 毎回同じコードを打ち直す必要があります

**HTMLファイルの利点：**
- ✅ コードを**永久に保存**できます
- ✅ 何度でも実行できます
- ✅ 他の人と共有できます（USBメモリ、メール、GitHubなど）
- ✅ 将来的にはWebサイトとして公開できます

HTMLファイルを作ることで、プログラミングの第一歩を踏み出すことができます！

### HTMLの基本的な仕組み

HTMLファイルは、「**タグ**」と呼ばれる記号で構成されています。タグは `<` と `>` で囲まれた命令のようなものです。

**タグの構造：**

```
開始タグ      内容       終了タグ
   ↓          ↓          ↓
<script>  ここにコード  </script>
```

例えば、`<script>` というタグは「**ここからJavaScriptが始まります**」という意味を持ちます。そして `</script>` は「**ここでJavaScriptが終わります**」という意味です。

**覚えておこう：**
- 開始タグ：`<script>` → 開始を示す
- 終了タグ：`</script>` → 終了を示す（スラッシュ `/` がつく）
- タグは必ずペアで使う

このように、多くのタグは**開始タグと終了タグのペア**になっています。終了タグには `/` がついているのが特徴です。

## scriptタグの役割

### scriptタグとは

`<script>` タグは、HTMLの中でJavaScriptを書くための特別なタグです。ブラウザはHTMLファイルを読み込むとき、`<script>` タグを見つけると、その中のJavaScriptコードを実行します。

```html
<script>
console.log("成功！");
</script>
```

上記のように、`<script>` と `</script>` の間にJavaScriptのコードを書きます。ブラウザがこのHTMLファイルを開くと、自動的に `console.log("成功！")` が実行されます。

### なぜscriptタグを使うのか

開発者ツールのコンソールで直接コードを書く場合と比べて、scriptタグを使う方法にはいくつかの利点があります。

**保存ができる**

HTMLファイルとして保存しておけば、明日も来週も同じコードを実行できます。開発者ツールでは、ブラウザを閉じるたびに消えてしまいますが、ファイルなら永久に残ります。

**編集がしやすい**

VSCodeなどのエディタを使えば、コードの色分け（シンタックスハイライト）が効いて見やすくなります。また、入力補完機能も使えるので、タイプミスを減らすことができます。

**複数行のコードが書きやすい**

開発者ツールでは長いコードを書くのが大変ですが、エディタなら何百行でも快適に書けます。

## HTMLファイルを作成しよう

それでは、実際にHTMLファイルを作成してみましょう。

### 手順1：VSCodeを開く

まず、VSCode（Visual Studio Code）を起動します。もしVSCodeをインストールしていない場合は、公式サイトからダウンロードしてインストールしてください。

VSCodeがない場合は、Windowsに標準で入っている「メモ帳」でも構いません。ただし、VSCodeの方がコードが見やすく、入力補完も効くのでおすすめです。

### 手順2：新規ファイルを作成する

VSCodeを開いたら、新しいファイルを作成します。

**VSCodeの場合**

1. メニューバーの「ファイル」をクリックします
2. 「新規ファイル」を選択します
3. または、キーボードショートカット `Ctrl + N`（Macの場合は `Cmd + N`）を使うこともできます

**メモ帳の場合**

1. メモ帳を開きます
2. 新しいウィンドウが開いた状態で始めます

### 手順3：ファイルを保存する

空のファイルが開いたら、まず保存します。これは非常に重要なステップです。

**VSCodeの場合**

1. メニューバーの「**ファイル**」をクリックします
2. 「**名前を付けて保存**」を選択します
3. ファイル名を `first.html` と入力します
4. 保存場所を選んで「**保存**」をクリックします

**キーボードショートカット：** `Ctrl + S` （Macは `Cmd + S`）

**メモ帳の場合**

1. メニューバーの「**ファイル**」をクリックします
2. 「**名前を付けて保存**」を選択します
3. ファイル名を `first.html` と入力します
4. 🚨 **重要：** 「ファイルの種類」を「**すべてのファイル**」に変更します
5. 保存場所を選んで「**保存**」をクリックします

**🚨 超重要ポイント：ファイル名には必ず `.html` をつける**

```
✅ 正しい：first.html
❌ 間違い：first（拡張子がない）
❌ 間違い：first.txt（間違った拡張子）
❌ 間違い：first.html.txt（二重拡張子）
```

ファイル名は必ず `.html` で終わるようにしてください。これにより、コンピュータがこのファイルをHTMLファイルとして認識します。

**メモ帳を使う場合の注意：**
メモ帳では、「ファイルの種類」を「すべてのファイル」に変更しないと、自動的に `.txt` が追加されて `first.html.txt` になってしまいます。必ず確認してください。

### 手順4：scriptタグを書く

ファイルを保存したら、次のコードを入力します。

**入力する内容：**

```html
<script>
</script>
```

**入力手順：**
1. `<script>` と入力します（`<` と `>` で `script` を囲む）
2. **Enterキー**を押して改行します
3. `</script>` と入力します（`/` を忘れずに！）

**ポイント：**
- `<` は「Shift + る」で入力できます
- `>` は「Shift + る」を2回押すか、「Shift + .」で入力できます
- `/` は「め」のキーで入力できます

これで、JavaScriptを書くための場所が準備できました。

### 手順5：JavaScriptコードを書く

`<script>` と `</script>` の間に、JavaScriptのコードを書きます。

**完成形：**

```html
<script>
console.log("成功！");
</script>
```

**入力手順：**
1. `<script>` の行の次の行（2行目）に、`console.log("成功！");` と入力します
2. 文字は半角英数字で入力してください
3. `"成功！"` の部分は、全角の日本語でOKです

`console.log("成功！");` は、レッスン1で学んだコードです。コンソールに「成功！」という文字を表示します。

**入力が終わったら：**
- ファイルを保存します
- `Ctrl + S`（Macの場合は `Cmd + S`）を押すと、素早く保存できます
- VSCodeでは、ファイルのタブに「●」マークが表示されている場合は未保存です

**よくある間違い：**
```html
<!-- ❌ 間違い：全角の記号を使っている -->
<script>
console.log("成功！");
</script>

<!-- ❌ 間違い：セミコロンがない -->
<script>
console.log("成功！")
</script>

<!-- ❌ 間違い：引用符が全角 -->
<script>
console.log("成功！");
</script>

<!-- ✅ 正しい：半角記号を使う -->
<script>
console.log("成功！");
</script>
```

## HTMLファイルを実行する

作成したHTMLファイルをブラウザで開いて、JavaScriptを実行してみましょう。

### ファイルを開く方法

HTMLファイルをブラウザで開くには、いくつかの方法があります。

**方法1：ダブルクリック**

エクスプローラー（Finderの場合はFinder）で、保存した `first.html` ファイルをダブルクリックします。デフォルトのブラウザでファイルが開きます。

**方法2：ブラウザにドラッグ&ドロップ**

ブラウザのウィンドウに、`first.html` ファイルをドラッグ&ドロップします。

**方法3：ブラウザから開く**

1. ブラウザを開きます
2. `Ctrl + O`（Macの場合は `Cmd + O`）を押します
3. ファイルを選択して「開く」をクリックします

### 結果を確認する

ブラウザでHTMLファイルを開いても、**画面には何も表示されません**。「えっ、失敗？」と思うかもしれませんが、これは**正常**です。

**なぜ何も表示されないの？**

`console.log()` はコンソールに出力するものなので、画面には表示されないのです。レッスン1でも同じでしたね。

**結果を確認する手順：**

1. ブラウザで `first.html` を開いた状態で、**F12キー**を押します
2. または、ブラウザ上で**右クリック** → 「**検証**」を選択します
3. 開発者ツールが開いたら、「**Console**」タブをクリックします

**成功の確認：**

コンソールに「**成功！**」と表示されていれば、**大成功**です！

```
Console
  成功！
```

おめでとうございます！あなたは初めてのHTMLファイルを作成し、JavaScriptを実行することに成功しました。

### 🚨 うまくいかない場合のチェックリスト

もし「成功！」が表示されない場合は、以下を一つずつ確認してください。

#### チェック1：ファイル名の確認

ファイル名が `first.html` になっているか確認します。

**よくある間違い：**
- ❌ `first.html.txt` になっている（メモ帳で保存時に「すべてのファイル」を選ばなかった）
- ❌ `first` だけ（拡張子がない）
- ❌ `First.html`（大文字小文字が違う - Windowsでは動きますが、Linuxでは問題になります）

**確認方法：**
エクスプローラーで、「表示」→「ファイル名拡張子」にチェックを入れて、実際のファイル名を確認してください。

#### チェック2：タグの確認

`<script>` と `</script>` が正しく書かれているか確認します。

**よくある間違い：**
```html
❌ <Script>  （大文字）
❌ <srcript> （スペルミス）
❌ <script>  （終了タグがない）
❌ <script>  （終了タグに / がない）
     </script
❌ < script> （余計なスペース）

✅ <script>  （正しい）
     </script>
```

#### チェック3：セミコロンの確認

`console.log("成功！");` の最後にセミコロン `;` があるか確認します。

```javascript
❌ console.log("成功！")  // セミコロンがない
✅ console.log("成功！"); // セミコロンがある
```

#### チェック4：引用符の確認

`"成功！"` の部分が、**半角**のダブルクォーテーション `"` で囲まれているか確認します。

**よくある間違い：**
```javascript
❌ console.log("成功！");  // 全角の引用符
❌ console.log('成功！');  // シングルクォート（これも動きますが、今は統一のため使わない）
✅ console.log("成功！");  // 半角のダブルクォーテーション
```

#### チェック5：ファイルを保存したか確認

コードを書いた後、**保存**しましたか？

- VSCodeの場合、ファイルのタブに「●」マークがある場合は未保存です
- `Ctrl + S` を押して保存してください
- 保存後、ブラウザで **F5キー** を押して更新してください

#### チェック6：正しいファイルを開いているか確認

ブラウザで開いているファイルは、本当に `first.html` ですか？

- ブラウザのアドレスバーを確認してください
- `file:///C:/Users/.../first.html` のようなパスが表示されているはずです

それでもうまくいかない場合は、もう一度最初から手順を確認してみてください。

## コードを追加してみよう

基本的なHTMLファイルが動くことを確認できたら、コードを追加してみましょう。

### 複数のconsole.logを書く

レッスン2で学んだように、JavaScriptは上から順番に実行されます。複数の `console.log()` を書くと、順番に出力されます。

```html
<script>
console.log("1行目です");
console.log("2行目です");
console.log("3行目です");
</script>
```

このコードを保存してブラウザを更新すると、コンソールに3行が順番に表示されます。

### 計算結果を表示する

レッスン3で学んだ計算も、HTMLファイルの中で実行できます。

```html
<script>
console.log(10 + 5);
console.log(100 - 30);
console.log(8 * 7);
console.log(84 / 4);
</script>
```

ブラウザを更新すると、計算結果がコンソールに表示されます。

### 文字と計算を組み合わせる

文字列と計算を別々の行で出力することもできます。

```html
<script>
console.log("今日の計算");
console.log(1 + 2 + 3 + 4 + 5);
console.log("答えは上の数字です");
</script>
```

## 練習問題

### 課題：自分のHTMLファイルを作成する

以下の内容を表示するHTMLファイルを作成してください。

1. 自分の名前（または好きな名前）
2. 好きな数字
3. その数字を2倍した値
4. 「完了」という文字

### 保存場所

`exercises/lesson-004/index.html` を使用してください。このファイルは既に用意されています。

### 進め方

1. VSCode（またはメモ帳）で `exercises/lesson-004/index.html` を開きます
2. `<script>` タグの中にコードを書きます
3. 上記の4つの内容を出力する `console.log()` を書きます
4. ファイルを保存します
5. ブラウザで開いて結果を確認します

### 期待される出力例

（好きな数字を7にした場合）

```
山田太郎
7
14
完了
```

---

**ヒント**

- `console.log()` は4回使います
- 名前と「完了」は文字列なので `"` で囲みます
- 好きな数字はそのまま書きます
- 2倍した値は `* 2` を使って計算します

---

**解説**

```html
<script>
console.log("山田太郎");
console.log(7);
console.log(7 * 2);
console.log("完了");
</script>
```

1行目では、名前を文字列として出力しています。文字列なので `"` で囲みます。

2行目では、好きな数字をそのまま出力しています。数値なので `"` は不要です。

3行目では、好きな数字を2倍しています。`7 * 2` は `14` と計算され、その結果が出力されます。

4行目では、「完了」という文字列を出力しています。

それぞれの `console.log()` が上から順番に実行され、コンソールに4行の出力が表示されます。
