## 二重ループとは

これまでのレッスンでは、1つのfor文を使って1列のデータを処理してきました。しかし、実際のプログラミングでは、表のような2次元的なデータを扱うことがよくあります。

二重ループとは、**for文の中にもう1つfor文を入れる**構造のことです。これを使うと、行と列のある表形式のデータを処理できます。

例えば、以下のような場面で二重ループが役立ちます：

- **九九の表全体**：1の段から9の段まで、すべて表示する
- **座席表**：5行6列の座席を番号付けする
- **カレンダー**：週と日の組み合わせで1ヶ月分を表示
- **商品リスト**：カテゴリごとに商品を表示する
- **画像処理**：ピクセル単位で画像を処理する（横×縦）

多くのWebアプリケーションで見る「表」は、二重ループの技術を使って作られています。Excelのような表計算ソフト、ECサイトの商品一覧、SNSの投稿一覧なども、この考え方を応用しています。

## 二重ループの基本構造

まずは、最もシンプルな二重ループの例を見てみましょう。

```javascript
// 外側のループ（行）
for (let i = 1; i <= 3; i++) {
    // 内側のループ（列）
    for (let j = 1; j <= 3; j++) {
        console.log("i=" + i + ", j=" + j);
    }
}

// 結果:
// i=1, j=1
// i=1, j=2
// i=1, j=3
// i=2, j=1
// i=2, j=2
// i=2, j=3
// i=3, j=1
// i=3, j=2
// i=3, j=3
```

**動きの仕組み：**

1. 外側のループでiが1になる
2. 内側のループがjを1から3まで回す
3. 外側のループでiが2になる
4. 内側のループがjを1から3まで回す
5. 外側のループでiが3になる
6. 内側のループがjを1から3まで回す

つまり、**外側のループが1回進むごとに、内側のループは最初から最後まで全部実行される**という仕組みです。

この構造を使うと、3×3の9マス分のデータを簡単に処理できます。

## 外側と内側のループの役割

二重ループでは、外側のループと内側のループがそれぞれ異なる役割を持ちます。

### 外側のループ：行を制御

外側のループは「行」を制御します。

```javascript
for (let i = 1; i <= 3; i++) {
    console.log("--- " + i + "行目 ---");

    for (let j = 1; j <= 4; j++) {
        console.log("  " + j + "列目");
    }
}

// 結果:
// --- 1行目 ---
//   1列目
//   2列目
//   3列目
//   4列目
// --- 2行目 ---
//   1列目
//   2列目
//   3列目
//   4列目
// --- 3行目 ---
//   1列目
//   2列目
//   3列目
//   4列目
```

外側のループが1回進むと、内側のループが完全に終わるまで待ちます。これが「行」の切り替えに対応します。

### 内側のループ：列を制御

内側のループは「列」を制御します。同じ行の中で、左から右へ処理が進むイメージです。

このように、外側と内側のループを組み合わせることで、表の各セルを順番に処理できるようになります。

## 変数名の慣習

二重ループでは、通常以下のような変数名を使います：

- **外側のループ**：`i`（row の r、または単に慣習）
- **内側のループ**：`j`（i の次の文字）

```javascript
for (let i = 0; i < 3; i++) {      // 外側：i
    for (let j = 0; j < 3; j++) {  // 内側：j
        console.log(i + "," + j);
    }
}
```

さらに深くネストする場合は、`k`、`l`と続けることもありますが、3重以上のループは複雑になるため、なるべく避けるのが良い設計です。

より分かりやすくするために、`row`（行）と`col`（列）という変数名を使うこともあります：

```javascript
for (let row = 0; row < 3; row++) {
    for (let col = 0; col < 3; col++) {
        console.log("行" + row + ", 列" + col);
    }
}
```

どちらの方法でも構いませんが、チームで開発する場合はコーディング規約に従います。

## 掛け算を使った二重ループ

二重ループの両方の変数を使って、計算を行うこともできます。

### 簡単な掛け算表

```javascript
// 3×3の掛け算表
for (let i = 1; i <= 3; i++) {
    for (let j = 1; j <= 3; j++) {
        let result = i * j;
        console.log(i + " × " + j + " = " + result);
    }
}

// 結果:
// 1 × 1 = 1
// 1 × 2 = 2
// 1 × 3 = 3
// 2 × 1 = 2
// 2 × 2 = 4
// 2 × 3 = 6
// 3 × 1 = 3
// 3 × 2 = 6
// 3 × 3 = 9
```

外側のループの`i`と内側のループの`j`を掛け合わせることで、すべての組み合わせの計算ができます。

## 九九の全表を作成する

二重ループを使えば、九九の全段（1の段から9の段まで）を一気に表示できます。

```javascript
// 九九の全表（1の段から9の段まで）
for (let i = 1; i <= 9; i++) {
    console.log("--- " + i + "の段 ---");

    for (let j = 1; j <= 9; j++) {
        let answer = i * j;
        console.log(i + " × " + j + " = " + answer);
    }

    console.log(""); // 空行を入れて見やすくする
}

// 結果:
// --- 1の段 ---
// 1 × 1 = 1
// 1 × 2 = 2
// 1 × 3 = 3
// ...
// 1 × 9 = 9
//
// --- 2の段 ---
// 2 × 1 = 2
// 2 × 2 = 4
// ...
// --- 9の段 ---
// 9 × 1 = 9
// ...
// 9 × 9 = 81
```

このコードでは、外側のループが段（1の段、2の段...）を制御し、内側のループが各段の1から9までを制御しています。

これにより、81個の掛け算（9段×9回）をたった数行のコードで表示できます。手作業で書くと81行必要ですが、二重ループを使えば簡潔に書けます。

## 行ごとに処理を分ける

二重ループでは、行が切り替わるタイミングで特別な処理を入れることができます。

### 区切り線を入れる

```javascript
for (let i = 1; i <= 3; i++) {
    console.log("========== " + i + "行目 ==========");

    for (let j = 1; j <= 5; j++) {
        console.log("  (" + i + ", " + j + ")");
    }
}

// 結果:
// ========== 1行目 ==========
//   (1, 1)
//   (1, 2)
//   (1, 3)
//   (1, 4)
//   (1, 5)
// ========== 2行目 ==========
//   (2, 1)
//   (2, 2)
//   (2, 3)
//   (2, 4)
//   (2, 5)
// ========== 3行目 ==========
//   (3, 1)
//   (3, 2)
//   (3, 3)
//   (3, 4)
//   (3, 5)
```

外側のループの中で、内側のループの前後に処理を追加することで、見出しや区切り線を入れられます。

### 行ごとの合計を計算する

```javascript
for (let i = 1; i <= 3; i++) {
    let sum = 0; // 行ごとに合計をリセット

    for (let j = 1; j <= 5; j++) {
        sum += j; // 1から5までを足す
    }

    console.log(i + "行目の合計: " + sum);
}

// 結果:
// 1行目の合計: 15
// 2行目の合計: 15
// 3行目の合計: 15
```

外側のループで変数を宣言すれば、行ごとに値をリセットできます。これを使って、行ごとの集計や処理ができます。

## 実用的な応用例

二重ループは、実際のWebアプリケーションで非常によく使われます。

### 座席表の作成

```javascript
// 5行×6列の座席表
for (let row = 1; row <= 5; row++) {
    for (let col = 1; col <= 6; col++) {
        let seatNumber = (row - 1) * 6 + col;
        console.log("座席番号: " + seatNumber + " (Row " + row + ", Col " + col + ")");
    }
}

// 結果:
// 座席番号: 1 (Row 1, Col 1)
// 座席番号: 2 (Row 1, Col 2)
// ...
// 座席番号: 30 (Row 5, Col 6)
```

映画館やコンサートの座席予約システムなどで使われる技術です。

```javascript
// 4週間分（4行）、各週7日（7列）
for (let week = 1; week <= 4; week++) {

```

## 二重ループの注意点

二重ループは便利ですが、注意すべき点もあります。

### 処理回数が急激に増える

二重ループでは、外側と内側の回数を掛け合わせた回数だけ処理が実行されます。

```javascript
// 外側10回 × 内側10回 = 合計100回
for (let i = 0; i < 10; i++) {
    for (let j = 0; j < 10; j++) {
        console.log(i + ", " + j);
    }
}
```

10×10なら100回で済みますが、100×100なら10,000回、1000×1000なら1,000,000回になります。大きな数を扱うときは、パフォーマンスに注意が必要です。

### 変数名の衝突に注意

内側と外側で同じ変数名を使うと、エラーや予期しない動作の原因になります。

```javascript
// 悪い例：同じ変数名を使用
for (let i = 0; i < 3; i++) {
    for (let i = 0; i < 3; i++) {  // エラー：iは既に宣言されている
        console.log(i);
    }
}
```

必ず異なる変数名（`i`と`j`、または`row`と`col`）を使いましょう。

### 無限ループに注意

二重ループでは、どちらかのループが無限ループになると、プログラム全体が止まってしまいます。

```javascript
// 危険な例：内側のループが無限ループ
for (let i = 0; i < 3; i++) {
    for (let j = 0; j >= 0; j++) {  // jは常に0以上なので終わらない
        console.log(i, j);
    }
}
```

条件式と更新式が正しく書かれているか、必ず確認しましょう。

## 三重ループとそれ以上

二重ループをさらにネストして、三重ループ、四重ループを作ることもできます。

```javascript
// 三重ループの例
for (let i = 1; i <= 2; i++) {
    for (let j = 1; j <= 2; j++) {
        for (let k = 1; k <= 2; k++) {
            console.log(i + ", " + j + ", " + k);
        }
    }
}

// 結果: 2×2×2 = 8回実行される
```

ただし、三重以上のループは複雑になりすぎるため、実務では避けられることが多いです。もし必要な場合は、関数に分割するなどして、コードを分かりやすくする工夫が必要です。

### ヒント

- **外側のループ**：1から9まで回します（`for (let i = 1; i <= 9; i++)`）。これが「段」を表します
- **内側のループ**：1から9まで回します（`for (let j = 1; j <= 9; j++)`）。これが各段の「何倍」を表します
- **掛け算の計算**：`let answer = i * j`で掛け算の結果を計算します
- **表示形式**：`console.log(i + " × " + j + " = " + answer)`で表示します

外側のループが1回進むごとに、内側のループは1から9まで全部実行されます。

つまり、外側が1のとき、内側は1から9まで回ります（1×1, 1×2, ..., 1×9）。
次に外側が2のとき、内側はまた1から9まで回ります（2×1, 2×2, ..., 2×9）。

これを9回繰り返すことで、81個の掛け算すべてを表示できます。

### 解答例

```javascript
// 九九の全表（1の段から9の段まで）
for (let i = 1; i <= 9; i++) {
    for (let j = 1; j <= 9; j++) {
        let answer = i * j;
        console.log(i + " × " + j + " = " + answer);
    }
}
```

### 解説

このコードでは、二重ループを使って九九の全表（81個の掛け算）を表示しています。各部分の役割を見ていきましょう。

**外側のループ（`for (let i = 1; i <= 9; i++)`）**

- 変数`i`を1から9まで変化させます
- これが「何の段」かを表します（1の段、2の段、...、9の段）
- 外側のループが1回進むごとに、内側のループが完全に実行されます

**内側のループ（`for (let j = 1; j <= 9; j++)`）**

- 変数`j`を1から9まで変化させます
- これが「何倍」かを表します（×1、×2、...、×9）
- 外側のループの`i`が固定された状態で、1から9まで全部実行されます

**計算（`let answer = i * j`）**

- 外側のループの`i`と内側のループの`j`を掛け合わせます
- これにより、すべての組み合わせの掛け算ができます

**表示（`console.log(...)`）**

- 「2 × 3 = 6」のような形式で結果を表示します

**動きの流れ：**

1. i=1、j=1→9：1×1=1, 1×2=2, ..., 1×9=9
2. i=2、j=1→9：2×1=2, 2×2=4, ..., 2×9=18
3. i=3、j=1→9：3×1=3, 3×2=6, ..., 3×9=27
4. ...
5. i=9、j=1→9：9×1=9, 9×2=18, ..., 9×9=81

合計で9×9=81回の掛け算が表示されます。

**実行結果の一部：**

```
1 × 1 = 1
1 × 2 = 2
1 × 3 = 3
...
1 × 9 = 9
2 × 1 = 2
2 × 2 = 4
...
9 × 8 = 72
9 × 9 = 81
```

**応用のポイント：**

- **範囲を変えれば**：12×12の掛け算表や、20×20の表も作れます
- **見出しを追加すれば**：各段の前に「--- 3の段 ---」のような表示も可能です
- **条件を追加すれば**：偶数だけ、10以上だけなど、フィルタリングもできます

二重ループを使いこなせるようになると、表形式のデータや2次元的な処理が自由にできるようになります。

## まとめ

お疲れ様でした。今回のレッスンでは、二重ループ（ネストループ）について学びました。

### 今回学んだキーポイント

**1. ネストループの構造**

for文の中にfor文を入れることで、2次元的な処理ができます。

基本的な構造は以下の通りです：

```javascript
for (let i = 開始; i <= 終了; i++) {  // 外側のループ
    for (let j = 開始; j <= 終了; j++) {  // 内側のループ
        // ここで i と j の両方を使える
    }
}
```

外側のループが1回進むごとに、内側のループは最初から最後まで完全に実行されます。この仕組みを理解することが、二重ループを使いこなす鍵です。

**2. 2次元的な処理**

二重ループを使うと、行と列のような2次元データを処理できます。

- 外側のループ：行を制御する
- 内側のループ：列を制御する

この考え方は、表計算、座席配置、カレンダー、ゲームのマップなど、様々な場面で応用できます。Webアプリケーションで見る「表」の多くは、この技術を使って作られています。

**3. 実用的な活用**

二重ループの実用例として、以下のようなものがあります：

- **九九の全表**：すべての段を一度に表示
- **座席表**：行と列で座席を管理
- **カレンダー**：週と日の組み合わせ
- **商品一覧**：カテゴリと商品の組み合わせ

今回作成した九九の表は、教育アプリや学習サイトでよく使われる機能です。二重ループを使えば、81個の計算結果を数行のコードで生成できます。
