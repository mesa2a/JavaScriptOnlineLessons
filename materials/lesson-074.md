## while文とは

プログラミングにおいて、同じ処理を何度も繰り返したい場面は数多くあります。例えば、1から100までの数字を表示したり、ユーザーが正解するまで質問を繰り返したり、データのリストを順番に処理したりする場合です。

このような繰り返し処理を実現するための基本的な構文が**while文**です。while文は、指定した条件が真である限り、処理を繰り返し実行します。

### while文の基本構造

while文は以下の構造を持ちます。

```javascript
while (条件式) {
  // 条件が真の間、繰り返し実行される処理
}
```

条件式が`true`の間、中括弧`{}`内の処理が繰り返し実行されます。条件式が`false`になると、ループを抜けて次の処理に進みます。

### 日常生活での例え

while文は、日常生活の中にも似たような考え方があります。

例えば、「お腹が空いている間は食べ続ける」という行動を考えてみましょう。

```
while (お腹が空いている) {
  食べる
  満腹度をチェックする
}
```

この場合、「お腹が空いている」という条件が真の間、食べる行動を繰り返します。満腹になれば条件が偽になり、食べるのを止めます。

プログラミングのwhile文も、これと同じ仕組みです。

## カウンタ変数を使ったループ

while文で繰り返し処理を行う際に、最もよく使われるのが**カウンタ変数**です。カウンタ変数は、ループの回数を数えるための変数です。

### 基本的なカウントアップの例

```javascript
let i = 0;  // カウンタ変数を0で初期化

while (i < 5) {  // iが5未満の間、繰り返す
  console.log(i);  // 現在のiの値を表示
  i++;  // iを1増やす（インクリメント）
}
```

このコードは以下のように動作します。

1. **初期化**：カウンタ変数`i`を0で初期化します
2. **条件チェック**：`i < 5`が真かどうかを確認します
3. **処理実行**：条件が真なら、`console.log(i)`と`i++`を実行します
4. **条件チェックに戻る**：再び条件をチェックし、真なら処理を繰り返します
5. **ループ終了**：`i`が5になると`i < 5`が偽になり、ループを抜けます

実行結果：

```
0
1
2
3
4
```

### カウンタ変数の役割

カウンタ変数には3つの重要な要素があります。

1. **初期化**：ループを始める前に初期値を設定します（例：`let i = 0`）
2. **条件式**：ループを続けるかどうかの判断基準です（例：`i < 5`）
3. **更新**：ループのたびにカウンタの値を変更します（例：`i++`）

この3つの要素が正しく設定されていないと、ループが正しく動作しません。

## while文の実行フロー

while文がどのように実行されるのか、詳しく見ていきましょう。

```javascript
let count = 0;

while (count < 3) {
  console.log("カウント: " + count);
  count++;
}

console.log("ループ終了");
```

このコードの実行フローは以下の通りです。

**1回目のループ**
- 条件チェック：`count < 3`は`0 < 3`で真
- 処理実行：`console.log("カウント: 0")`が実行される
- カウンタ更新：`count++`で`count`が1になる

**2回目のループ**
- 条件チェック：`count < 3`は`1 < 3`で真
- 処理実行：`console.log("カウント: 1")`が実行される
- カウンタ更新：`count++`で`count`が2になる

**3回目のループ**
- 条件チェック：`count < 3`は`2 < 3`で真
- 処理実行：`console.log("カウント: 2")`が実行される
- カウンタ更新：`count++`で`count`が3になる

**4回目のチェック**
- 条件チェック：`count < 3`は`3 < 3`で偽
- ループを抜けて、次の処理に進む

実行結果：

```
カウント: 0
カウント: 1
カウント: 2
ループ終了
```

## 無限ループの危険性

while文を使う際に最も注意すべき点は、**無限ループ**です。無限ループとは、条件が永遠に真のままでループが終了しない状態のことです。

### 無限ループの例

```javascript
let i = 0;

while (i < 5) {
  console.log(i);
  // i++を忘れている！
}
```

このコードでは、`i`の値が更新されないため、`i < 5`が常に真のままになります。結果として、ループが永遠に続き、ブラウザが応答しなくなる可能性があります。

### 無限ループを防ぐポイント

無限ループを防ぐために、以下の点に注意しましょう。

1. **カウンタ変数の更新を忘れない**：`i++`などの更新処理を必ず含める
2. **条件式が偽になることを確認する**：いつかは条件が偽になるように設計する
3. **意図した回数でループが終わることをテストする**：実際に実行して確認する

## さまざまな条件式

while文では、さまざまな条件式を使うことができます。

### 異なる開始値と終了値

```javascript
let i = 1;  // 1から開始

while (i <= 10) {  // 10以下の間繰り返す
  console.log(i);
  i++;
}
```

このコードは1から10までの数字を表示します。`i <= 10`と書くことで、10も含めて表示することができます。

### カウントダウン

```javascript
let i = 5;  // 5から開始

while (i > 0) {  // 0より大きい間繰り返す
  console.log(i);
  i--;  // 1ずつ減らす
}

console.log("発射!");
```

実行結果：

```
5
4
3
2
1
発射!
```

カウントダウンのように、値を減らしていくこともできます。この場合、`i--`を使って値を1ずつ減らします。

### 2ずつ増やす

```javascript
let i = 0;

while (i < 10) {
  console.log(i);
  i += 2;  // 2ずつ増やす
}
```

実行結果：

```
0
2
4
6
8
```

`i += 2`を使うことで、2ずつ値を増やすこともできます。

## 実践例：5回メッセージを表示する

while文を使って、5回メッセージを表示するプログラムを作ってみましょう。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>5回ループ</title>
</head>
<body>
    <h1>while文の練習</h1>
    <button id="startButton">ループ開始</button>
    <div id="output"></div>

    <script src="script.js"></script>
</body>
</html>
```

```javascript
let startButton = document.getElementById("startButton");
let output = document.getElementById("output");

startButton.addEventListener("click", function() {
  // outputをクリア
  output.innerHTML = "";

  let i = 0;  // カウンタ変数を初期化

  while (i < 5) {  // 5回繰り返す
    // 新しい段落要素を作成
    let p = document.createElement("p");
    p.textContent = (i + 1) + "回目のメッセージです";
    output.appendChild(p);

    i++;  // カウンタを1増やす
  }
});
```

このコードでは、ボタンをクリックすると5回ループが実行され、それぞれのループで新しい段落要素が作成されて画面に追加されます。

### コードの詳しい説明

1. **outputをクリア**：前回の結果を消去します
2. **カウンタ初期化**：`let i = 0`でカウンタを0から始めます
3. **ループ条件**：`i < 5`なので、0、1、2、3、4の5回ループします
4. **要素作成**：各ループで新しい`<p>`要素を作成します
5. **テキスト設定**：`(i + 1)`を使って、1から始まる番号を表示します
6. **要素追加**：作成した要素をoutputに追加します
7. **カウンタ更新**：`i++`でカウンタを1増やします

```javascript
let startLoop = document.getElementById("startLoop");
let result = document.getElementById("result");

startLoop.addEventListener("click", function() {
  // 結果をクリア
  result.innerHTML = "";

  // カウンタ変数を初期化

  // while文で5回繰り返す

    // 結果を表示

  }

```

### 解説

このコードでは、while文を使って5回のループを実装しています。

**カウンタ変数の初期化**
```javascript
let i = 0;
```
カウンタ変数`i`を0で初期化します。ループの回数を数えるための変数です。

**while文の条件式**
```javascript
while (i < 5) {
```
`i < 5`という条件が真の間、ループが続きます。iは0から始まり、4まで増えるので、合計5回ループします。

**ループ内の処理**
```javascript
let p = document.createElement("p");
p.textContent = "ループ回数: " + (i + 1);
result.appendChild(p);
```
各ループで新しい段落要素を作成し、現在のループ回数を表示します。`(i + 1)`を使うことで、1から始まる番号を表示しています。

**カウンタの更新**
```javascript
i++;
```
ループのたびに`i`を1増やします。これがないと無限ループになってしまいます。

## まとめ

お疲れ様でした。今回のレッスンでは、JavaScriptの基本的な繰り返し処理であるwhile文を学びました。

**今回学んだキーポイント**

- **while文の構造**：`while (条件式) { 処理 }`という形式で、条件が真の間、処理を繰り返します。条件式は毎回評価され、偽になるとループを抜けます
- **条件式の評価**：ループの前と各ループの後に条件式が評価されます。条件が真である限り処理が繰り返され、偽になった時点でループが終了します
- **無限ループの危険**：カウンタ変数の更新を忘れると、条件が永遠に真のままになり、無限ループが発生します。必ずカウンタを更新する処理を含めましょう
- **カウンタ変数の使い方**：`let i = 0`で初期化し、`i < 5`のような条件式で制御し、`i++`で更新するのが基本パターンです

while文は、繰り返し処理の基本となる重要な構文です。今回学んだ基本的なカウントアップのパターンは、今後のプログラミングで頻繁に使用します。
