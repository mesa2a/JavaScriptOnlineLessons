## イベントとは

### イベントの概念

**イベント**とは、Webページ上で起こる「出来事」のことです。

例えば、以下のような出来事がイベントです。

- ボタンを**クリック**した
- マウスを要素の上に**乗せた**
- キーボードのキーを**押した**
- ページの読み込みが**完了した**

これまでのレッスンで書いたコードは、ページを開いた瞬間に自動的に実行されていました。

```javascript
let elem = document.getElementById("text");
elem.textContent = "変わった！";
```

このコードは、ページを開くと同時に文字が「変わった！」に変わります。

しかし、**実際のWebサイトでは、ユーザーの操作に応じて動作する**必要があります。

例えば：
- ボタンをクリックしたときだけ動画を再生する
- 入力欄に文字を入力したときだけチェックする
- マウスを乗せたときだけメニューを表示する

このように、「ユーザーが何かしたときに反応する」仕組みを作るために、**イベント**という概念があります。

### 身近な例で理解する

普段使っているWebサイトを思い出してみましょう。

**YouTube:**
- 再生ボタンをクリックすると → 動画が再生される
- 一時停止ボタンをクリックすると → 動画が止まる

**Amazon:**
- 「カートに入れる」ボタンをクリックすると → 商品が追加される
- 「購入する」ボタンをクリックすると → 注文画面に進む

**Twitter（X）:**
- いいねボタンをクリックすると → ハートが赤くなる
- リツイートボタンをクリックすると → 投稿が共有される

これらは全て、**クリックというイベントに反応している**のです。

今回のレッスンでは、このような「クリックしたら何かが起こる」仕組みを作れるようになります。

### なぜイベントが重要なのか

イベントを使えるようになると、以下のことができるようになります。

1. **ユーザーの操作に反応できる**
   - クリックしたときだけ処理を実行
   - 必要なときにだけ動作する

2. **インタラクティブなページを作れる**
   - ユーザーが操作して楽しめるページ
   - 動的で魅力的な体験を提供

3. **実用的なWebアプリケーションを作れる**
   - フォームの送信
   - データの保存
   - ゲームの操作

イベントは、**静的なページから動的なWebアプリケーションへの第一歩**です。

## onclick属性の基本

### onclick属性とは

`onclick`属性は、**要素がクリックされたときに実行するJavaScriptコードを指定する属性**です。

最もシンプルな例を見てみましょう。

```html
<button onclick="alert('クリックされました！')">ボタン</button>
```

このボタンをクリックすると、「クリックされました！」というアラートが表示されます。

### onclick属性の書き方

`onclick`属性の基本的な書き方は以下の通りです。

```html
<button onclick="JavaScriptのコード">ボタンのテキスト</button>
```

それぞれの部分を詳しく見ていきましょう。

**1. `<button>`タグ**
- ボタンを作成するHTMLタグです
- クリックできる要素を作ります

**2. `onclick=`**
- クリックされたときに実行するコードを指定する属性です
- 「on」は「〜のときに」、「click」は「クリック」という意味です

**3. `"JavaScriptのコード"`**
- ダブルクォーテーション（`"`）で囲みます
- この中にJavaScriptのコードを書きます

**4. `ボタンのテキスト`**
- ボタンに表示される文字です
- ユーザーに何のボタンかを伝えます

### 実際に試してみよう

まずは、何も機能がない普通のボタンを作ってみましょう。

```html
<button>クリックしてね</button>
```

これだけでボタンは表示されますが、クリックしても何も起きません。

次に、`onclick`属性を追加してみましょう。

```html
<button onclick="alert('こんにちは！')">クリックしてね</button>
```

このボタンをクリックすると、「こんにちは！」というアラートが表示されます。

**何が起こったのか？**

1. ユーザーがボタンをクリックする
2. ブラウザが`onclick`属性のコードを実行する
3. `alert('こんにちは！')`が実行される
4. アラートが表示される

このように、`onclick`属性を使うと、**クリックされたときに実行する処理**を指定できます。

## 実践：クリックで反応するページを作る

### ステップ1：シンプルなボタンを作る

まず、1つのボタンを作ってみましょう。

**HTML:**

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Lesson 019</title>
</head>
<body>
    <h1>ボタンをクリックしてね</h1>
    <button onclick="alert('ボタンがクリックされました！')">クリック</button>

    <script src="script.js"></script>
</body>
</html>
```

**何が書かれているのか：**

- 9行目：見出しを表示
- 10行目：ボタンを作成
  - `onclick="alert('ボタンがクリックされました！')"` - クリックされたときにアラートを表示
  - `クリック` - ボタンに表示される文字

このページをブラウザで開いて、ボタンをクリックしてみましょう。アラートが表示されるはずです。

### ステップ2：複数のボタンを作る

次に、3つのボタンを作り、それぞれ違う反応をさせてみましょう。

```html
<h1>どのボタンをクリックする？</h1>
<button onclick="alert('1つ目のボタンがクリックされました')">ボタン1</button>
<button onclick="alert('2つ目のボタンがクリックされました')">ボタン2</button>
<button onclick="alert('3つ目のボタンがクリックされました')">ボタン3</button>
```

それぞれのボタンをクリックすると、違うメッセージが表示されます。

**ポイント：**
- 各ボタンは独立しています
- それぞれ違う`onclick`の内容を持っています
- クリックしたボタンに応じた処理が実行されます

## onclickで要素を操作する

`onclick`の中では、`alert()`だけでなく、要素の操作もできます。

### 例1：文字を変更する

ボタンをクリックすると、ページ上の文字が変わるようにしてみましょう。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Lesson 019</title>
</head>
<body>
    <p id="message">最初の文字</p>
    <button onclick="document.getElementById('message').textContent = '変わった！'">変更</button>

    <script src="script.js"></script>
</body>
</html>
```

**何が起こっているのか：**

1. 最初は「最初の文字」と表示されています
2. ボタンをクリックすると
3. `document.getElementById('message')`で`<p>`要素を取得
4. `.textContent = '変わった！'`で文字を変更
5. 「変わった！」と表示が変わります

### 例2：色を変える

ボタンをクリックすると、文字の色が変わるようにしてみましょう。

```html
<p id="text">この文字の色が変わります</p>
<button onclick="document.getElementById('text').style.color = 'red'">赤にする</button>
<button onclick="document.getElementById('text').style.color = 'blue'">青にする</button>
<button onclick="document.getElementById('text').style.color = 'green'">緑にする</button>
```

**何が起こっているのか：**

- 1つ目のボタンをクリック → 文字が赤色になる
- 2つ目のボタンをクリック → 文字が青色になる
- 3つ目のボタンをクリック → 文字が緑色になる

このように、`onclick`の中で要素のスタイルを変更することができます。

### 例3：表示・非表示を切り替える

前回学んだ`display`プロパティと組み合わせてみましょう。

```html
<p id="secret">秘密のメッセージ！</p>
<button onclick="document.getElementById('secret').style.display = 'none'">隠す</button>
<button onclick="document.getElementById('secret').style.display = 'block'">表示</button>
```

**何が起こっているのか：**

- 「隠す」ボタンをクリック → メッセージが消える
- 「表示」ボタンをクリック → メッセージが現れる

このように、`onclick`を使うと、ユーザーの操作に応じて要素を操作できます。

## onclickの注意点

### 注意点1：引用符の使い分け

`onclick`属性の中で文字列を使う場合、**引用符の使い分け**に注意が必要です。

**正しい例：**

```html
<button onclick="alert('こんにちは')">ボタン</button>
```

- 外側：ダブルクォーテーション（`"`）
- 内側：シングルクォーテーション（`'`）

**間違った例：**

```html
<button onclick="alert("こんにちは")">ボタン</button>
```

同じ種類の引用符を使うと、どこからどこまでが文字列なのかわからなくなり、エラーになります。

**なぜエラーになるのか：**

ブラウザは最初の`"`を見つけると、次の`"`までを`onclick`の値だと認識します。

```html
onclick="alert("  ← ここまでがonclickの値だと認識される
```

そのため、残りの部分が正しく解釈されず、エラーになります。

**覚え方：**
- 外側と内側で**違う種類**の引用符を使う
- 外側がダブル（`"`）なら内側はシングル（`'`）
- 外側がシングル（`'`）なら内側はダブル（`"`）

### 注意点2：onclick属性のスペルに注意

`onclick`は全て**小文字**で書くのが推奨されています。

```html
<button onclick="alert('OK')">ボタン</button>  <!-- 正しい -->
<button onClick="alert('OK')">ボタン</button>  <!-- 動くが推奨されない -->
<button onlick="alert('OK')">ボタン</button>   <!-- 間違い（cが抜けている）-->
```

スペルミスに注意しましょう。

### 注意点3：長いコードは避ける

`onclick`に長いコードを書くと、読みにくくなります。

**読みにくい例：**

```html
<button onclick="document.getElementById('text').style.color = 'red'; document.getElementById('text').style.fontSize = '30px'; document.getElementById('text').textContent = '変わった！'">ボタン</button>
```

このような場合は、次回のレッスンで学ぶ**関数**を使うと、読みやすく整理できます。

## よくある間違いと解決方法

### 間違い1：引用符を忘れる

**間違い：**

```html
<button onclick=alert('こんにちは')>ボタン</button>
```

`onclick`の値を囲む引用符（`"`）がありません。

**正しい書き方：**

```html
<button onclick="alert('こんにちは')">ボタン</button>
```

### 間違い2：同じ引用符を使う

**間違い：**

```html
<button onclick="alert("こんにちは")">ボタン</button>
```

外側と内側で同じダブルクォーテーションを使っています。

**正しい書き方：**

```html
<button onclick="alert('こんにちは')">ボタン</button>
```

### 間違い3：onclick属性のスペルミス

**間違い：**

```html
<button onlick="alert('こんにちは')">ボタン</button>  <!-- cが抜けている -->
<button onckick="alert('こんにちは')">ボタン</button> <!-- cが多い -->
```

**正しい書き方：**

```html
<button onclick="alert('こんにちは')">ボタン</button>
```

### 間違い4：タグの閉じ忘れ

**間違い：**

```html
<button onclick="alert('こんにちは')">ボタン
```

`</button>`の閉じタグがありません。

**正しい書き方：**

```html
<button onclick="alert('こんにちは')">ボタン</button>
```

## まとめ

### 今回学んだこと

**1. イベントの概念**

イベントとは、Webページ上で起こる「出来事」のことです。

- ボタンのクリック
- マウスの移動
- キーボードの入力

JavaScriptを使うと、これらのイベントに反応して処理を実行できます。

**2. onclick属性の使い方**

`onclick`属性を使うと、要素がクリックされたときに実行する処理を指定できます。

```html
<button onclick="alert('クリックされました')">ボタン</button>
```

- `onclick=` - クリックされたときに実行
- `"JavaScriptのコード"` - 実行する処理を書く

**3. 引用符の使い分け**

`onclick`属性の中で文字列を使う場合、引用符の使い分けが重要です。

```html
<button onclick="alert('こんにちは')">ボタン</button>
```

- 外側：ダブルクォーテーション（`"`）
- 内側：シングルクォーテーション（`'`）

同じ種類の引用符を使うとエラーになります。

**4. インタラクティブなページ**

`onclick`を使うと、ユーザーの操作に反応するページを作れます。

- ボタンをクリックして文字を変える
- ボタンをクリックして色を変える
- ボタンをクリックして要素を表示・非表示にする

これまでは「ページを開いたら自動的に実行される」コードでしたが、今回から「ユーザーが操作したときに実行される」コードを書けるようになりました。
