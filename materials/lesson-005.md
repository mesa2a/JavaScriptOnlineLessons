# Lesson 005: ブラウザで実行

---

## 今回の学習

### 前回の復習

前回は、HTMLファイルの作成方法を学びました。VSCodeやメモ帳で `first.html` を作成し、`<script>` タグの中にJavaScriptコードを書くことで、ブラウザでJavaScriptを実行できることを確認しました。

### 今回の目標

1. HTMLファイルをブラウザで開いて実行できる
2. 開発者ツールでコンソールを確認できる
3. コードを変更して再実行する方法を習得する
4. リロード（再読み込み）の意味を理解する

---

## HTMLファイルを実行する

前回作成した `first.html` を使って、実際にブラウザで実行してみましょう。

### ファイルをダブルクリックして開く

最も簡単な方法は、HTMLファイルをダブルクリックすることです。

1. エクスプローラー（Windowsの場合）またはFinder（Macの場合）を開きます
2. `first.html` を保存したフォルダに移動します
3. `first.html` をダブルクリックします

すると、デフォルトのWebブラウザ（Chrome、Edge、Firefoxなど）が起動し、ファイルが開きます。

### 画面には何も表示されない

ブラウザでHTMLファイルを開いても、画面は真っ白のままです。これは正常な動作です。

`console.log()` は、コンソールに文字を出力する命令です。Webページの画面に表示するわけではありません。画面に何かを表示するには、別の方法が必要ですが、それは次回以降で学びます。

今は「画面が白いのは正常」と覚えておいてください。

---

## コンソールを開く

JavaScriptの出力を確認するには、開発者ツールのコンソールを開く必要があります。

### F12キーでコンソールを開く

最も簡単な方法は、キーボードの `F12` キーを押すことです。

1. ブラウザでHTMLファイルを開いた状態にします
2. キーボードの `F12` キーを押します
3. 開発者ツールが画面の右側または下側に表示されます
4. 「Console」タブをクリックします

Macの場合は `Cmd + Option + J` でも開くことができます。

### 他の方法で開発者ツールを開く

`F12` キー以外にも、いくつかの方法があります。

**右クリックメニューから開く**

1. ブラウザの画面上で右クリックします
2. 「検証」または「要素の検証」を選択します
3. 開発者ツールが開きます
4. 「Console」タブをクリックします

**ブラウザのメニューから開く**

Chromeの場合は、右上の三点メニュー → 「その他のツール」 → 「デベロッパーツール」で開けます。

### 出力を確認する

コンソールを開くと、`first.html` に書いた `console.log()` の出力が表示されているはずです。

```
成功！
```

この文字が表示されていれば、JavaScriptが正しく実行されています。

もし表示されていない場合は、前回のレッスンで作成した `first.html` の内容を確認してください。

## コードを変更して再実行する

プログラミングでは、コードを書く → 実行する → 結果を確認する → 修正する、というサイクルを繰り返します。このサイクルを実際に体験してみましょう。

### コードを変更する

`first.html` の内容を変更してみましょう。

1. VSCode（またはメモ帳）で `first.html` を開きます
2. `console.log("成功！");` の部分を変更します

例えば、次のように変更してみてください。

```html
<script>
console.log("Hello, World!");
</script>
```

### ファイルを保存する

変更したら、必ずファイルを保存します。

- `Ctrl + S`（Macの場合は `Cmd + S`）を押します

保存しないと、変更がファイルに反映されません。ブラウザで開いても、古いコードが実行されてしまいます。

これは初心者がよくやるミスです。「コードを変更したのに結果が変わらない」という場合は、まず保存を確認してください。

### ブラウザをリロードする

ファイルを保存したら、ブラウザで結果を確認します。このとき、ブラウザを「リロード」（再読み込み）する必要があります。

**リロードの方法**

1. ブラウザのアドレスバーの左にある「更新」ボタン（円形の矢印）をクリックします
2. または、`F5` キーを押します
3. または、`Ctrl + R`（Macの場合は `Cmd + R`）を押します

リロードすると、ブラウザはHTMLファイルを最初から読み込み直し、JavaScriptを再実行します。

コンソールを確認すると、新しいメッセージ「Hello, World!」が表示されているはずです。

---

## リロードの意味

### なぜリロードが必要なのか

ブラウザは、HTMLファイルを一度読み込むと、その内容をメモリに保存します。ファイルを変更しても、ブラウザは自動的に変更を検知しません。

そのため、ファイルを変更したら、ブラウザに「もう一度ファイルを読み込んでほしい」と伝える必要があります。これがリロードです。

### リロードの流れ

1. ブラウザがHTMLファイルを読み込む
2. `<script>` タグを見つける
3. JavaScriptコードを実行する
4. `console.log()` がコンソールに出力される

リロードするたびに、この流れが最初から実行されます。つまり、リロードするたびにJavaScriptが再実行されます。

### 注意：コンソールの履歴

リロードすると、コンソールの表示がクリアされて新しい出力だけが表示される場合と、古い出力の下に新しい出力が追加される場合があります。

これはブラウザの設定によって異なります。表示が混乱する場合は、コンソールの上部にある「クリア」ボタン（禁止マークのアイコン）をクリックして、表示をクリアできます。

## 開発サイクルを練習する

ここまでの流れを5回練習して、体に覚えさせましょう。プログラミングでは、この「編集 → 保存 → リロード → 確認」のサイクルを何百回、何千回と繰り返します。

### 5つの違うメッセージを試す

以下の5つのメッセージを順番に試してください。それぞれ、コードを変更 → 保存 → リロード → 確認、の手順を行います。

**1回目**

```html
<script>
console.log("JavaScript学習中");
</script>
```

**2回目**

```html
<script>
console.log("今日は良い天気です");
</script>
```

**3回目**

```html
<script>
console.log(100 + 200);
</script>
```

計算結果の `300` が表示されます。

**4回目**

```html
<script>
console.log("答えは");
console.log(50 * 2);
</script>
```

2行の出力が表示されます。

**5回目**

```html
<script>
console.log("1 + 1 = ");
console.log(1 + 1);
console.log("計算完了");
</script>
```

3行の出力が表示されます。

### この練習の目的

この練習を通じて、以下のことが自然にできるようになります。

- VSCodeとブラウザの切り替え
- ファイルの保存操作
- ブラウザのリロード操作
- コンソールでの結果確認

これらの操作は、今後のすべてのレッスンで使います。スムーズにできるようになるまで練習してください。

## よくある問題と対処法

### 変更が反映されない

**原因1：保存していない**

VSCodeのタブに白い丸（●）が表示されている場合は、ファイルが保存されていません。`Ctrl + S` で保存してください。

**原因2：リロードしていない**

ブラウザを `F5` でリロードしてください。ただ画面を見ているだけでは、変更は反映されません。

**原因3：別のファイルを編集している**

開いているファイルが本当に `first.html` か確認してください。同じ名前のファイルが複数ある場合、間違ったファイルを編集している可能性があります。

### コンソールに何も表示されない

**原因1：タグが間違っている**

`<script>` と `</script>` のスペルを確認してください。`<scritp>` のようなタイプミスがあると動きません。

**原因2：構文エラーがある**

コンソールに赤いエラーメッセージが表示されていませんか。エラーがある場合は、その内容を確認してコードを修正してください。

**原因3：ファイルの拡張子が違う**

ファイル名が `first.html` ではなく `first.html.txt` になっていませんか。拡張子が `.html` であることを確認してください。

### エラーメッセージの読み方

コンソールに赤いテキストでエラーメッセージが表示されることがあります。これは、JavaScriptのコードに問題があることを示しています。

よくあるエラーの例を見てみましょう。

**Uncaught SyntaxError: Unexpected token**

コードの書き方に問題があります。括弧の閉じ忘れや、引用符の閉じ忘れがないか確認してください。

**Uncaught ReferenceError: xxx is not defined**

存在しない名前を使おうとしています。タイプミスがないか確認してください。例えば `consolelog` と書いていませんか。正しくは `console.log` です。

エラーメッセージは英語ですが、慣れてくると原因がわかるようになります。今は「赤いメッセージ = 何か問題がある」と覚えておいてください。

## 練習問題

### 課題：開発サイクルを完全に習得する

以下の手順を実行して、開発サイクルを完全に身につけてください。

### 保存場所

`exercises/lesson-005/index.html` を使用してください。このファイルは既に用意されています。

### 進め方

1. VSCode（またはメモ帳）で `exercises/lesson-005/index.html` を開きます
2. `<script>` タグの中にコードを入力して保存します
3. ブラウザで開いてリロードして結果を確認します
4. コンソールの出力が正しいことを確認します

### 課題1：自己紹介を出力する

自分の名前、年齢、住んでいる都道府県を出力してください。

```html
<script>
console.log("名前：○○");
console.log("年齢：○○歳");
console.log("住所：○○県");
</script>
```

○○の部分を自分の情報に置き換えてください。

### 課題2：今日の予定を出力する

今日やることを3つ出力してください。

```html
<script>
console.log("今日の予定");
console.log("1. ○○");
console.log("2. ○○");
console.log("3. ○○");
</script>
```

### 課題3：計算結果を出力する

100から1を引き続けて、5回の計算結果を出力してください。

```html
<script>
console.log(100 - 1);
console.log(100 - 1 - 1);
console.log(100 - 1 - 1 - 1);
console.log(100 - 1 - 1 - 1 - 1);
console.log(100 - 1 - 1 - 1 - 1 - 1);
</script>
```

期待される出力は `99`、`98`、`97`、`96`、`95` です。

---

**重要なポイント**

各課題で「編集 → 保存 → リロード → 確認」のサイクルを確実に行ってください。このサイクルがスムーズにできるようになることが、今回の最も重要な目標です。
