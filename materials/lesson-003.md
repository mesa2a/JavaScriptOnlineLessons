## 四則演算

JavaScriptは計算機としても使えます。実は、ブラウザのコンソールは非常に高機能な電卓として活用できます。スマートフォンの電卓アプリと違って、複雑な計算式を一度に入力できるので、とても便利です。

`console.log` の括弧の中に計算式を書くと、計算結果が表示されます。前回は括弧の中に文字列を入れましたが、今回は数字と計算式を入れてみましょう。

**重要なポイント：**
- 数字を計算する時は、ダブルクォーテーション（`"`）で囲みません
- 計算式をそのまま `console.log()` の括弧の中に書きます
- JavaScriptが自動的に計算して、結果を表示してくれます

### 足し算（+）

最も基本的な計算、足し算から始めましょう。足し算には `+` 記号を使います。

**やってみよう：**
ブラウザのコンソールを開いて（F12キー → Consoleタブ）、以下を入力してEnterを押してください。

```javascript
console.log(1 + 1)
```

**実行結果**
```
2
```

素晴らしい！`1 + 1` という計算式が実行され、その結果である `2` が表示されました。

**もっと大きな数字でもやってみましょう：**

```javascript
console.log(12345 + 67890)
```

**実行結果**
```
80235
```

電卓で打つよりも、式をそのまま書けるので直感的です。コンソールは瞬時に計算してくれます。

**練習：** 自分の好きな数字を2つ足してみましょう。たとえば、誕生日の日と月を足してみるのも面白いですね。

### 引き算（-）

引き算には `-` 記号を使います。マイナス記号はキーボードの「ほ」のキーにあります。

```javascript
console.log(100 - 50)
```

**実行結果**
```
50
```

引き算の結果がマイナスになることもあります。

```javascript
console.log(50 - 100)
```

**実行結果**
```
-50
```

JavaScriptは負の数も正しく扱えます。

### 掛け算（*）

掛け算は、数学で使う `×` ではなく、**アスタリスク `*`** を使います。

**キーボードでの入力方法：**
- `Shift` キーを押しながら `:` キー（「け」のキー）を押します
- 記号は `*` です（星印のような形）

**なぜ `×` じゃないの？**
プログラミング言語が英語圏で生まれたためです。英語のキーボードには `×` がないため、代わりにアスタリスク `*` を使うようになりました。最初は違和感があるかもしれませんが、すぐに慣れます。

**やってみよう：**

```javascript
console.log(7 * 7)
```

**実行結果**
```
49
```

九九の計算も簡単にできます。

```javascript
console.log(8 * 9)
```

**実行結果**
```
72
```

**よくある間違い：**
```javascript
// ❌ 間違い：×を使ってしまう
console.log(7 × 7)  // エラーになります

// ✅ 正しい：*を使う
console.log(7 * 7)  // 49
```

### 割り算（/）

割り算は、数学で使う `÷` ではなく、**スラッシュ `/`** を使います。

**キーボードでの入力方法：**
- スラッシュはキーボードの「め」のキーにあります
- 記号は `/` です（右に傾いた斜め線）

**やってみよう：**

```javascript
console.log(100 / 4)
```

**実行結果**
```
25
```

きれいに割り切れました！

**割り切れない場合はどうなる？**

割り切れない場合は、小数で表示されます。

```javascript
console.log(10 / 3)
```

**実行結果**
```
3.3333333333333335
```

JavaScriptは小数点以下もしっかり計算してくれます。

**豆知識：**
コンピュータの仕組み上、小数の計算には若干の誤差が生じることがあります。たとえば `10 / 3` の結果は数学的には `3.333...` と無限に続きますが、コンピュータは有限の桁数で表現するため、最後の方の数字が少し変わることがあります。日常的な計算では気にする必要はありません。

### 🚨 超重要：数字はクォーテーションで囲まない

ここで初心者が最もよく間違えるポイントを説明します。

**計算するときは、数字をダブルクォーテーションで囲みません。**

**正しい例（計算される）：**

```javascript
console.log(1 + 1)
```

**実行結果**
```
2
```

これは数字の足し算なので、正しく計算されて結果は `2` です。

**間違った例（計算されない）：**

```javascript
console.log("1" + "1")
```

**実行結果**
```
11
```

あれ？ 結果が `11` になってしまいました。これは計算ではなく、文字列の `"1"` と `"1"` を「くっつけた」だけです。

**図で理解しよう：**

```
数字の足し算：    1  +  1  →  2 （計算される）
文字列の連結：  "1" + "1" → "11" （くっつけられる）
```

**なぜこうなるの？**

JavaScriptでは：
- クォーテーション（`"`）なし → **数字**として扱う → 計算できる
- クォーテーション（`"`）あり → **文字**として扱う → 計算されない（連結される）

レッスン2で学んだように、文字列（文字のデータ）はダブルクォーテーションで囲みました。数字も同じようにクォーテーションで囲んでしまうと、「数字のような見た目の文字」になってしまい、計算できなくなるのです。

**覚え方：**
- 計算したい → クォーテーションなし
- 文字として表示したい → クォーテーションあり

この違いは、プログラミングを学ぶ上で非常に重要な概念です。**数字と文字列は異なるデータ型**であり、同じ `+` 記号でも動作が変わります。

## 演算子の種類

計算に使う記号を「演算子」といいます。JavaScriptで使える主な演算子を紹介します。

| 演算子 | 意味 | 例 | 結果 |
|--------|------|-----|------|
| + | 足し算 | 5 + 3 | 8 |
| - | 引き算 | 10 - 4 | 6 |
| * | 掛け算 | 6 * 7 | 42 |
| / | 割り算 | 20 / 5 | 4 |
| % | 余り | 10 % 3 | 1 |

### 余りを求める演算子（%）

`%` は割り算の余りを求める演算子です。「モジュロ演算子」または「剰余演算子」とも呼ばれます。

**「余り」って何？**

たとえば、10個のクッキーを3人で分けるとします。
- 1人3個ずつ配ると → 3 × 3 = 9個使う
- 手元に残るのは → 10 - 9 = **1個**

この「残った1個」が「余り」です。

**やってみよう：**

```javascript
console.log(10 % 3)
```

**実行結果**
```
1
```

10を3で割ると、余りは1です。`%` 演算子は、この余りの部分だけを教えてくれます。

**偶数・奇数の判定に使える！**

```javascript
console.log(7 % 2)
```

**実行結果**
```
1
```

7を2で割ると余りは1です。奇数は2で割ると必ず1余ります。

```javascript
console.log(8 % 2)
```

**実行結果**
```
0
```

8を2で割ると余りは0です。偶数は2で割り切れるので、余りは0になります。

**プログラミングではよく使う！**

日常生活ではあまり使わない計算かもしれませんが、プログラミングでは頻繁に使います。

**実用例：**
- 「5個ずつ箱に入れたら何個余るか」
- 時計の計算（13時 = 1時、24時 = 0時）
- 曜日の計算（7日で1週間が繰り返す）
- 偶数・奇数の判定
- リストの要素を順番に表示する（インデックスを周期的に変える）

## 計算の優先順位

数学と同じように、JavaScriptでも**掛け算・割り算は足し算・引き算より先に計算**されます。これを「演算子の優先順位」といいます。

**例題で理解しよう：**

```javascript
console.log(2 + 3 * 4)
```

**実行結果**
```
14
```

**どうやって計算されたか：**

```
ステップ1: 掛け算を先に計算
2 + 3 * 4
2 + 12

ステップ2: 残った足し算を計算
2 + 12 = 14
```

左から順番に計算すると `(2 + 3) * 4 = 5 * 4 = 20` となりそうですが、そうはなりません。**掛け算が優先**されるので、`3 * 4` を先に計算します。

**もう一つ例を見てみましょう：**

```javascript
console.log(10 - 6 / 2)
```

**実行結果**
```
7
```

**計算の順序：**

```
ステップ1: 割り算を先に計算
10 - 6 / 2
10 - 3

ステップ2: 残った引き算を計算
10 - 3 = 7
```

まず `6 / 2 = 3` が計算され、次に `10 - 3 = 7` となります。

**優先順位まとめ：**
1. **高い（先に計算）**: `*`（掛け算）、`/`（割り算）、`%`（余り）
2. **低い（後で計算）**: `+`（足し算）、`-`（引き算）

### 括弧を使って優先順位を変える

計算の順番を変えたい場合は、**括弧 `()`** を使います。括弧の中が**最優先**で計算されます。

**括弧なしの場合：**

```javascript
console.log(2 + 3 * 4)
```

**実行結果**
```
14  // 先に 3 * 4 = 12、次に 2 + 12 = 14
```

**括弧ありの場合：**

```javascript
console.log((2 + 3) * 4)
```

**実行結果**
```
20  // 先に (2 + 3) = 5、次に 5 * 4 = 20
```

**計算の順序が変わった！**

```
括弧なし: 2 + 3 * 4 = 2 + 12 = 14
括弧あり: (2 + 3) * 4 = 5 * 4 = 20
```

括弧の中の `2 + 3` が先に計算され、その後 `5 * 4` となります。

**複雑な計算式の例：**

```javascript
console.log((10 + 5) * (8 - 3))
```

**実行結果**
```
75
```

**計算の順序：**

```
ステップ1: 左の括弧を計算
(10 + 5) * (8 - 3)
15 * (8 - 3)

ステップ2: 右の括弧を計算
15 * (8 - 3)
15 * 5

ステップ3: 掛け算を計算
15 * 5 = 75
```

**括弧を積極的に使おう！**

複雑な計算をするときは、括弧を積極的に使うことをお勧めします。

**メリット：**
- 計算の意図が明確になる
- 間違いを防げる
- 後からコードを読み返したときにも理解しやすい

**括弧の優先順位まとめ：**
1. **最優先**: `()`（括弧）
2. **高い**: `*`、`/`、`%`
3. **低い**: `+`、`-`

## 実用的な計算例

ここまで学んだ知識を使って、実用的な計算をしてみましょう。

### 年齢を日数に変換

自分の年齢が何日に相当するか計算してみましょう。1年は365日なので、年齢に365を掛けます。

例えば20歳の場合、

```javascript
console.log(20 * 365)
```

**実行結果**
```
7300
```

20歳は約7,300日です。7,000日以上生きてきたと考えると、なんだか感慨深いものがあります。ただし、この計算は閏年を考慮していない簡易的なものです。

### 年齢を時間に変換

日数に24を掛けると時間になります。1日は24時間だからです。

```javascript
console.log(20 * 365 * 24)
```

**実行結果**
```
175200
```

20歳は約175,200時間です。17万時間以上を過ごしてきたことになります。

### 年齢を分に変換

時間に60を掛けると分になります。

```javascript
console.log(20 * 365 * 24 * 60)
```

**実行結果**
```
10512000
```

20歳は約10,512,000分です。1千万分を超えています。

### 年齢を秒数に変換

さらに60を掛けると秒数になります。

```javascript
console.log(20 * 365 * 24 * 60 * 60)
```

**実行結果**
```
630720000
```

20歳は約630,720,000秒、つまり約6億3千万秒です。

### 計算式を分解して理解する

先ほどの計算式を分解してみましょう。

```
年齢 * 365 * 24 * 60 * 60

= 年齢 * (1年の日数) * (1日の時間) * (1時間の分) * (1分の秒)
= 年齢 * 365日 * 24時間 * 60分 * 60秒
```

このように、計算式には意味があります。何を計算しているのか理解しながらコードを書くことが大切です。

## 練習問題

### 課題：人生の秒数計算

自分の年齢を秒数に変換してコンソールに表示しましょう。

### 手順

1. ブラウザでF12キーを押して開発者ツールを開く
2. Consoleタブをクリック
3. `console.log(1 + 1)` で足し算を試す
4. `console.log(100 - 50)` で引き算を試す
5. `console.log(7 * 7)` で掛け算を試す
6. `console.log(100 / 4)` で割り算を試す
7. 自分の年齢を秒数に変換する式を入力する

### 確認方法

自分の年齢に応じた秒数が表示されれば成功です。

---

**ヒント**

計算式の組み立て方を整理しておきます。

- 1年 = 365日
- 1日 = 24時間
- 1時間 = 60分
- 1分 = 60秒

これらを掛け合わせると、「年齢 × 365 × 24 × 60 × 60」という式になります。

例えば30歳なら `console.log(30 * 365 * 24 * 60 * 60)` と入力します。自分の年齢の部分を実際の数字に置き換えてください。

---

**解答例**

25歳の場合のコード

```javascript
console.log(25 * 365 * 24 * 60 * 60)
```

表示される結果

```
788400000
```

25歳は約7億8千万秒です。

余裕があれば、以下の計算も試してみてください。

**身長をインチに変換**

1インチは約2.54cmです。身長（cm）を2.54で割るとインチになります。

```javascript
console.log(170 / 2.54)
```

**実行結果**
```
66.92913385826772
```

170cmは約66.9インチです。

**体重をポンドに変換**

1kgは約2.205ポンドです。体重（kg）に2.205を掛けるとポンドになります。

```javascript
console.log(60 * 2.205)
```

**実行結果**
```
132.3
```

60kgは約132.3ポンドです。

## まとめ

### 今回学んだこと

お疲れ様でした。今回のレッスンでは、以下のことを学びました。

**キーポイント1：四則演算**

JavaScriptで計算ができます。足し算は `+`、引き算は `-`、掛け算は `*`、割り算は `/` を使います。数字を計算する場合は、クォーテーションで囲みません。クォーテーションで囲むと文字列になり、計算ではなく文字の連結になってしまいます。

**キーポイント2：演算子の種類**

計算に使う記号を演算子といいます。基本の四則演算に加えて、`%` は余りを求める演算子です。この演算子は、偶数・奇数の判定や周期的な計算に便利です。

**キーポイント3：計算の優先順位**

掛け算・割り算は足し算・引き算より先に計算されます。計算の順番を変えたい場合は、括弧 `()` を使います。複雑な計算式では、括弧を使って意図を明確にすると間違いを防げます。
