## alertとは

### 画面に直接表示する方法

これまでは `console.log()` を使って、開発者ツールのコンソールに文字を出力していました。しかし、コンソールはわざわざ開発者ツールを開かないと見ることができません。

`alert()` を使うと、画面に直接ポップアップを表示できます。開発者ツールを開かなくても、メッセージを見ることができます。

### alertの基本的な使い方

`alert()` は、括弧の中に表示したいメッセージを書きます。

```javascript
alert("こんにちは");
```

このコードを実行すると、ブラウザの画面に「こんにちは」というメッセージが表示されたポップアップが出現します。

### console.logとの違い

`console.log()` と `alert()` には、いくつかの重要な違いがあります。

**表示される場所**

- `console.log()` はコンソールに表示されます（開発者ツールを開く必要があります）
- `alert()` は画面にポップアップとして表示されます

**プログラムの動作**

- `console.log()` は表示後すぐに次の処理に進みます
- `alert()` は「OK」ボタンを押すまで次の処理に進みません

**使い分け**

- `console.log()` は開発中のデバッグ（動作確認）に使います
- `alert()` はユーザーへの通知に使います

## alertを使ってみよう

実際にalertを使ってみましょう。

### 最初のalert

`first.html` を開いて、次のコードを入力してください。

```html
<script>
alert("こんにちは");
</script>
```

ファイルを保存して、ブラウザでリロードします。

すると、画面の中央にポップアップが表示されます。「こんにちは」というメッセージと「OK」ボタンがあります。

「OK」ボタンをクリックすると、ポップアップが閉じます。

### alertの動作を確認する

alertの重要な特徴は、「OK」ボタンを押すまで次の処理が止まることです。これを確認してみましょう。

```html
<script>
alert("最初のメッセージ");
alert("2番目のメッセージ");
alert("3番目のメッセージ");
</script>
```

このコードを実行すると、以下のように動作します。

1. 「最初のメッセージ」が表示されます
2. 「OK」をクリックします
3. 「2番目のメッセージ」が表示されます
4. 「OK」をクリックします
5. 「3番目のメッセージ」が表示されます
6. 「OK」をクリックします
7. プログラムが終了します

このように、alertは順番に表示され、前のalertを閉じないと次のalertは表示されません。

### 数値や計算結果も表示できる

alertは文字列だけでなく、数値や計算結果も表示できます。

```html
<script>
alert(100);
alert(50 + 30);
alert(10 * 5);
</script>
```

それぞれ「100」「80」「50」が表示されます。

## confirmとは

### 確認ダイアログ

`confirm()` は、alertに似ていますが、「OK」と「キャンセル」の2つのボタンがあります。ユーザーに確認を求めるときに使います。

```javascript
confirm("元気ですか？");
```

このコードを実行すると、「元気ですか？」というメッセージと、「OK」「キャンセル」の2つのボタンがあるポップアップが表示されます。

### alertとconfirmの違い

**alert**

- 「OK」ボタンのみ
- 一方的にメッセージを伝える
- ユーザーは「OK」を押すしかない

**confirm**

- 「OK」と「キャンセル」の2つのボタン
- ユーザーに選択を求める
- ユーザーは「はい」か「いいえ」を選べる

### confirmを使ってみよう

```html
<script>
confirm("元気ですか？");
</script>
```

このコードを実行すると、「元気ですか？」というメッセージと2つのボタンが表示されます。

今の段階では、どちらのボタンを押しても結果は同じです。confirmの戻り値（ユーザーの選択結果）を使う方法は、後のレッスンで学びます。

今は「confirmには2つのボタンがある」ということを覚えておいてください。

### alertとconfirmを組み合わせる

alertとconfirmを組み合わせて使うこともできます。

```html
<script>
alert("これからアンケートを始めます");
confirm("続けてもいいですか？");
alert("アンケートを開始します");
</script>
```

このコードは以下のように動作します。

1. 「これからアンケートを始めます」が表示されます（OK）
2. 「続けてもいいですか？」が表示されます（OK/キャンセル）
3. 「アンケートを開始します」が表示されます（OK）

## 3コマ物語を作ろう

alertを連続して使うと、紙芝居のような物語を作ることができます。

### 物語の例

```html
<script>
alert("ある日、犬がいました。");
alert("犬は散歩に出かけました。");
alert("そして、新しい友達に出会いました。");
</script>
```

このコードを実行すると、3つのメッセージが順番に表示されます。ユーザーは「OK」をクリックして次のメッセージに進みます。

### 物語をより面白くする

メッセージを工夫すると、より楽しい物語になります。

```html
<script>
alert("朝、目が覚めました。");
alert("窓の外を見ると、雪が降っていました。");
alert("今日は雪だるまを作ろう！");
</script>
```

### 計算を使った物語

数値と計算を組み合わせた物語も作れます。

```html
<script>
alert("りんごを5個持っています。");
alert("友達に2個あげました。");
alert("残りは...");
alert(5 - 2);
alert("3個です！");
</script>
```

このように、alertを使うと簡単なインタラクティブなコンテンツを作ることができます。

## alertとconsole.logの使い分け

ここで、alertとconsole.logの使い分けについて整理しましょう。

### 開発中はconsole.logを使う

プログラムを開発しているとき、変数の値や計算結果を確認したい場面がたくさんあります。このような場合は `console.log()` を使います。

理由は以下の通りです。

- alertは毎回「OK」をクリックしなければならず、面倒です
- console.logなら一度に複数の出力を確認できます
- console.logは開発者向けのツールです

### ユーザーへの通知はalertを使う

ユーザーに重要なメッセージを伝えたいときは `alert()` を使います。

- ユーザーは開発者ツールを開かないからです
- alertなら必ず目に入ります
- 重要なメッセージを見逃すことがありません

### 今後の学習では

今後のレッスンでは、主に `console.log()` を使って結果を確認します。alertは「ユーザーに見せるメッセージ」がある場合に使います。
