# Lesson 001: ブラウザと友達になる

---

## はじめに

JavaScriptの学習を始めてくださり、ありがとうございます。

「プログラミングって難しそう」「自分にできるかな」と不安に思っている方もいるかもしれません。大丈夫です。このカリキュラムは、プログラミングが全くの初めての方でも、一歩ずつ着実にスキルを身につけられるように設計されています。

最初は誰でも初心者です。今プロとして活躍しているエンジニアも、かつては「Hello」を画面に表示することから始めました。あなたも今日、その最初の一歩を踏み出します。

### このカリキュラムで作れるようになるもの

このカリキュラムを最後まで学ぶと、以下のようなアプリケーションを自分で作れるようになります。

- **ToDoリストアプリ** - タスクの追加・削除・完了管理ができる
- **クイズゲーム** - 問題を出題し、正解・不正解を判定する
- **電卓アプリ** - 四則演算ができる計算機
- **天気予報アプリ** - 外部のデータを取得して天気を表示する
- **チャットアプリ** - リアルタイムでメッセージをやり取りする

最初は信じられないかもしれませんが、一つ一つのレッスンを積み重ねていけば、必ずここまで到達できます。

### 学習のコツ

プログラミング学習を成功させるために、以下の3つを心がけてください。

**毎日少しずつ続ける**

一度に何時間も勉強するより、毎日30分でも継続する方が効果的です。プログラミングは「慣れ」が大切な分野です。毎日コードに触れることで、自然と身についていきます。

**必ず手を動かす**

教材を読むだけでは身につきません。必ず自分でコードを打ち、実行してください。「見る」と「やる」では、理解度が全く違います。最初は写すだけでも構いません。手を動かすことが大切です。

**間違いを恐れない**

プログラミングでエラーが出るのは当たり前のことです。プロのエンジニアでも毎日エラーと向き合っています。エラーは「ここが違うよ」と教えてくれる親切なメッセージです。何度間違えても大丈夫。やり直せるのがプログラミングの良いところです。

それでは、最初の一歩を踏み出しましょう。

## 今回の学習

### なぜJavaScriptを学ぶのか

普段使っているWebサービスのほとんどは、JavaScriptで動いています。具体的な例を見てみましょう。

**YouTube**

YouTubeで動画を見るとき、再生ボタンを押すと動画が始まります。一時停止、音量調整、全画面表示の切り替え。これらはすべてJavaScriptで実現されています。また、動画を見終わると「おすすめ動画」が表示されますが、これもJavaScriptがあなたの視聴履歴を分析して表示しています。コメントを投稿するとページを再読み込みしなくても即座に表示されます。これもJavaScriptの力です。

**Amazon**

Amazonで買い物をするとき、「カートに入れる」ボタンを押すと、ページ全体を読み込み直さなくてもカートの数字が増えます。商品ページを見ていると「この商品を買った人はこちらも買っています」という表示が出ます。検索ボックスに文字を入力すると、候補がリアルタイムで表示されます。これらの便利な機能は、すべてJavaScriptで作られています。

**Twitter/X**

ツイートを投稿すると、すぐにタイムラインに表示されます。いいねボタンを押すと、ハートの色が変わって数字が増えます。新しいツイートがあると「○件の新着ツイート」と通知が出て、クリックすると表示されます。スクロールすると自動的に次のツイートが読み込まれます。これらの「リアルタイム感」のある機能は、JavaScriptなしには実現できません。

**JavaScriptを学ぶとできること**

これらの機能はすべてJavaScriptで実現されています。JavaScriptを学ぶことで、こうした「動きのあるWebサイト」を自分で作れるようになります。静的な文字と画像だけのページではなく、ユーザーの操作に反応する、生き生きとしたWebサイトを作れるようになるのです。

## プログラミングとは何か

プログラミングとは、コンピュータに「こうしてほしい」と指示を書くことです。

人間同士は日本語や英語で会話します。「お茶を持ってきて」とお願いすれば、相手は台所に行ってお茶を持ってきてくれます。同じように、コンピュータにも言葉で指示を出すことができます。ただし、コンピュータは日本語や英語をそのまま理解することはできません。コンピュータが理解できる特別な言葉、それが「プログラミング言語」です。

今回学ぶJavaScriptも、そのプログラミング言語の一つです。世界中で最も使われているプログラミング言語の一つで、Webサイトやアプリケーションを作るのに欠かせない言語です。

### 身近な例

テレビのリモコンを想像してください。

電源ボタンを押すとテレビがつく。チャンネルボタンを押すとチャンネルが変わる。音量ボタンを押すと音が大きくなったり小さくなったりする。これは、リモコンのボタンを押すという「指示」に対して、テレビが「実行」しているということです。

プログラミングも同じ仕組みです。

私たちが「命令（コード）を書く」と、コンピュータがそれを「実行」します。今回は「画面に文字を表示して」という命令を書いてみます。とてもシンプルな命令ですが、これがプログラミングの第一歩です。

## 開発者ツールを使ってみよう

JavaScriptを実行するには、ブラウザの「開発者ツール」を使います。

「開発者ツール」と聞くと難しそうに感じるかもしれませんが、心配いりません。Chrome、Firefox、Edgeなどの普段使っているブラウザには、この機能が最初から入っています。特別なソフトをインストールする必要はありません。

開発者ツールは、Webサイトを作る人が使う便利な機能です。今回はその中の「コンソール」という機能を使って、JavaScriptのコードを実行してみます。

### コンソールを開く

それでは、実際にコンソールを開いてみましょう。以下の手順に従ってください。

**1. Chromeを開く**

普段使っているChromeブラウザを開きます。まだChromeをインストールしていない場合は、「Chrome ダウンロード」で検索してインストールしてください。

開くページはどこでも大丈夫です。Googleのトップページや、このページを開いたままでも構いません。

**2. F12キーを押す**

キーボードのF12キーを押します。ノートパソコンの場合、Fnキーを押しながらF12を押す必要があるかもしれません。

Macの場合は `Cmd + Option + I`（3つのキーを同時に押す）です。

画面の右側または下に、新しいパネルが開きます。これが「開発者ツール」です。最初は情報量が多くて驚くかもしれませんが、今は気にしなくて大丈夫です。

**3. Consoleタブをクリック**

開いたパネルの上部に「Elements」「Console」「Sources」などのタブがあります。この中から「Console」をクリックしてください。

「Console」タブが見つからない場合は、タブの右端に「>>」というマークがあるので、そこをクリックすると隠れているタブが表示されます。

Consoleタブをクリックすると、文字を入力できる画面が表示されます。これがJavaScriptを入力して実行する場所です。青い「>」マークの横にカーソルが点滅していれば、準備完了です。

### 最初の命令を実行する

コンソールが開いたら、いよいよ最初の命令を入力してみましょう。

**入力するコード：**
```javascript
console.log("Hello")
```

上のコードをそのまま入力してください。入力が終わったら、Enterキーを押します。

**実行結果：**
```
Hello
```

画面に「Hello」と表示されましたか？

おめでとうございます。これがあなたの最初のプログラムです。たった1行のコードですが、あなたは今、コンピュータに指示を出し、それを実行させることに成功しました。これがプログラミングです。

うまくいかなかった場合は、以下を確認してください。
- `console.log` がすべて小文字になっているか
- 括弧 `()` を忘れていないか
- `"Hello"` のダブルクォーテーションが半角になっているか

### コードの意味

先ほど入力したコードの意味を理解しましょう。

```javascript
console.log("Hello")
```

このコードは3つの部分に分けられます。

**console.log**

これは「コンソールに表示して」という命令です。`console` はコンソール画面を指し、`log` は「記録する・表示する」という意味です。この2つをドット（.）でつなげて、「コンソールに表示して」という命令になります。

**( )**

括弧は、命令に渡す内容（引数といいます）を囲むためのものです。「これを表示して」の「これ」を括弧の中に書きます。

**"Hello"**

表示したい文字です。文字を表示する場合は、必ずダブルクォーテーション（"）またはシングルクォーテーション（'）で囲む必要があります。これを「文字列」といいます。

つまり、`console.log("Hello")` は「コンソールに "Hello" という文字を表示して」という命令なのです。

## 練習問題

### 課題：初めてのJavaScript実行

ブラウザの開発者ツールを開いて、「Hello」をコンソールに表示させましょう。

### 手順

1. Chromeを開く
2. F12キーを押してみる
3. Consoleタブをクリック
4. `console.log("Hello")` と打つ
5. Enterを押す → Helloが表示される

### 確認方法

コンソールに「Hello」と表示されれば成功です。

---

**ヒント**

うまくいかない場合は、以下の点を確認してください。

- **大文字・小文字の区別**：`Console.log` ではなく `console.log` です。JavaScriptでは大文字と小文字が区別されます。
- **ダブルクォーテーション**：文字は必ず `"` （ダブルクォーテーション）で囲みましょう。全角の「"」ではなく、半角の `"` を使ってください。
- **括弧を忘れない**：`console.log` の後には必ず `()` が必要です。
- **スペルの確認**：`console` や `log` のスペルが間違っていないか確認してください。

---

**解答例**

コンソールに入力するコード

```javascript
console.log("Hello")
```

表示される結果

```
Hello
```

成功したら、`"Hello"` の部分を自分の好きな言葉に変えて、もう一度試してみましょう。例えば `console.log("こんにちは")` と入力すると、「こんにちは」と表示されます。
