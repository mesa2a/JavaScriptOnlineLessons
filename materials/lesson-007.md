## 変数とは

### データを保存する箱

プログラミングでは、データを保存しておいて後で使いたいことがよくあります。例えば、ユーザーの名前を保存しておいて、何度も表示したい場合です。

このとき使うのが「変数」です。変数は、データを保存しておく箱のようなものです。

### なぜ変数が必要なのか

変数を使わない場合と使う場合を比較してみましょう。

**変数を使わない場合**

```javascript
console.log("山田太郎さん、こんにちは");
console.log("山田太郎さん、今日は良い天気ですね");
console.log("山田太郎さん、また会いましょう");
```

この場合、「山田太郎」という名前を3回書いています。もし名前を「佐藤花子」に変えたい場合、3箇所すべてを修正しなければなりません。

**変数を使う場合**

```javascript
let name = "山田太郎";
console.log(name + "さん、こんにちは");
console.log(name + "さん、今日は良い天気ですね");
console.log(name + "さん、また会いましょう");
```

この場合、名前は最初の1箇所だけで定義しています。名前を変えたい場合は、`let name = "山田太郎"` の部分を変えるだけで済みます。

このように、変数を使うとコードの管理が楽になります。

### 変数の3つの要素

変数には3つの要素があります。

1. **名前**：変数を識別するための名前（例：name, age, price）
2. **値**：変数に保存されているデータ（例："山田太郎", 25, 100）
3. **型**：データの種類（例：文字列、数値）

## 変数を作成する

### letキーワード

JavaScriptで変数を作成するには、`let` というキーワードを使います。

```javascript
let name = "山田太郎";
```

このコードは、以下のことを行っています。

1. `name` という名前の変数を作成する
2. その変数に `"山田太郎"` という値を保存する

### 変数の作成と代入

変数の作成は「宣言」とも呼ばれます。`=` 記号を使って値を保存することを「代入」と言います。

```javascript
let age = 25;
```

このコードは、`age` という変数を宣言し、`25` という値を代入しています。

### 変数の値を取り出す

変数に保存した値は、変数名を書くことで取り出せます。

```javascript
let name = "山田太郎";
console.log(name);
```

このコードを実行すると、コンソールに「山田太郎」と表示されます。`console.log(name)` の部分で、`name` という変数から値を取り出して表示しています。

## 変数を使ってみよう

実際に変数を使ってみましょう。

### 名前を保存する

```html
<script>
let name = "山田太郎";
console.log(name);
</script>
```

このコードを `first.html` に入力して実行すると、コンソールに「山田太郎」と表示されます。

「山田太郎」の部分を自分の名前に変えてみてください。

### 年齢を保存する

```html
<script>
let age = 25;
console.log(age);
</script>
```

数値を保存する場合は、ダブルクォーテーション `"` は不要です。数値はそのまま書きます。

「25」の部分を自分の年齢に変えてみてください。

### 複数の変数を使う

複数の変数を同時に使うこともできます。

```html
<script>
let name = "山田太郎";
let age = 25;
console.log(name);
console.log(age);
</script>
```

このコードを実行すると、「山田太郎」と「25」が順番に表示されます。

### 変数をalertで表示する

変数の値は `alert()` でも表示できます。

```html
<script>
let name = "山田太郎";
alert(name);
</script>
```

このコードを実行すると、「山田太郎」というポップアップが表示されます。

## 変数の命名規則

変数には好きな名前をつけることができますが、いくつかのルールがあります。

### 使える文字

変数名には以下の文字が使えます。

- 英字（a-z、A-Z）
- 数字（0-9）
- アンダースコア（_）
- ドル記号（$）

ただし、数字で始めることはできません。

**正しい例**

```javascript
let name = "太郎";
let age1 = 25;
let user_name = "花子";
let $price = 100;
```

**間違った例**

```javascript
let 1age = 25;      // 数字で始まっている
let user-name = "花子";  // ハイフンは使えない
let my name = "太郎";    // スペースは使えない
```

### 予約語は使えない

JavaScriptには、特別な意味を持つ「予約語」があります。これらは変数名として使えません。

例えば、`let`、`if`、`for`、`function` などは予約語です。

```javascript
let let = 10;  // エラー：letは予約語
let if = 20;   // エラー：ifは予約語
```

### 大文字と小文字は区別される

JavaScriptでは、大文字と小文字は別の文字として扱われます。

```javascript
let name = "太郎";
let Name = "花子";
let NAME = "次郎";
```

この3つは、すべて別の変数です。ただし、紛らわしいので同じ単語の大文字小文字違いは避けましょう。

### 良い変数名の付け方

変数名は、その変数が何を表しているかがわかるようにつけましょう。

**良い例**

```javascript
let userName = "山田太郎";
let userAge = 25;
let productPrice = 1000;
```

**悪い例**

```javascript
let a = "山田太郎";
let b = 25;
let x = 1000;
```

`a`、`b`、`x` のような名前では、何を表しているかわかりません。

### キャメルケース

複数の単語を組み合わせた変数名を作るとき、JavaScriptでは「キャメルケース」という書き方がよく使われます。

キャメルケースでは、最初の単語は小文字で始め、2番目以降の単語は大文字で始めます。

```javascript
let firstName = "太郎";
let lastName = "山田";
let phoneNumber = "090-1234-5678";
```

この形がラクダ（camel）のこぶのように見えることから、キャメルケースと呼ばれています。

## 文字列と数値

変数に保存できるデータには、いくつかの種類があります。ここでは、文字列と数値について詳しく見てみましょう。

### 文字列

文字の並びを「文字列」と言います。文字列は `"` または `'` で囲みます。

```javascript
let message = "こんにちは";
let greeting = 'おはようございます';
```

どちらを使っても構いませんが、一般的には `"` がよく使われます。

### 数値

数値は `"` で囲まずにそのまま書きます。

```javascript
let age = 25;
let price = 1000;
let temperature = 23.5;
```

小数点を含む数値も保存できます。

### 文字列と数値の違い

文字列と数値は、見た目が同じでも異なる扱いを受けます。

```javascript
let a = "100";  // 文字列
let b = 100;    // 数値
```

`"100"` は文字列なので計算には使えません。`100` は数値なので計算に使えます。

この違いは、今後のレッスンで詳しく学びます。

## 自己紹介データを作ろう

5つの変数を使って、自己紹介データを作りましょう。

### 5つの変数を作成する

```html
<script>
let name = "山田太郎";
let age = 25;
let city = "東京";
let hobby = "読書";
let food = "ラーメン";

console.log(name);
console.log(age);
console.log(city);
console.log(hobby);
console.log(food);
</script>
```

このコードを実行すると、5つの値が順番にコンソールに表示されます。

それぞれの値を自分の情報に変えてみてください。

### alertで表示する

同じデータをalertで表示することもできます。

```html
<script>
let name = "山田太郎";
let age = 25;
let city = "東京";
let hobby = "読書";
let food = "ラーメン";

alert(name);
alert(age);
alert(city);
alert(hobby);
alert(food);
</script>
```

5つのポップアップが順番に表示されます。

## まとめ

### 今回学んだこと

**キーポイント1：変数とは**

変数は、データを保存しておく箱のようなものです。一度保存した値は、何度でも取り出して使うことができます。

**キーポイント2：変数の作成方法**

`let 変数名 = 値;` の形式で変数を作成します。`let` は変数を宣言するキーワード、`=` は値を代入する記号です。

**キーポイント3：命名規則**

変数名には英字、数字、アンダースコア、ドル記号が使えます。数字で始めることはできません。また、予約語は使えません。

**キーポイント4：良い変数名**

変数名は、その変数が何を表しているかがわかるようにつけましょう。キャメルケース（例：userName）がよく使われます。
