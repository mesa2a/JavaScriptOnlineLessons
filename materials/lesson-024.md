# Lesson 024: ミニプロジェクト

このレッスンでは、これまで学んだことを組み合わせて、実際に動くWebページを作ります。

## プロジェクトの目標

次の機能を持つインタラクティブなページを作成します。

1. 3つのボタンで背景色を変更する
2. クリック回数をカウントする
3. カウンターをリセットできる

## 必要な知識

このプロジェクトでは、次の知識を使います。

- `document.getElementById()`で要素を取得
- `textContent`で文字を変更
- `style.backgroundColor`で色を変更
- `onclick`でクリックイベントを処理
- `let`で変数を定義
- 関数を定義して処理をまとめる

## プロジェクトの仕様

### 1. 色を変更するボタン

3つのボタンを用意し、それぞれクリックすると表示エリアの背景色が変わるようにします。

- 赤ボタン: 背景色を赤にする
- 青ボタン: 背景色を青にする
- 緑ボタン: 背景色を緑にする

### 2. カウンター

ボタンをクリックした回数を表示します。

- 最初は0回
- どのボタンをクリックしても1増える
- 「リセット」ボタンで0に戻る

## 実装のヒント

### カウンターの管理

クリック回数を変数で管理します。

```javascript
let count = 0;
```

各色ボタンの関数の中で、カウントを1増やします。

```javascript
count = count + 1;
```

または、短く書くこともできます。

```javascript
count++;
```

## 完成例の動作

### 初期状態

- 表示エリアの背景色: 白（または指定なし）
- カウンター表示: 0

### 赤ボタンを1回クリック

- 表示エリアの背景色: 赤
- カウンター表示: 1

### 青ボタンを1回クリック

- 表示エリアの背景色: 青
- カウンター表示: 2

### 緑ボタンを1回クリック

- 表示エリアの背景色: 緑
- カウンター表示: 3

### リセットボタンをクリック

- 表示エリアの背景色: 白（または指定なし）
- カウンター表示: 0

## 必要な変数

次の変数が必要です。

```javascript
let count = 0;  // クリック回数
```

## 必要な関数

次の関数が必要です。

### setRed関数

赤ボタンがクリックされたときに実行される関数です。

1. `count`を1増やす
2. 表示エリアの背景色を赤にする
3. カウンター表示を更新する

### setBlue関数

青ボタンがクリックされたときに実行される関数です。

1. `count`を1増やす
2. 表示エリアの背景色を青にする
3. カウンター表示を更新する

### setGreen関数

緑ボタンがクリックされたときに実行される関数です。

1. `count`を1増やす
2. 表示エリアの背景色を緑にする
3. カウンター表示を更新する

### resetCounter関数

リセットボタンがクリックされたときに実行される関数です。

1. `count`を0に戻す
2. 表示エリアの背景色を白に戻す
3. カウンター表示を0に更新する

## HTML構造

次のような構造が必要です。

```html
<div id="display">表示エリア</div>
<p id="counter">0</p>
<button onclick="setRed()">赤</button>
<button onclick="setBlue()">青</button>
<button onclick="setGreen()">緑</button>
<button onclick="resetCounter()">リセット</button>
```

## 練習問題

次の要件を満たすページを作成してください。

1. id="display"の要素を用意する（表示エリア）
2. id="counter"の要素を用意し、初期値として「0」を表示する
3. 赤ボタンを用意し、クリックするとsetRed関数が実行されるようにする
4. 青ボタンを用意し、クリックするとsetBlue関数が実行されるようにする
5. 緑ボタンを用意し、クリックするとsetGreen関数が実行されるようにする
6. リセットボタンを用意し、クリックするとresetCounter関数が実行されるようにする
7. count変数を定義し、初期値を0にする
8. setRed関数を定義し、次の処理を行う
   - countを1増やす
   - id="display"の要素の背景色を赤にする
   - id="counter"の要素のtextContentをcountの値に更新する
9. setBlue関数を定義し、次の処理を行う
   - countを1増やす
   - id="display"の要素の背景色を青にする
   - id="counter"の要素のtextContentをcountの値に更新する
10. setGreen関数を定義し、次の処理を行う
    - countを1増やす
    - id="display"の要素の背景色を緑にする
    - id="counter"の要素のtextContentをcountの値に更新する
11. resetCounter関数を定義し、次の処理を行う
    - countを0に戻す
    - id="display"の要素の背景色を白にする
    - id="counter"の要素のtextContentを0に更新する

## ポイント

- 変数を使って状態を管理します
- 複数の関数を使って処理を分けます
- すべての関数から同じ変数にアクセスできます（グローバル変数）
- 同じような処理を繰り返し書くことで理解を深めます

- DOM操作（`getElementById`, `textContent`, `style`）
