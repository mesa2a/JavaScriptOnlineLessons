# レッスン33: 条件分岐入門

これまでのレッスンでは、プログラムは常に同じ処理を実行していました。しかし、実際のアプリケーションでは、状況に応じて異なる処理を行う必要があります。このレッスンでは、条件によって処理を分岐させる方法を学びます。

## 条件分岐とは

条件分岐とは、ある条件が満たされているかどうかによって、異なる処理を実行する仕組みのことです。例えば、以下のような状況があります。

- 年齢が18歳以上なら「大人」と表示する
- 点数が60点以上なら「合格」と表示する
- ボタンがクリックされた回数が10回を超えたら「たくさんクリックされました」と表示する

このような「もし〜なら〜する」という処理を、プログラムで実現するのが条件分岐です。

## if文の基本

JavaScriptでは、if文を使って条件分岐を行います。基本的な書き方は以下の通りです。

```javascript
if (条件) {
  // 条件が満たされたときに実行する処理
}
```

条件が満たされている場合、つまり条件が「true（真）」のときに、中括弧 { } の中の処理が実行されます。

## 実際の例: 年齢判定

年齢が18歳以上かどうかを判定するプログラムを作ってみましょう。

```javascript
let age = 20;

if (age >= 18) {
  console.log("大人です");
}
```

このプログラムでは、ageが18以上の場合に「大人です」と表示されます。

age >= 18という部分が条件です。>= は「以上」を意味する比較演算子です。

## 条件の真偽

条件は、trueまたはfalseという特殊な値に評価されます。これらの値を「真偽値（ブール値）」と呼びます。

```javascript
let age = 20;
console.log(age >= 18);  // true
```

age >= 18という式は、trueという値になります。このtrueという値によって、if文の中の処理が実行されるかどうかが決まります。

```javascript
let age = 15;
console.log(age >= 18);  // false
```

ageが15の場合、age >= 18という式はfalseになります。この場合、if文の中の処理は実行されません。

## 比較演算子

条件を作るために、以下のような比較演算子を使います。

- >= : 以上（左辺が右辺以上）
- <= : 以下（左辺が右辺以下）
- > : より大きい（左辺が右辺より大きい）
- < : より小さい（左辺が右辺より小さい）

```javascript
let age = 20;

if (age >= 18) {
  console.log("18歳以上です");
}

if (age > 18) {
  console.log("18歳より上です");
}
```

>= と > の違いに注意してください。>= は「等しい場合も含む」のに対し、> は「等しい場合は含まない」という違いがあります。

## ブロックとは

if文の中括弧 { } で囲まれた部分を「ブロック」と呼びます。

```javascript
if (age >= 18) {
  // ここがブロック
  console.log("大人です");
  console.log("選挙権があります");
}
```

ブロックの中には、複数の処理を書くことができます。条件が満たされた場合、ブロック内のすべての処理が順番に実行されます。

## 変数の値を変えて試す

同じif文でも、変数の値を変えることで、実行される処理が変わります。

```javascript
let age = 20;

if (age >= 18) {
  console.log("大人です");
}

age = 15;

if (age >= 18) {
  console.log("大人です");
}
```

最初のif文では「大人です」と表示されますが、2回目のif文では何も表示されません。なぜなら、2回目の時点でageは15になっており、15 >= 18はfalseだからです。

## DOMと組み合わせる

if文をDOM操作と組み合わせることで、条件に応じて表示を変更できます。

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>年齢判定</title>
  <script src="script.js"></script>
</head>
<body>
  <h1>年齢判定</h1>
  <button onclick="checkAge()">判定する</button>
  <p id="result"></p>
</body>
</html>
```

```javascript
function checkAge() {
  let age = 20;

  if (age >= 18) {
    const elem = document.getElementById("result");
    elem.textContent = "大人です";
  }
}
```

このプログラムでは、ボタンをクリックすると、ageが18以上の場合に「大人です」と表示されます。

## 実践例: 点数判定

点数が60点以上かどうかを判定するプログラムを作ってみましょう。

```javascript
function checkScore() {
  let score = 75;

  if (score >= 60) {
    const elem = document.getElementById("result");
    elem.textContent = "合格です";
  }
}
```

scoreが60以上の場合に「合格です」と表示されます。

## カウンターと組み合わせる

以前学んだカウンターと組み合わせることで、クリック回数に応じて表示を変更できます。

```javascript
let count = 0;

function addCount() {
  count++;
  const counter = document.getElementById("counter");
  counter.textContent = count;

  if (count >= 10) {
    const message = document.getElementById("message");
    message.textContent = "10回以上クリックされました";
  }
}
```

このプログラムでは、カウントが10以上になったときにメッセージが表示されます。

## 条件が満たされない場合

if文では、条件が満たされない場合は、ブロック内の処理は実行されません。何も起こりません。

```javascript
let age = 15;

if (age >= 18) {
  console.log("大人です");  // この行は実行されない
}

console.log("プログラム終了");  // この行は実行される
```

if文の条件がfalseの場合、ブロック内の処理はスキップされ、if文の後の処理が実行されます。

## まとめ

このレッスンでは、以下のことを学びました。

- if文を使って条件分岐ができる
- 条件はtrueまたはfalseに評価される
- 比較演算子（>=、<=、>、<）を使って条件を作る
- 条件が満たされた場合のみ、ブロック内の処理が実行される
- if文をDOM操作やカウンターと組み合わせられる
