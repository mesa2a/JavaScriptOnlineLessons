## 命令の順次実行

プログラムは、書いた順番に上から下へ実行されます。これを「順次実行」といいます。

この概念は、プログラミングの最も基本的で重要な考え方です。コンピュータは人間のように「全体を見渡して判断する」ということをしません。書かれた命令を、1行目から順番に、一つずつ忠実に実行していきます。

例えば、3つの `console.log` を書くと、1つ目、2つ目、3つ目の順番で実行されます。人間が本を読むときに1ページ目から順番に読んでいくのと同じです。料理のレシピを上から順番に実行していくのにも似ています。

### コードで見てみよう

以下のコードをコンソールに入力してみましょう。

```javascript
console.log("おはよう")
console.log("こんにちは")
console.log("おやすみ")
```

**実行結果**
```
おはよう
こんにちは
おやすみ
```

3つのメッセージが、書いた順番通りに表示されます。1行目の「おはよう」が最初に表示され、次に「こんにちは」、最後に「おやすみ」が表示されます。

コンピュータは、1行目の `console.log("おはよう")` を実行し終わってから、2行目の `console.log("こんにちは")` に進みます。2行目が終わったら3行目に進む、という具合です。途中をスキップしたり、順番を変えて実行したりすることはありません。

### 順番を変えてみる

順番を入れ替えると、表示される順番も変わります。試しに順番を変えてみましょう。

```javascript
console.log("おやすみ")
console.log("おはよう")
console.log("こんにちは")
```

**実行結果**
```
おやすみ
おはよう
こんにちは
```

「おやすみ」が最初に表示され、次に「おはよう」、最後に「こんにちは」が表示されます。コードを書いた順番がそのまま実行順序になります。

このように、プログラムは必ず上から下へ順番に実行されます。プログラムを書くときは、「どの順番で実行されるか」を常に意識することが大切です。

### なぜ順次実行が重要なのか

順次実行は単純な概念に見えますが、プログラミングの基礎として非常に重要です。

例えば、料理で「野菜を切る」→「鍋に入れる」→「火にかける」という順番があります。これを「火にかける」→「野菜を切る」→「鍋に入れる」の順番で実行すると、おかしなことになります。

プログラミングでも同じで、正しい順番で命令を並べないと、期待した結果が得られません。これから学んでいく様々な機能も、この「順次実行」を基本として動作します。

## 文字列とは

プログラミングでは、文字のデータを「文字列」と呼びます。

「おはよう」「こんにちは」「Hello」など、文字が並んだものはすべて文字列です。1文字だけの「あ」も文字列ですし、とても長い文章も文字列です。

「文字列」という名前は、「文字」が「列」のように並んでいるという意味です。英語では「String」といい、糸のように文字がつながっているイメージです。

### 文字列の書き方

文字列は、ダブルクォーテーション（"）またはシングルクォーテーション（'）で囲んで書きます。

```javascript
console.log("これは文字列です")
console.log('これも文字列です')
```

どちらを使っても結果は同じです。プロジェクトや会社によってどちらを使うか決まっていることもありますが、今は好きな方を使って構いません。

ただし、開始と終了で同じ記号を使う必要があります。

```javascript
console.log("Hello")   // 正しい
console.log('Hello')   // 正しい
console.log("Hello')   // エラー（開始と終了が違う）
```

`"Hello'` のように、ダブルクォーテーションで始めてシングルクォーテーションで終わるとエラーになります。必ず同じ記号で囲んでください。

### なぜクォーテーションが必要なのか

クォーテーションは、「ここからここまでが文字列です」ということをコンピュータに伝える役割があります。

例えば、`Hello` とだけ書くと、コンピュータは「Hello という名前の何か（変数など）」を探そうとします。しかし `"Hello"` と書くと、「Hello という文字を表示して」という意味になります。

クォーテーションがあることで、コンピュータは「これは文字データだ」と正しく認識できるのです。

### 日本語も使える

JavaScriptでは、日本語の文字列も問題なく使えます。

```javascript
console.log("日本語も表示できます")
console.log("ひらがな、カタカナ、漢字")
console.log("絵文字も使えます 🎉")
```

ひらがな、カタカナ、漢字、絵文字など、様々な文字を表示できます。日本語を扱えるのは、私たちにとってとてもありがたいことです。

プログラミング言語によっては日本語の扱いが難しいものもありますが、JavaScriptは日本語を含む多くの言語の文字を簡単に扱えます。

### 空の文字列

文字が何もない「空の文字列」も作れます。

```javascript
console.log("")
```

これを実行すると、空白の行が表示されます（何も表示されないように見えます）。

「何もない」ことを表現するのは奇妙に感じるかもしれませんが、プログラミングでは重要な概念です。例えば、ユーザーが何も入力しなかった場合を表現するのに使います。

### 文字列の長さ

文字列には「長さ」があります。「Hello」は5文字、「おはよう」は4文字です。

今はまだ使いませんが、後のレッスンで文字列の長さを調べる方法を学びます。文字列を扱うための様々な機能がJavaScriptには用意されています。

## 複数行のコードを実行する

これまでは1行ずつコードを入力してきましたが、複数行のコードを一度に実行する方法を紹介します。

### 方法1：1行ずつ実行

各行を入力してEnterを押し、1行ずつ実行します。これは前回から使っている方法です。

```javascript
console.log("1行目")  // 入力してEnter
console.log("2行目")  // 入力してEnter
console.log("3行目")  // 入力してEnter
```

この方法は簡単ですが、1行実行するたびに結果が表示されるので、たくさんのコードを試すときは少し面倒です。

### 方法2：Shift + Enterで改行

コンソールで `Shift + Enter` を押すと、実行せずに改行できます。すべて入力し終わったら `Enter` を押して一度に実行します。

```javascript
console.log("1行目")   // Shift + Enter（改行）
console.log("2行目")   // Shift + Enter（改行）
console.log("3行目")   // Enter（実行）
```

この方法を使うと、複数行のコードをまとめて入力してから一度に実行できます。

### Shift + Enterの使い方

具体的な手順を説明します。

1. コンソールに `console.log("1行目")` と入力
2. `Shift` キーを押しながら `Enter` キーを押す（改行される）
3. 次の行に `console.log("2行目")` と入力
4. `Shift + Enter` で改行
5. `console.log("3行目")` と入力
6. `Enter` キーだけを押す（実行される）

最後の行で `Enter` だけを押すと、入力したすべてのコードが上から順番に実行されます。

複数行のコードを試すときは、この方法がとても便利です。これから先のレッスンでも頻繁に使うので、ぜひ覚えておいてください。

## いろいろな言葉を表示してみよう

ここまで学んだことを使って、いろいろな言葉を表示してみましょう。

時間帯に合わせた挨拶を表示してみます。

```javascript

```

このように、`console.log` を使えば何でも表示できます。自分の好きなように言葉を変えて試してみてください。
