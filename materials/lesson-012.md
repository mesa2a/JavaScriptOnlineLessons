## console.log の復習

### console.log とは何か

`console.log()` は、プログラマーにとって最も重要なツールの1つです。コンソールに値を出力することで、プログラムが正しく動いているか確認できます。

**なぜ console.log が重要なのか**

実際のWebサービス開発でも、プログラマーは常に `console.log()` を使っています。

YouTubeのエンジニアは、動画の再生回数が正しく増えているか確認するために `console.log()` を使います。

Amazonのエンジニアは、カートの合計金額が正しく計算されているか確認するために `console.log()` を使います。

このように、`console.log()` はプログラムの「デバッグ（問題を見つけて修正すること）」に欠かせないツールです。

### 基本の使い方を確認

**文字列を出力**

```javascript
console.log("Hello, World!");
console.log("JavaScriptの復習中です");
```

この2行を実行すると、コンソールには以下のように表示されます。

```
Hello, World!
JavaScriptの復習中です
```

**数値を出力**

```javascript
console.log(100);
console.log(50 + 30);
console.log(200 * 1.1);
```

このコードを実行すると、以下のように表示されます。

```
100
80
220
```

2行目は `50 + 30` という計算が先に行われ、結果の `80` が出力されます。3行目も同様に、`200 * 1.1` が計算されて `220` が出力されます。

### 変数の値を出力

変数に保存した値も、`console.log()` で出力できます。

```javascript
let name = "山田太郎";
console.log(name);

let age = 25;
console.log(age);
```

このコードを実行すると、以下のように表示されます。

```
山田太郎
25
```

変数名ではなく、変数に保存されている**値**が出力されます。

### 文字列と変数を連結して出力

`+` 演算子を使って、文字列と変数を組み合わせることができます。

```javascript
let userName = "佐藤花子";
let userAge = 30;
console.log("名前: " + userName);
console.log("年齢: " + userAge + "歳");
console.log(userName + "さんは" + userAge + "歳です");
```

このコードを実行すると、以下のように表示されます。

```
名前: 佐藤花子
年齢: 30歳
佐藤花子さんは30歳です
```

3行目では、複数の文字列と変数を `+` でつなげています。このように、何個でもつなげることができます。

### 確認問題で理解度チェック

以下のコードの出力を予想してみてください。

```javascript
let a = 10;
let b = 20;
console.log(a + b);
console.log("a + b = " + (a + b));
console.log("a = " + a + ", b = " + b);
```

**答え**

```
30
a + b = 30
a = 10, b = 20
```

**解説**

1行目では、`a + b` という数値の足し算が行われ、`30` が出力されます。

2行目では、`(a + b)` が先に計算されて `30` になり、それが文字列 `"a + b = "` と連結されて `"a + b = 30"` になります。括弧を使うことで、計算を先に行うことができます。

3行目では、文字列、変数a、文字列、変数bの順に連結されます。変数の値が自動的に文字列に変換されて連結されます。

## alert の復習

### alert とは何か

`alert()` は、画面にポップアップウィンドウを表示する関数です。ユーザーに重要なメッセージを伝えたいときに使います。

**実際のWebサービスでの使用例**

Amazonで買い物をしているとき、「カートに追加しました」というメッセージが表示されることがあります。これは `alert()` に似た仕組みです。

Twitterで投稿しようとしたときに「本当に送信しますか？」と確認されることがあります。これも `alert()` や `confirm()` に似た機能です。

このように、ユーザーに情報を伝えたり、確認を求めたりするときに、ポップアップは重要な役割を果たします。

### 基本の使い方を確認

**文字列を表示**

```javascript
alert("こんにちは");
alert("JavaScriptの学習、お疲れ様です");
```

このコードを実行すると、まず「こんにちは」というポップアップが表示されます。「OK」ボタンを押すと、次に「JavaScriptの学習、お疲れ様です」というポップアップが表示されます。

**数値を表示**

```javascript
alert(100);
alert(50 + 50);
```

数値もそのまま表示できます。計算式を書くと、計算結果が表示されます。

### 変数の値を表示

```javascript
let message = "今日は良い天気です";
alert(message);

let score = 85;
alert("テストの点数: " + score + "点");
```

1つ目の `alert()` では、`message` 変数に保存されている文字列が表示されます。

2つ目の `alert()` では、文字列と変数を組み合わせたメッセージが表示されます。

### console.log と alert の違いを理解する

`console.log()` と `alert()` は、どちらも値を表示する機能ですが、重要な違いがあります。

| 項目 | console.log | alert |
|------|-------------|-------|
| 表示場所 | コンソール（開発者ツール内） | 画面（ポップアップウィンドウ） |
| 次の処理 | すぐに次の行に進む | OKボタンを押すまで止まる |
| 用途 | デバッグ（プログラマー向け） | ユーザーへの通知 |
| 一般ユーザーの目 | 見えない | 見える |

**console.log の特徴**

- プログラムはすぐに次の行に進みます
- 複数の値を連続して出力できます
- 一般のユーザーには見えません（開発者ツールを開かないと見えない）
- デバッグ（問題の発見と修正）に最適

**alert の特徴**

- ユーザーが「OK」を押すまでプログラムは止まります
- 画面に大きく表示されるので、一般のユーザーにも見えます
- 重要な通知に使います
- あまり多用すると、ユーザーが煩わしく感じます

### 確認問題で理解度チェック

以下のコードを実行すると、何が起きますか。順番も含めて説明してください。

```javascript
alert("処理を開始します");
console.log("処理中...");
alert("処理が完了しました");
console.log("完了");
```

**答え**

1. まず「処理を開始します」というポップアップが表示されます
2. ユーザーが「OK」を押すと、コンソールに「処理中...」と表示されます
3. 次に「処理が完了しました」というポップアップが表示されます
4. ユーザーが「OK」を押すと、コンソールに「完了」と表示されます

`alert()` は「OK」を押すまでプログラムが止まるので、次の行には進みません。一方、`console.log()` はすぐに次の行に進みます。

## 変数の復習

### 変数とは何だったか

変数は、「データを保存する箱」です。箱には名前（変数名）が付いていて、中に値を入れることができます。

**日常生活での例え**

引き出しに「文房具」というラベルを貼って、中にペンや消しゴムを入れておくようなものです。「文房具」という名前で引き出しを開ければ、中身を取り出せます。

プログラミングでも同じです。`let price = 1000;` と書くと、`price` という名前の箱に `1000` という値を入れることができます。後から `price` という名前を使えば、`1000` という値を取り出せます。

### let と const の使い分け

JavaScriptには、変数を宣言する2つの方法があります。

**let - 値が変わる変数**

```javascript
let counter = 0;       // 最初は0
counter = counter + 1; // 1に変わる
counter = counter + 1; // 2に変わる
console.log(counter);  // 2
```

`let` で宣言した変数は、後から値を変更できます。カウンター、合計金額、ユーザーの入力など、値が変わる可能性があるものには `let` を使います。

**const - 値が変わらない定数**

```javascript
const taxRate = 1.1;   // 消費税率
const pi = 3.14;       // 円周率
const maxScore = 100;  // 最大スコア
```

`const` で宣言した変数（定数）は、後から値を変更できません。消費税率、円周率、設定値など、変わらない値には `const` を使います。

**使い分けの基準**

迷ったときは、以下のように考えます。

1. この値は後で変わる可能性があるか？
   - はい → `let` を使う
   - いいえ → `const` を使う

2. わからない場合
   - まず `const` を使う
   - 後で変更が必要になったら `let` に変える

### 変数を使った計算

変数に保存した値は、計算に使うことができます。

```javascript
let price = 100;
let count = 3;
let total = price * count;
console.log(total);  // 300
```

このコードでは、`price`（単価）と `count`（個数）を掛け算して、`total`（合計）を計算しています。

**実用的な例 - 買い物の合計計算**

```javascript
const taxRate = 1.1;

let applePrice = 150;
let appleCount = 2;
let appleTotal = applePrice * appleCount;

let breadPrice = 200;
let breadCount = 1;
let breadTotal = breadPrice * breadCount;

let subtotal = appleTotal + breadTotal;
let totalWithTax = subtotal * taxRate;

console.log("りんご: " + appleTotal + "円");
console.log("パン: " + breadTotal + "円");
console.log("小計: " + subtotal + "円");
console.log("税込: " + totalWithTax + "円");
```

このプログラムは、Amazonのショッピングカートのような計算をしています。

### 文字列の連結

文字列同士、または文字列と変数を `+` でつなげることができます。

```javascript
let firstName = "山田";
let lastName = "太郎";
let fullName = firstName + lastName;
console.log(fullName);  // "山田太郎"
```

**実用的な例 - 挨拶メッセージの生成**

```javascript
let userName = "佐藤花子";
let greeting = "こんにちは、" + userName + "さん";
alert(greeting);  // "こんにちは、佐藤花子さん"
```

このような文字列連結は、TwitterやInstagramで「〇〇さんがあなたをフォローしました」というメッセージを生成するときにも使われています。

### カウンターの仕組み

`counter = counter + 1` という式は、プログラミングで非常によく使われるパターンです。

```javascript
let counter = 0;

counter = counter + 1;  // 1
console.log(counter);

counter = counter + 1;  // 2
console.log(counter);

counter = counter + 1;  // 3
console.log(counter);
```

**動作の流れ**

1. `let counter = 0;` でカウンターを0で初期化
2. `counter = counter + 1;` を実行
   - 右辺の `counter + 1` を計算 → `0 + 1 = 1`
   - 結果を `counter` に代入 → `counter = 1`
3. 2回目の `counter = counter + 1;` を実行
   - 右辺の `counter + 1` を計算 → `1 + 1 = 2`
   - 結果を `counter` に代入 → `counter = 2`
4. 3回目の `counter = counter + 1;` を実行
   - 右辺の `counter + 1` を計算 → `2 + 1 = 3`
   - 結果を `counter` に代入 → `counter = 3`

この仕組みは、YouTubeの再生回数、Twitterのいいね数、ゲームのスコアなど、あらゆる場面で使われています。

### 確認問題で理解度チェック

以下のコードで、`let` と `const` のどちらを使うべきか考えてください。

```javascript
??? pi = 3.14;
??? radius = 5;
??? score = 0;
??? maxScore = 100;
??? playerName = "太郎";
```

**答え**

```javascript
const pi = 3.14;         // 円周率は変わらない
const radius = 5;        // 半径は（この計算では）変わらない
let score = 0;           // スコアは増える可能性がある
const maxScore = 100;    // 最大値は変わらない
let playerName = "太郎"; // プレイヤー名は変更される可能性がある
```

**解説**

`pi`（円周率）は普遍的な定数なので `const` を使います。

`radius`（半径）は、この計算の中では変わらないので `const` を使います。

`score`（スコア）は、ゲームを進めるうちに増えていく可能性があるので `let` を使います。

`maxScore`（最大スコア）は、設定値で変わらないので `const` を使います。

`playerName`（プレイヤー名）は、ユーザーが変更する可能性があるので `let` を使います。

## 自己紹介ページを作ろう

それでは、第1章の集大成として、自己紹介ページを作成しましょう。これまで学んだすべての知識を使います。

### なぜ自己紹介ページなのか

自己紹介ページは、Webサービスの基本中の基本です。

TwitterやInstagramのプロフィールページ、LinkedInの経歴ページ、ブログの自己紹介ページなど、多くのWebサービスに自己紹介の機能があります。

これらはすべて、変数に情報を保存し、それを組み合わせて表示するという、今回学ぶ内容と同じ仕組みで作られています。

### 要件を確認

自己紹介ページには、以下の要素を含めます。

1. **変数を使って個人情報を保存する**
   - 名前、年齢、出身地、趣味など

2. **定数を使って固定値を保存する**
   - 現在の年、消費税率など

3. **文字列連結で文章を作成する**
   - 複数の変数を組み合わせて自己紹介文を作る

4. **console.log と alert の両方で出力する**
   - デバッグ用にコンソールにも出力
   - ユーザー向けに alert でも表示

5. **計算を含める**
   - 生まれ年から年齢を計算するなど

### 完成例を見てみよう

以下は、自己紹介ページの完成例です。この例を参考に、自分だけのオリジナルページを作ってみましょう。

```html
<script>
// 定数（変わらない値）
const currentYear = 2025;
const birthYear = 1998;

// 変数（個人情報）
let name = "山田太郎";
let city = "東京";
let hobby = "プログラミング";
let favoriteFood = "ラーメン";

// 年齢を計算

// 自己紹介文を作成
let intro1 = "私の名前は" + name + "です。";

let intro3 = city + "に住んでいます。";

// コンソールに出力（デバッグ用）
console.log("=== 自己紹介 ===");
console.log(intro1);
console.log(intro2);
console.log(intro3);
console.log(intro4);
console.log(intro5);

</script>
```

### プログラムの仕組みを理解しよう

このプログラムは、以下のような構造になっています。

**1. 定数の定義**

```javascript
const currentYear = 2025;
const birthYear = 1998;
```

`currentYear` と `birthYear` は変わらない値なので、`const` を使っています。

**2. 変数の定義**

```javascript
let name = "山田太郎";
let city = "東京";
// ... 他の変数
```

個人情報は変更される可能性があるので、`let` を使っています。

**3. 計算**

```javascript
let age = currentYear - birthYear;
```

現在の年から生まれ年を引くことで、年齢を計算しています。これにより、`currentYear` を更新するだけで自動的に年齢も更新されます。

**4. 文字列の作成**

```javascript
let intro1 = "私の名前は" + name + "です。";
```

文字列と変数を `+` でつなげて、完成した文章を作っています。

**5. 出力**

```javascript
console.log(intro1);
alert(intro1);
```

同じ内容を、コンソールと alert の両方で出力しています。

**問題3の解説**
