# JavaScript学習教材

このプロジェクトは、JavaScriptを基礎から学ぶための学習教材です。

## セットアップ

### 1. 依存パッケージのインストール

プロジェクトのルートディレクトリで以下のコマンドを実行してください。

```bash
npm install
```

## 学習の進め方

### 1. 教材を読む

`materials/` フォルダにあるレッスンファイル（`lesson-XXX.md`）を読んで、概念を学びます。

### 2. 練習問題に取り組む

各レッスンの練習問題セクションに従って、`exercises/lesson-XXX/` フォルダにあるファイルを編集します。

#### レッスン1-12の場合

- `exercises/lesson-XXX/index.html` を編集
- `<script>` タグの中にコードを記述

#### レッスン13以降の場合

- `exercises/lesson-XXX/index.html` - HTML要素を追加
- `exercises/lesson-XXX/script.js` - JavaScriptコードを記述

### 3. テストで確認する

コードを書いたら、テストを実行して正解かどうか確認できます。

```bash
npm test exercises/lesson-XXX
```

例：

```bash
npm test exercises/lesson-004
```

#### テスト結果の見方

- **✓（緑色）**: テストが通過しました（正解です）
- **✕（赤色）**: テストが失敗しました（まだ正解ではありません）

すべてのテストが緑色の✓になれば、課題は完成です。

### 4. 解答を確認する

どうしても分からない場合は、`solutions/lesson-XXX/` フォルダにある解答例を参照してください。

## テスト機能について

このプロジェクトでは、Vitestという自動テストツールを使用しています。

### テストの目的

- 課題が正しく実装できているか、即座に確認できる
- エラーメッセージから、何が足りないかヒントを得られる
- 自習時でも、自分の理解度を確認できる

### よくあるテストエラー

#### `expected X to be Y`

- 期待値（Y）と実際の値（X）が異なっています
- 変数名や値が間違っていないか確認してください

#### `undefined`

- 変数が定義されていません
- 変数名のスペルミスや、`let`/`const`を付け忘れていないか確認してください

#### `Tests failed`

- 一部のテストが失敗しています
- エラーメッセージを読んで、どのテストが失敗したか確認してください

## トラブルシューティング

### テストが実行できない

```bash
npm install
```

を実行して、依存パッケージをインストールしてください。

### すべてのテストが失敗する

- ファイルが正しい場所にあるか確認してください
- `<script>` タグが閉じられているか確認してください
- ブラウザの開発者ツール（F12）でエラーが出ていないか確認してください
