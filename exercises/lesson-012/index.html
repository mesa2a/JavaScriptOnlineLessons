🔍 重要な概念の復習

1. console.log と alert の違い

項目 console.log alert
表示場所 コンソール（開発者ツール） 画面（ポップアップ）
次の処理 すぐに進む OKを押すまで止まる
主な用途 開発中のデバッグ ユーザーへの通知
例 console.log("値: " + x) alert("完了しました")

2. let と const の使い分け

キーワード 再代入 使う場面 例
let ✅ できる 値が変わる変数 let counter = 0;
let total = 0;
const ❌ できない 値が変わらない定数 const taxRate = 1.1;
const pi = 3.14;
💡 覚えておくこと：迷ったら const を使い、再代入が必要になったら let に変える

3. よく使うパターン

パターン1：文字列連結
let name = "太郎";
let age = 20;
let message = name + "は" + age + "歳です";
パターン2：カウントアップ
let counter = 0;
counter = counter + 1; // 1
counter = counter + 1; // 2
パターン3：計算と累積
let total = 0;
total = total + 100; // 100
total = total + 200; // 300
パターン4：税込価格計算
const taxRate = 1.1;
let price = 1000;
let priceWithTax = price * taxRate;

課題1：オリジナル自己紹介ページ

第1章で学んだすべての知識を使って、自分だけのオリジナル自己紹介ページを作成してください。

最低5つの変数を使う
最低1つの定数を使う
最低1つの計算を含める
文字列連結で文章を作る
console.logで出力
alertでも表示（任意）
💡 アイデア：
  • 現在の年から生まれ年を引いて年齢を計算
  • 好きな色、血液型、将来の夢なども追加
  • 趣味の開始年から何年続けているか計算
  • 学校や職業の情報も含める

実装例の構成

// 定数
const currentYear = 2025;

// 変数（個人情報）
let name = "あなたの名前";
let birthYear = あなたの生まれ年;
let city = "あなたの出身地";
let hobby = "あなたの趣味";
let favoriteFood = "好きな食べ物";

// 計算
let age = currentYear - birthYear;

// 自己紹介文を作成
let intro1 = "私の名前は" + name + "です。";
let intro2 = birthYear + "年生まれの" + age + "歳です。";
// ... 続きを作成

// 出力
console.log(intro1);
console.log(intro2);
