📝 Lesson 009: 文字の連結

String Concatenation - 名前合成マシンを作ろう！

🎯 今回の目標

  • 文字列同士を連結できるようになる
  • 変数を使って文章を組み立てられるようになる
  • +演算子の2つの役割を理解する
  • 名前合成マシンを作れるようになる

💡 文字列の連結とは

複数の文字列を1つにつなげることを「連結（concatenation）」と言います。JavaScriptでは、+演算子を使って文字列を連結します。

例：
let greeting = "こんにちは" + "世界";
console.log(greeting); // "こんにちは世界"

これは、2つの文字列をくっつけて1つの新しい文字列を作っています！

➕ 数値の場合（足し算）

let a = 10;
let b = 20;
let result = a + b;
// result = 30

計算が行われます

📝 文字列の場合（連結）

let first = "山田";
let last = "太郎";
let full = first + last;
// full = "山田太郎"

連結が行われます

⚠️ +演算子の2つの役割

+演算子は状況によって動作が変わります！

オペランドの型 動作 例
両方が数値 足し算 10 + 20 = 30
少なくとも一方が文字列 連結 "10" + "20" = "1020"
文字列と数値 連結（数値が文字列に変換される） "合計:" + 100 = "合計:100"
🚨 注意が必要なケース

文字列として保存された数字は、足し算ではなく連結になります！

let a = "10"; // 文字列
let b = "20"; // 文字列
console.log(a + b); // "1020" （連結）

1基本の名前合成

自分の名字と名前を変数に保存し、フルネームを作成して表示してください。

📋 手順

  1. firstNameという変数に名字を保存する
  2. lastNameという変数に名前を保存する
  3. fullNameという変数に、firstName + lastNameの結果を保存する
  4. それぞれの値をconsole.logで表示する
💡 ヒント： 文字列は "（ダブルクォーテーション）で囲みます。+演算子で文字列をつなげることができます。
let firstName = "山田";
let lastName = "太郎";
let fullName = firstName + lastName;

console.log("名字：" + firstName);
console.log("名前：" + lastName);
console.log("フルネーム：" + fullName);
📺 期待される出力（コンソール）：
名字：山田
名前：太郎
フルネーム：山田太郎

2挨拶文の作成

名前と時間帯を変数に保存し、挨拶文を作成してください。

📋 手順

  1. nameという変数に名前を保存する
  2. timeOfDayという変数に時間帯（"朝"、"昼"、"夜"など）を保存する
  3. 文字列を連結して挨拶文を作成する
  4. console.logで挨拶文を表示する
💡 ヒント： "さん"や"、"などの記号も文字列として連結できます。例：name + "さん、おはようございます。"
// あなたのコードをここに書いてください
let name = "あなたの名前";
let timeOfDay = "朝";

// 挨拶文を作成して表示
📺 期待される出力例：
山田さん、おはようございます。
または
太郎さん、こんばんは。

3プロフィール文の作成

複数の情報を変数に保存し、1つの文章にまとめて表示してください。

📋 手順

  1. 以下の情報を変数に保存する：
    • 名前（name）
    • 年齢（age）
    • 出身地（hometown）
    • 趣味（hobby）
  2. これらの変数を連結してプロフィール文を作成する
  3. profileという変数に保存する
  4. console.logで表示する
💡 ヒント： 数値（age）も+で連結できます。JavaScriptが自動的に文字列に変換してくれます！
let name = "山田太郎";
let age = 25;
let hometown = "東京";
let hobby = "読書";

let profile = name + "は" + age + "歳で、" + hometown + "出身です。趣味は" + hobby + "です。";
console.log(profile);
📺 期待される出力：
山田太郎は25歳で、東京出身です。趣味は読書です。

4家族の名前合成

3人の家族の名字と名前を変数に保存し、それぞれのフルネームと全員の名前を表示してください。

📋 手順

  1. 3人分の名字と名前を変数に保存する
    • person1First, person1Last
    • person2First, person2Last
    • person3First, person3Last
  2. それぞれのフルネームを作成する（person1Full, person2Full, person3Full）
  3. 各フルネームを表示する
  4. 全員の名前をカンマで区切って連結し、1つの文字列として表示する
💡 ヒント： カンマ（、）も文字列の一部として連結できます。例：person1Full + "、" + person2Full
let person1First = "山田";
let person1Last = "太郎";
let person1Full = person1First + person1Last;

// 残りの2人の情報も同様に作成してください

console.log("家族1：" + person1Full);
// 残りの家族も表示

let allNames = person1Full + "、" + person2Full + "、" + person3Full;
console.log("全員：" + allNames);
📺 期待される出力例：
家族1：山田太郎
家族2：山田花子
家族3：山田次郎
全員：山田太郎、山田花子、山田次郎

5計算と連結の組み合わせ（チャレンジ！）

生まれ年と現在の年を変数に保存し、年齢を計算して、文章を作成してください。

📋 手順

  1. birthYearという変数に生まれ年を保存する
  2. currentYearという変数に現在の年（2025）を保存する
  3. ageという変数に年齢を計算して保存する（currentYear - birthYear）
  4. 文字列連結を使って「私は○○年生まれで、今年○○歳になります。」という文章を作成する
  5. console.logで表示する
💡 ヒント： まず計算（-）を行い、その結果を変数に保存してから、文字列連結（+）で文章を作ります。
🚨 重要： このタスクでは、計算（減算）と連結（+）の両方を使います。birthYearとcurrentYearは数値として保存してください！
let birthYear = 1998;
let currentYear = 2025;
let age = currentYear - birthYear; // 計算

let message = "私は" + birthYear + "年生まれで、今年" + age + "歳になります。";
console.log(message);
📺 期待される出力：
私は1998年生まれで、今年27歳になります。
