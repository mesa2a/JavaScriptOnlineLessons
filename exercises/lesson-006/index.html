レッスン6：alertで画面に表示 - 演習

🎯 今回の目標

この演習では、alert()とconfirm()を使ってユーザーにメッセージを表示する方法を学びます。

  • ✅ alert()でポップアップを表示できる
  • ✅ 複数のalert()を連続で使える
  • ✅ confirm()で確認ダイアログを表示できる
  • ✅ console.log()との違いを理解する

📚 console.log() と alert() の違い

console.log()とalert()は、どちらも何かを表示する命令ですが、表示する場所が異なります。

console.log()

  • 📝 コンソールに表示
  • 開発者ツール（F12）を開かないと見えない
  • プログラマー向けのツール
  • デバッグ（バグ探し）に使う
  • 実行を止めない

alert()

  • 💬 画面にポップアップ表示
  • 誰でも見える
  • ユーザー向けのメッセージ
  • お知らせや警告に使う
  • OKを押すまで実行が止まる
🚨 重要ポイント

alert()は「OKボタンを押すまで次に進まない」という特徴があります。これは3コマ漫画のように、順番にストーリーを見せたいときに便利です。

📝 課題1：自己紹介を3コマで表示する

自分の名前、趣味、あいさつを、3つのalert()で順番に表示してください。

手順：
  1. 下のscriptタグの中にコードを書く
  2. ファイルを保存する（Ctrl + S）
  3. ブラウザでこのファイルを開く（またはリロード F5）
  4. ポップアップが表示されたら、OKボタンを押す
  5. 次のポップアップが表示される → また OKを押す
  6. 3つ目のポップアップが表示される → OKを押す
<script> alert("私の名前は山田太郎です。"); alert("趣味は読書です。"); alert("よろしくお願いします。"); </script>

期待される表示：

  1. 最初のポップアップ：「私の名前は山田太郎です。」
  2. OKを押すと次：「趣味は読書です。」
  3. OKを押すと最後：「よろしくお願いします。」

📝 課題2：朝の1日を5コマで表示する

朝起きてから家を出るまでの行動を、5つのalert()で順番に表示してください。

重要： 課題1のコードを残したまま、課題2のコードを追加してください。そうすると、ポップアップが合計8つ（3+5）表示されます。確認したら、課題1の3行を削除またはコメントアウトして、課題2だけが動くようにしましょう。
<script> // 課題1はコメントアウト // alert("私の名前は山田太郎です。"); // alert("趣味は読書です。"); // alert("よろしくお願いします。"); // 課題2 alert("目が覚めました。"); alert("顔を洗いました。"); alert("朝ごはんを食べました。"); alert("歯を磨きました。"); alert("家を出ました。"); </script>

ヒント： 自分の朝の行動を思い出して書いてみましょう。例えば、「目が覚めた」「朝ごはんを食べた」「学校に行った」などです。

📝 課題3：計算物語を作る

お金の計算をストーリー形式で表示してください。

ストーリーの流れ：
  1. 「100円持っています」
  2. 「50円のお菓子を買いました」
  3. 「残りは...」
  4. 計算結果（alert(100 - 50)）
  5. 「50円です」
<script> alert("100円持っています。"); alert("50円のお菓子を買いました。"); alert("残りは..."); alert(100 - 50); alert("50円です。"); </script>
注目： alert(100 - 50)のように、クォーテーション（引用符）をつけないと、計算された結果（50）が表示されます。

応用： 金額や商品を変えて、自分だけの計算物語を作ってみましょう！

📝 課題4：confirmを使った確認

confirm()は、ユーザーに「はい」か「いいえ」を選んでもらうためのポップアップです。

<script> confirm("この先に進みますか？"); alert("ありがとうございます。"); </script>

試してみよう：

  1. 上のコードを実行する
  2. confirmのポップアップが表示される
  3. 「OK」または「キャンセル」をクリック
  4. どちらを選んでも次のalertが表示される
メモ： confirm()は、ユーザーが「OK」を押したか「キャンセル」を押したかを判定できますが、それは後のレッスンで学びます。今は「確認ダイアログが表示される」ことを体験してください。

🎓 学習のポイント

alertの特徴

  • 画面に表示される - F12を開かなくても見える
  • 順番に表示される - OKを押すまで次に進まない
  • ストーリーが作れる - 3コマ漫画のように表現できる
  • ユーザーへの通知 - お知らせや警告に使う

console.logとの使い分け

  • console.log() → プログラムの動作確認（開発者用）
  • alert() → ユーザーへのメッセージ（ユーザー用）
