🔒 Lesson 010: 変わらない値

const - 定数で間違いを防ごう！

🎯 今回の目標

  • 定数（const）とは何かを理解する
  • constを使って変わらない値を定義できる
  • letとconstの違いを理解する
  • エラーメッセージを読めるようになる

💡 定数（const）とは

定数とは、一度値を設定したら変更できない変数のことです。JavaScriptではconstキーワードを使って定数を宣言します。

例：
const pi = 3.14;
console.log(pi); // 3.14

円周率（pi）のように、プログラムの中で変更してはいけない値を保存するときに使います。

🤔 なぜconstを使うのか？

  • 意図を明確にする：この値は変更しないという意図が伝わる
  • 間違いを防ぐ：うっかり変更しようとするとエラーが出る
  • コードの品質を上げる：読みやすく、保守しやすいコードになる

📝 let（変数）

let count = 1;
count = 2; // ✅ OK!
count = 3; // ✅ OK!

再代入できる
値が変わる場合に使う

🔒 const（定数）

const pi = 3.14;
pi = 3.14159; // ❌ エラー！

再代入できない
値が変わらない場合に使う

🚨 重要：constは変更できない！

constで宣言した定数に値を再代入しようとすると、"Assignment to constant variable"というエラーが発生します。

❌ エラーメッセージ：
Uncaught TypeError: Assignment to constant variable.

1円周率と円の面積

円周率を定数として定義し、半径5の円の面積を計算してください。

📋 手順

  1. const pi = 3.14で円周率を定数として定義
  2. let radius = 5で半径を変数として定義
  3. 面積 = 半径 × 半径 × 円周率 の公式で計算
  4. 結果をareaという変数に保存
  5. 半径と面積をconsole.logで表示
💡 ヒント： 円周率は数学で決まっている値なので、constを使います。半径は後で変更する可能性があるので、letを使います。
const pi = 3.14;
let radius = 5;
let area = radius * radius * pi;

console.log("半径：" + radius);
console.log("面積：" + area);
📺 期待される出力（コンソール）：
半径：5
面積：78.5

3割引計算

割引率20%を定数として定義し、1000円の商品の割引後価格を計算してください。

📋 手順

  1. const discountRate = 0.2で割引率（20%）を定義
  2. let originalPrice = 1000で元の価格を定義
  3. 割引後価格 = 元の価格 × (1 - 割引率) で計算
  4. 元の価格、割引率、割引後価格を表示
💡 ヒント： 20%引きは、80%（1 - 0.2 = 0.8）の価格になるということです。1000円 × 0.8 = 800円になります。
🚨 重要： 割引率0.2は「20%」を意味します。パーセント表示したい場合は、0.2 × 100 = 20 として計算します。
const discountRate = 0.2;
let originalPrice = 1000;
let discountedPrice = originalPrice * (1 - discountRate);

console.log("元の価格：" + originalPrice + "円");
console.log("割引率：" + (discountRate * 100) + "%");
console.log("割引後価格：" + discountedPrice + "円");
📺 期待される出力：
元の価格：1000円
割引率：20%
割引後価格：800円

4エラーを体験する

constに再代入しようとして、エラーメッセージを確認してください。

📋 手順

  1. const message = "Hello"で定数を宣言
  2. message = "World"で再代入を試みる
  3. F12キーで開発者ツールを開く
  4. コンソールタブでエラーメッセージを確認
  5. エラーメッセージの内容と、エラーが発生した行を確認
🚨 重要：このエラーは意図的に発生させています！

エラーが出ることで、constが再代入できないことを確認します。これは学習のためなので、心配しないでください。

const message = "Hello";
message = "World"; // ← ここでエラーが発生します
console.log(message);
❌ 表示されるエラーメッセージ：
Uncaught TypeError: Assignment to constant variable.
at index.html:2

📖 エラーメッセージの読み方

  • Uncaught：捕捉されなかった（処理されなかった）
  • TypeError：型に関するエラー
  • Assignment to constant variable：定数への代入
  • at index.html:2：index.htmlの2行目でエラー発生
