レッスン7：値を保存する - 演習

🎯 今回の目標

この演習では、変数を使ってデータを保存する方法を学びます。

  • ✅ 変数とは何かを理解する
  • ✅ letを使って変数を作成できる
  • ✅ 変数に値を保存し、取り出すことができる
  • ✅ 変数の命名規則を理解する
  • ✅ 5つの変数を作って自己紹介データを作れる

📦 変数とは何か

変数は、データを保存しておく箱のようなものです。

身近な例で考えよう

学校のロッカーを思い浮かべてください：

  • ロッカー番号 = 変数名（例：locker5）
  • 中身 = 値（例：教科書、体操服）
  • 札 = データの型（例：「教科書入れ」「体操服入れ」）

プログラムでも同じように、「名前」をつけた箱に「データ」を入れて、後で取り出して使います。

なぜ変数が必要？

❌ 変数を使わない場合

console.log("山田太郎さん、こんにちは"); console.log("山田太郎さん、今日は良い天気ですね"); console.log("山田太郎さん、また会いましょう");

問題： 名前を変えたい場合、3箇所すべて修正が必要

✅ 変数を使う場合

let name = "山田太郎"; console.log(name + "さん、こんにちは"); console.log(name + "さん、今日は良い天気ですね"); console.log(name + "さん、また会いましょう");

利点： 1箇所変えるだけで、すべて変わる！

📝 変数の作り方

基本の形

let 変数名 = 値;
部分 名前 説明
let キーワード 「変数を作るよ」という宣言
変数名 識別子 箱につける名前（自由に決められる）
= 代入演算子 「右の値を左の箱に入れる」という意味
値 データ 保存したい情報
; セミコロン 命令の終わりを示す

具体例

let name = "山田太郎"; // 文字列を保存 let age = 25; // 数値を保存
🚨 重要な違い
  • 文字列はクォーテーション（" "）で囲む → "山田太郎"
  • 数値はクォーテーションをつけない → 25

📝 課題1：基本の変数作成

以下の3つの情報を変数に保存し、console.log()で表示してください。

保存する情報：
  1. 自分の名前（変数名：name）
  2. 自分の年齢（変数名：age）
  3. 好きな色（変数名：color）
let name = "自分の名前"; let age = 自分の年齢; let color = "好きな色"; console.log(name); console.log(age); console.log(color);
確認方法：
  1. 上のコードを下の<script>タグに書く
  2. ファイルを保存（Ctrl + S）
  3. ブラウザでこのファイルを開く
  4. F12を押して開発者ツールを開く
  5. コンソールタブを確認 → 3つの値が表示されればOK！

📝 課題2：5つの変数を作成

自己紹介データとして、5つの変数を作成してください。

作成する変数：
  1. name - 名前（文字列）
  2. age - 年齢（数値）
  3. birthplace - 出身地（文字列）
  4. occupation - 職業または学校（文字列）
  5. dream - 将来の夢（文字列）
let name = "山田太郎"; let age = 25; let birthplace = "東京"; let occupation = "学生"; let dream = "プログラマー"; console.log(name); console.log(age); console.log(birthplace); console.log(occupation); console.log(dream);

ヒント： 文字列は必ず " " で囲む。数値（年齢）だけはクォーテーションなし。

📝 課題3：数値の変数を作成

以下の数値データを変数に保存してください。すべて数値なので、クォーテーションは不要です。

作成する変数：
  1. temperature - 今日の気温（例：20）
  2. height - 自分の身長（cm、例：165）
  3. favoriteNumber - 好きな数字（例：7）
  4. sleepHours - 1日の睡眠時間（例：7）
let temperature = 20; let height = 165; let favoriteNumber = 7; let sleepHours = 7; console.log(temperature); console.log(height); console.log(favoriteNumber); console.log(sleepHours);
注意： 数値にクォーテーションをつけると文字列になってしまいます。
  • let age = 25; → 数値（計算できる）
  • let age = "25"; → 文字列（計算できない）

📝 課題4：alertで自己紹介

課題2で作成した5つの変数を、alert()で順番に表示してください。

let name = "山田太郎"; let age = 25; let birthplace = "東京"; let occupation = "学生"; let dream = "プログラマー"; alert(name); alert(age); alert(birthplace); alert(occupation); alert(dream);

実行すると： 5つのポップアップが順番に表示されます。OKを押すたびに次の情報が表示されます。

📐 変数の命名規則

使える文字

使える 例
英字（a-z, A-Z） name, userName
数字（0-9） age1, user2
アンダースコア（_） user_name, _temp
ドル記号（$） $price, price$

✅ 正しい例

let name = "太郎"; let age1 = 25; let user_name = "花子"; let $price = 100; let userName = "次郎";

❌ 間違った例

let 1age = 25; // 数字で始まっている let user-name = "花子"; // ハイフンは使えない let my name = "太郎"; // スペースは使えない let let = 10; // 予約語は使えない

キャメルケース（推奨）

複数の単語を組み合わせるときは、キャメルケースを使います。

  • 最初の単語は小文字で始める
  • 2番目以降の単語は大文字で始める
let firstName = "太郎"; // first Name → firstName let lastName = "山田"; // last Name → lastName let phoneNumber = "090-1234-5678"; // phone Number → phoneNumber let favoriteFood = "ラーメン"; // favorite Food → favoriteFood

なぜ「キャメル（ラクダ）」？

phoneNumberの大文字部分（N）が、ラクダのこぶのように見えるからです！

🎓 学習のポイント

変数の3つの要素

  1. 名前：変数を識別するための名前（例：name, age）
  2. 値：変数に保存されているデータ（例："山田太郎", 25）
  3. 型：データの種類（例：文字列、数値）

文字列 vs 数値

種類 書き方 例
文字列 クォーテーションで囲む "山田太郎", "東京"
数値 そのまま書く 25, 170, 23.5

良い変数名の付け方

  • ✅ 内容がわかる名前をつける（userName > a）
  • ✅ キャメルケースを使う（firstName）
  • ✅ 英語を使う（プログラミングの慣習）
  • ❌ 短すぎる名前は避ける（a, xなど）
  • ❌ 予約語は使わない（let, ifなど）
