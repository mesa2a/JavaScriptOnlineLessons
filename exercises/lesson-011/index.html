📖 復習：letとconstの違い

📝 let（変数）

再代入できる

let counter = 0;
counter = 1; // OK!
counter = 2; // OK!

値が変わる場合に使う

🔒 const（定数）

再代入できない

const pi = 3.14;
pi = 3.14159; // エラー！

値が変わらない場合に使う

counter = counter + 1 の意味

数学 vs プログラミング

数学 プログラミング
x = x + 1 は成り立たない counter = counter + 1 は成り立つ
= は「等しい」 = は「代入する」
ステップ1：右辺を計算する
counter + 1 // 現在の値に1を足す
ステップ2：結果を左辺に代入する
counter = 結果 // 計算結果をcounterに保存

具体例：counterが5のとき

counter = counter + 1;

// ステップ1：右辺を計算
// counter + 1 = 5 + 1 = 6

// ステップ2：結果を代入
// counter = 6

🎯 なぜカウンターにletを使うのか

💡 ポイント：カウンターは値が変わっていくので、let を使います。
let counter = 0; // 最初は0
counter = counter + 1; // 1に変わる
counter = counter + 1; // 2に変わる
⚠️ constを使うとエラー：
const counter = 0;
counter = counter + 1; // エラー！

🎯 最大値にはconstを使う

カウンターの上限値は変わらないので、const を使います。

例：上限付きカウンター

const maxCount = 10; // 上限は固定（const）
let counter = 0; // カウンターは変わる（let）

counter = counter + 1;
console.log(counter + " / " + maxCount); // "1 / 10"

📝 よくある間違い

間違い1：カウンターにconstを使う
const counter = 0;
counter = counter + 1; // エラー！

正解：カウンターは値が変わるので let を使う

間違い2：上限値にletを使う
let maxCount = 10; // constの方が良い

正解：変わらない値には const を使う

間違い3：counter + 1だけ書く
let counter = 0;
counter + 1; // これでは値が変わらない！
console.log(counter); // まだ0のまま

正解：counter = counter + 1 と代入する
