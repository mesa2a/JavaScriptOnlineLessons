レッスン8：変数を使った計算 - 演習

🎯 今回の目標

この演習では、変数を使って計算する方法を学びます。

  • ✅ 変数を使って計算ができる
  • ✅ 計算結果を変数に保存できる
  • ✅ 文字列と変数を組み合わせて表示できる
  • ✅ 実用的な買い物計算機を作れる

🧮 変数を使った計算の基本

なぜ変数を使うのか？

❌ 直接数値を書く場合

let total = 100 * 3; console.log(total); // 300

問題：

  • 100が何を表すか不明
  • 3が何を表すか不明
  • 価格を変えたいとき、すべての100を探す必要がある

✅ 変数を使う場合

let price = 100; let count = 3; let total = price * count; console.log(total); // 300

利点：

  • 意味が明確（価格×個数）
  • priceを変えるだけで済む
  • 何度でも再利用できる

計算の流れ

  1. priceに100を保存
  2. countに3を保存
  3. price * countを計算（100 × 3 = 300）
  4. 結果の300をtotalに保存
  5. totalの値を表示

➕ 四則演算の復習

変数を使っても、四則演算はすべて同じように使えます。

演算 記号 例 結果
足し算 + let a = 10; let b = 20; let c = a + b; 30
引き算 - let a = 100; let b = 30; let c = a - b; 70
掛け算 * let a = 5; let b = 6; let c = a * b; 30
割り算 / let a = 100; let b = 4; let c = a / b; 25

🔗 文字列と変数の連結

+記号は、文字列が含まれる場合は連結をします。

連結の仕組み

console.log(1 + 2); // 3（数値の足し算） console.log("1" + "2"); // "12"（文字列の連結） console.log("合計：" + 3); // "合計：3"（文字列と数値の連結）
🚨 重要ポイント
  • 数値同士の場合 → 足し算
  • 文字列が含まれる場合 → 連結
  • 数値は自動的に文字列に変換される

変数を使った連結

let total = 300; console.log("合計：" + total + "円"); // 出力：合計：300円

複数の変数を連結

let item = "りんご"; let price = 150; let count = 3; let total = price * count; console.log(item + "を" + count + "個買いました"); console.log("合計は" + total + "円です"); // 出力： // りんごを3個買いました // 合計は450円です

⚠️ よくある間違い

間違い1：計算順序

❌ 間違い

let a = 10; let b = 20; console.log("合計：" + a + b); // 出力：合計：1020（文字列連結）

「合計：」に10が連結され、さらに20が連結される

✅ 正しい

let a = 10; let b = 20; console.log("合計：" + (a + b)); // 出力：合計：30（正しく計算）

括弧の中が先に計算される

間違い2：変数名をクォーテーションで囲む

❌ 間違い

let price = 100; console.log("price"); // 出力：price（文字列）

✅ 正しい

let price = 100; console.log(price); // 出力：100（変数の値）

📝 課題1：基本の計算

単価200円の商品を4個買った場合の合計金額を計算し、以下の形式で表示してください。

期待される出力： 
単価：200円
個数：4個
合計：800円
手順：
  1. priceという変数に200を保存
  2. countという変数に4を保存
  3. totalという変数にprice * countの計算結果を保存
  4. 3つのconsole.log()で結果を表示
let price = 200; let count = 4; let total = price * count; console.log("単価：" + price + "円"); console.log("個数：" + count + "個"); console.log("合計：" + total + "円");
確認方法：
  1. 上のコードを下の<script>タグに書く
  2. ファイルを保存（Ctrl + S）
  3. ブラウザでこのファイルを開く
  4. F12を押して開発者ツールを開く
  5. コンソールタブを確認

📝 課題2：割引計算

1000円の商品に20%の割引を適用した金額を計算し、表示してください。

期待される出力： 
元の価格：1000円
割引率：20%
割引額：200円
支払い額：800円
計算の流れ：
  1. 元の価格：1000円
  2. 割引率：20%
  3. 割引額 = 元の価格 × 割引率 ÷ 100
  4. 支払い額 = 元の価格 - 割引額
💡 ヒント

20%は「20 / 100」または「0.2」です。

割引額の計算：price * discountRate / 100

📝 課題3：買い物リスト

以下の買い物リストの合計を計算してください。

  • ノート：150円 × 2冊
  • ペン：100円 × 3本
  • 消しゴム：80円 × 1個
期待される出力： 
ノート：300円
ペン：300円
消しゴム：80円
合計：680円
手順：
  1. 各商品の価格と個数を変数に保存
  2. 各商品の小計を計算
  3. すべての小計を足して総合計を計算
  4. 結果を表示
💡 ヒント

変数名の例：

  • notebookPrice, notebookCount, notebookTotal
  • penPrice, penCount, penTotal
  • eraserPrice, eraserCount, eraserTotal
  • grandTotal（総合計）

📝 課題4：お釣り計算

1000円札を出して680円の買い物をした場合のお釣りを計算し、表示してください。

期待される出力： 
支払い：1000円
金額：680円
お釣り：320円
計算の流れ：
  1. 支払い金額：1000円
  2. 購入金額：680円
  3. お釣り = 支払い金額 - 購入金額
💡 ヒント

引き算（-）を使います。

変数名の例：payment（支払い）、cost（金額）、change（お釣り）

💬 コメントについて

//で始まる行は「コメント」と呼ばれ、プログラムの実行には影響しません。

// これはコメントです let price = 100; // 変数の横にも書けます /* 複数行のコメントは このように書きます */
コメントの用途：
  • コードの説明を書く
  • 後で見返したときにわかりやすくする
  • 一時的にコードを無効化する（デバッグ時）

🎓 学習のポイント

式と値

  • 式：計算や操作を表すコード（例：100 * 3）
  • 値：式が評価された結果（例：300）
  • 変数は値を持っているので、式の中で使える

変数を使う利点

  1. わかりやすい：price * countは意味が明確
  2. 変更が簡単：価格を変えるのは1箇所だけ
  3. 再利用できる：同じ値を何度も使える
  4. 計算を分割できる：複雑な計算を段階的に行える

文字列連結の注意点

  • +は文字列連結と数値加算の両方に使われる
  • 文字列が含まれると連結になる
  • 計算を先にしたい場合は括弧を使う：(a + b)
